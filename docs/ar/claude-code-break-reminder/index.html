كيف تضيف تذكيرًا بالاستراحة إلى Claude Code

vibestretch إضافة لـ Claude Code. تستخدم ثلاثة خطافات لرصد الدورات الطويلة وتنبيهك إلى الحركة.

التثبيت

شغّل هذين الأمرين داخل Claude Code:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

لا توجد اعتماديات، ولا عملية خلفية، ولا بيانات قياس عن بُعد. ولا شيء آخر يحتاج إلى إعداد.

أين يظهر التنبيه

  • سطر في الجلسة.
  • رنين خفيف مرفق.
  • شريط إشعار في Warp وGhostty وiTerm2 وWezTerm وkitty. وفي VS Code يحتاج إلى إضافة إشعارات.
  • شريط الحالة لديك، إن أعددته.

أضفه إلى شريط الحالة

/vibestretch:statusline

ينشئ هذا الأمر نسخة احتياطية من إعداداتك ويغلّف أمر شريط الحالة الحالي لديك. وإن لم يكن لديك أمر، يثبّت شريطًا بسيطًا. بعد التنبيه يبقى التمرين ظاهرًا هناك 5 دقائق. تراجع عنه بالأمر /vibestretch:statusline off. شغّل off قبل إلغاء تثبيت الإضافة.

VS Code

في الطرفية المدمجة يعمل السطر والرنين وشريط الحالة كلها. أما في لوحة الدردشة الخاصة بالإضافة فلا يصلك إلا الرنين. ويحتاج شريط الإشعار إلى إضافة إشعارات في الحالتين. جرى التحقق من ذلك على Claude Code 2.1.234.

الإعدادات

كل الإعدادات متغيرات بيئة اختيارية. الأوقات بالثواني.

المتغيرالقيمة الافتراضيةالمعنى
VIBESTRETCH_MIN_TURN120يجب أن تستمر الدورة الحالية هذه المدة على الأقل.
VIBESTRETCH_MIN_ACTIVE300وقت الوكيل المطلوب منذ آخر استراحة.
VIBESTRETCH_COOLDOWN900أدنى فاصل بين التنبيهات.
VIBESTRETCH_AWAY300عدم استخدام لوحة المفاتيح أو الفأرة هذه المدة يعني أنك بعيد. على macOS فقط. القيمة 0 توقف هذا الفحص.
VIBESTRETCH_DISABLEunsetاضبطه على أي قيمة لكتم التنبيهات.
VIBESTRETCH_NOTIFY1اضبطه على 0 لإلغاء إشعار سطح المكتب.
VIBESTRETCH_SOUND1اضبطه على 0 لكتم الصوت.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtمسار قائمة تمارينك الخاصة.

هل تشغّل Claude Code دون واجهة باستخدام claude -p من سكربت؟ اضبط VIBESTRETCH_DISABLE=1 هناك.

الأسئلة الشائعة

كيف أزيل جزء شريط الحالة؟
شغّل /vibestretch:statusline off. افعل ذلك قبل إلغاء تثبيت الإضافة، وإلا سيبقى الجزء مُعدًّا لكنه متجمّد.
هل يصل التنبيه إلى النموذج؟
لا. التنبيه عبارة عن systemMessage. يُعرض عليك ولا يُضاف أبدًا إلى سياق النموذج.
لماذا أسمع صوتين؟
بعض الطرفيات، مثل iTerm2، تشغّل صوتها الخاص للإشعارات. اضبط VIBESTRETCH_SOUND=0 لتُبقي صوت الطرفية فقط.
