How to add a break reminder to Claude Code

vibestretch is a Claude Code plugin. It uses three hooks to notice long turns and nudge you to move.

Install

Run these two commands inside Claude Code:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

There are no dependencies, no daemon and no telemetry. Nothing else to configure.

Where the nudge shows up

  • A line in the session.
  • A soft bundled chime.
  • A notification banner in Warp, Ghostty, iTerm2, WezTerm and kitty. In VS Code it needs a notifier extension.
  • Your status line, if you set it up.

Add it to your status line

/vibestretch:statusline

This command backs up your settings and wraps your existing status line command. If you have none, it installs a minimal one. After a nudge, the exercise stays there for 5 minutes. Undo it with /vibestretch:statusline off. Run off before you uninstall the plugin.

VS Code

In the integrated terminal the line, the chime and the status line all work. In the extension's chat panel only the chime reaches you. The banner needs a notifier extension in both places. This was checked on Claude Code 2.1.234.

Settings

All settings are optional environment variables. Times are in seconds.

VariableDefaultMeaning
VIBESTRETCH_MIN_TURN120The current turn must run at least this long.
VIBESTRETCH_MIN_ACTIVE300Agent time needed since your last break.
VIBESTRETCH_COOLDOWN900Minimum gap between nudges.
VIBESTRETCH_AWAY300No keyboard or mouse for this long means you are away. macOS only. 0 turns the guard off.
VIBESTRETCH_DISABLEunsetSet to anything to mute nudges.
VIBESTRETCH_NOTIFY1Set to 0 to drop the desktop notification.
VIBESTRETCH_SOUND1Set to 0 to mute the sound.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtPath to your own exercise list.

Running Claude Code headless with claude -p from a script? Set VIBESTRETCH_DISABLE=1 there.

FAQ

How do I remove the status line segment?
Run /vibestretch:statusline off. Do this before you uninstall the plugin, or the segment stays configured but frozen.
Does the nudge reach the model?
No. The nudge is a systemMessage. It is shown to you and never added to the model's context.
Why do I hear two sounds?
Some terminals, such as iTerm2, play their own sound for notifications. Set VIBESTRETCH_SOUND=0 to keep only the terminal's sound.
