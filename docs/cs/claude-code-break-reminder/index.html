Jak přidat připomínku přestávek do Claude Code

vibestretch je plugin pro Claude Code. Pomocí tří hooků pozná dlouhé běhy a připomene vám, abyste se pohnuli.

Instalace

Spusťte v Claude Code tyto dva příkazy:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

Žádné závislosti, žádný démon a žádná telemetrie. Nic dalšího se nenastavuje.

Kde se připomínka zobrazí

  • Řádek v relaci.
  • Jemný přibalený zvuk.
  • Oznámení ve Warp, Ghostty, iTerm2, WezTerm a kitty. Ve VS Code vyžaduje rozšíření pro oznámení.
  • Váš stavový řádek, pokud si ho nastavíte.

Přidejte ji do stavového řádku

/vibestretch:statusline

Tento příkaz zálohuje vaše nastavení a obalí váš stávající příkaz stavového řádku. Pokud žádný nemáte, nainstaluje jednoduchý. Po připomínce tam cvik zůstane 5 minut. Vrátíte to příkazem /vibestretch:statusline off. Před odinstalací pluginu spusťte off.

VS Code

V integrovaném terminálu funguje řádek, zvuk i stavový řádek. V panelu chatu rozšíření se k vám dostane jen zvuk. Oznámení na obou místech vyžaduje rozšíření pro oznámení. Ověřeno na Claude Code 2.1.234.

Nastavení

Všechna nastavení jsou volitelné proměnné prostředí. Časy jsou v sekundách.

ProměnnáVýchozíVýznam
VIBESTRETCH_MIN_TURN120Aktuální běh musí trvat alespoň takto dlouho.
VIBESTRETCH_MIN_ACTIVE300Potřebný čas agenta od poslední přestávky.
VIBESTRETCH_COOLDOWN900Minimální odstup mezi připomínkami.
VIBESTRETCH_AWAY300Když takto dlouho nepoužijete klávesnici ani myš, jste pryč. Jen macOS. 0 tuto ochranu vypne.
VIBESTRETCH_DISABLEunsetNastavte na cokoli a připomínky utichnou.
VIBESTRETCH_NOTIFY1Nastavte na 0 a oznámení na ploše se nezobrazí.
VIBESTRETCH_SOUND1Nastavte na 0 a zvuk se vypne.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtCesta k vašemu vlastnímu seznamu cviků.

Spouštíte Claude Code bez rozhraní přes claude -p ze skriptu? Nastavte tam VIBESTRETCH_DISABLE=1.

Časté dotazy

Jak odstraním část stavového řádku?
Spusťte /vibestretch:statusline off. Udělejte to před odinstalací pluginu, jinak část zůstane nastavená, ale zamrzlá.
Dostane se připomínka k modelu?
Ne. Připomínka je systemMessage. Zobrazí se vám a do kontextu modelu se nikdy nepřidá.
Proč slyším dva zvuky?
Některé terminály, například iTerm2, přehrávají u oznámení vlastní zvuk. Nastavte VIBESTRETCH_SOUND=0 a zůstane jen zvuk terminálu.
