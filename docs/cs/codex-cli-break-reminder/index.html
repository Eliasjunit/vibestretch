Jak přidat připomínku přestávek do Codex CLI

vibestretch se do OpenAI Codex CLI instaluje z tržiště pluginů. Během dlouhých běhů zobrazí řádek s protažením a přehraje zvuk.

Instalace jako plugin

codex plugin marketplace add Eliasjunit/vibestretch
codex plugin add vibestretch@vibestretch

Codex nespustí hooky pluginu, dokud je nezkontrolujete. Otevřete /hooks a označte tři položky vibestretch jako důvěryhodné. Do té doby je plugin nainstalovaný, ale mlčí.

Ruční instalace

Totéž zařídí klon repozitáře a konfigurační soubor:

git clone https://github.com/Eliasjunit/vibestretch ~/.codex/vibestretch
cp ~/.codex/vibestretch/hooks/codex-hooks.json ~/.codex/hooks.json

Už máte ~/.codex/hooks.json? Slučte do něj tři položky z našeho souboru. Svůj soubor nepřepisujte. Codex vás při prvním spuštění požádá, abyste nové konfiguraci hooků důvěřovali. To je v pořádku.

Vyberte si jeden způsob. Pokud máte zároveň plugin i ručně přidané položky, každý hook se spustí dvakrát. Pokud jste instalovali ručně před verzí 0.8.0, při přechodu na plugin odstraňte naše položky z ~/.codex/hooks.json.

Co dostanete v Codexu

Dostanete řádek v relaci a zvuk. Oznámení nebude, protože Codex nemá ve výstupu hooku pole pro sekvenci terminálu. Nebude ani část stavového řádku. Tuto lištu v Codexu nelze skriptovat.

Počítadlo je sdílené s Claude Code a Gemini CLI. Hodina čekání se započítá jednou, ať vás v křesle držel kterýkoli agent. Adaptér byl vyzkoušen na skutečné instalaci Codex CLI 0.149.1 na macOS.

Časté dotazy

Nainstaloval jsem ho, ale nic se neděje. Proč?
Codex spouští hooky pluginu, až když jim důvěřujete. Otevřete /hooks a označte tři položky vibestretch jako důvěryhodné.
Každý hook se spouští dvakrát. Proč?
Nejspíš máte v ~/.codex/hooks.json plugin i ručně přidané položky. Ponechte jen jedno z toho.
Můžu ho používat s codex exec?
V tom prostředí nastavte VIBESTRETCH_DISABLE=1. Běhy bez dozoru by se neměly počítat jako čas, který jste prosezeli.
