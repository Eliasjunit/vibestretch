Jak přidat připomínku přestávek do Gemini CLI

Gemini CLI má hooky zapnuté od verze v0.26. vibestretch přidá tři z nich a během dlouhých běhů vám připomene protažení.

Instalace

Naklonujte repozitář:

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

Pak zkopírujte objekt hooks z ~/.gemini/vibestretch/hooks/gemini-hooks.json do ~/.gemini/settings.json. Tento soubor obsahuje celou vaši konfiguraci Gemini, takže ho slučte. Nenahrazujte ho. S jq je to jeden řádek:

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

Pokud už máte vlastní hooky v BeforeAgent, AfterTool nebo AfterAgent, tento příkaz je nahradí našimi. V tom případě přidejte naše tři položky do svých seznamů ručně.

Které hooky používá

  • BeforeAgent: agent začíná pracovat na vašem zadání.
  • AfterTool: nástroj skončil. Přičte se čas čekání, a pokud je připomínka na řadě, zobrazí se.
  • AfterAgent: běh skončil. Počítání se uzavře.

Co dostanete v Gemini CLI

Dostanete řádek v relaci a zvuk. Oznámení nebude. Gemini vyhrazuje standardní výstup hooku jen pro JSON, takže není kam vypsat řídicí sekvenci.

Adaptér byl vyzkoušen na skutečné instalaci Gemini CLI 0.56.0 na macOS. Počítadlo je sdílené s Claude Code a Codex CLI.

Časté dotazy

Jakou verzi Gemini CLI potřebuji?
Hooky jsou zapnuté od Gemini CLI v0.26.
Přepíše sloučení moje nastavení?
Ostatní nastavení zůstanou. Pokud už máte vlastní hooky v BeforeAgent, AfterTool nebo AfterAgent, jq tyto seznamy nahradí našimi. V tom případě přidejte naše tři položky ručně. Soubor si nejdřív zazálohujte.
Můžu ho používat s gemini -p?
Když spouštíte Gemini ze skriptu, z cronu nebo z bota, nastavte VIBESTRETCH_DISABLE=1.
