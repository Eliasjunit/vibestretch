So richtest du eine Pausen-Erinnerung in Claude Code ein

vibestretch ist ein Plugin für Claude Code. Es nutzt drei Hooks, um lange Durchläufe zu erkennen und dich zum Bewegen zu erinnern.

Installation

Führe diese zwei Befehle in Claude Code aus:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

Es gibt keine Abhängigkeiten, keinen Daemon und keine Telemetrie. Sonst ist nichts zu konfigurieren.

Wo die Erinnerung erscheint

  • Als Zeile in der Sitzung.
  • Als leiser, mitgelieferter Ton.
  • Als Benachrichtigung in Warp, Ghostty, iTerm2, WezTerm und kitty. In VS Code braucht es dafür eine Notifier-Erweiterung.
  • In deiner Statuszeile, wenn du sie einrichtest.

In die Statuszeile einbauen

/vibestretch:statusline

Dieser Befehl sichert deine Einstellungen und umschließt deinen bestehenden Statuszeilen-Befehl. Hast du keinen, installiert er einen minimalen. Nach einer Erinnerung bleibt die Übung dort 5 Minuten lang stehen. Rückgängig machst du das mit /vibestretch:statusline off. Führe off aus, bevor du das Plugin deinstallierst.

VS Code

Im integrierten Terminal funktionieren Zeile, Ton und Statuszeile. Im Chat-Panel der Erweiterung erreicht dich nur der Ton. Für die Benachrichtigung braucht es an beiden Stellen eine Notifier-Erweiterung. Geprüft mit Claude Code 2.1.234.

Einstellungen

Alle Einstellungen sind optionale Umgebungsvariablen. Zeiten sind in Sekunden angegeben.

VariableStandardBedeutung
VIBESTRETCH_MIN_TURN120So lange muss der aktuelle Durchlauf mindestens laufen.
VIBESTRETCH_MIN_ACTIVE300Benötigte Agent-Zeit seit deiner letzten Pause.
VIBESTRETCH_COOLDOWN900Mindestabstand zwischen Erinnerungen.
VIBESTRETCH_AWAY300So lange ohne Tastatur oder Maus gilt als abwesend. Nur macOS. 0 schaltet diese Prüfung ab.
VIBESTRETCH_DISABLEunsetAuf einen beliebigen Wert setzen, um Erinnerungen abzuschalten.
VIBESTRETCH_NOTIFY1Auf 0 setzen, um die Desktop-Benachrichtigung abzuschalten.
VIBESTRETCH_SOUND1Auf 0 setzen, um den Ton abzuschalten.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtPfad zu deiner eigenen Übungsliste.

Du startest Claude Code headless mit claude -p aus einem Skript? Setze dort VIBESTRETCH_DISABLE=1.

Häufige Fragen

Wie entferne ich das Segment aus der Statuszeile?
Führe /vibestretch:statusline off aus. Mach das, bevor du das Plugin deinstallierst. Sonst bleibt das Segment konfiguriert, aktualisiert sich aber nicht mehr.
Erreicht die Erinnerung das Modell?
Nein. Die Erinnerung ist eine systemMessage. Sie wird dir angezeigt und nie in den Kontext des Modells aufgenommen.
Warum höre ich zwei Töne?
Manche Terminals, etwa iTerm2, spielen bei Benachrichtigungen einen eigenen Ton ab. Setze VIBESTRETCH_SOUND=0, um nur den Ton des Terminals zu behalten.
