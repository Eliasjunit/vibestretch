So richtest du eine Pausen-Erinnerung in Codex CLI ein

vibestretch lässt sich in OpenAI Codex CLI über den Plugin-Marketplace installieren. Bei langen Durchläufen zeigt es eine Dehn-Zeile und spielt einen Ton.

Als Plugin installieren

codex plugin marketplace add Eliasjunit/vibestretch
codex plugin add vibestretch@vibestretch

Codex führt die Hooks eines Plugins erst aus, wenn du sie geprüft hast. Öffne /hooks und vertraue den drei Einträgen von vibestretch. Bis dahin ist das Plugin installiert, bleibt aber still.

Von Hand installieren

Ein Klon und eine Konfigurationsdatei erledigen dasselbe:

git clone https://github.com/Eliasjunit/vibestretch ~/.codex/vibestretch
cp ~/.codex/vibestretch/hooks/codex-hooks.json ~/.codex/hooks.json

Du hast schon eine ~/.codex/hooks.json? Füge die drei Einträge aus unserer Datei in deine ein. Überschreib deine Datei nicht. Codex fragt beim ersten Start, ob du einer neuen Hook-Konfiguration vertraust. Diese Abfrage ist normal.

Entscheide dich für einen Weg. Sind Plugin und handgemachte Einträge beide vorhanden, läuft jeder Hook doppelt. Hast du vor 0.8.0 von Hand installiert, entferne unsere Einträge aus ~/.codex/hooks.json, wenn du zum Plugin wechselst.

Was du in Codex bekommst

Du bekommst die Zeile in der Sitzung und den Ton. Eine Benachrichtigung gibt es nicht, weil Codex kein Hook-Ausgabefeld für eine Terminal-Sequenz hat. Ein Statuszeilen-Segment gibt es auch nicht. Diese Leiste lässt sich in Codex nicht per Skript ansteuern.

Der Zähler wird mit Claude Code und Gemini CLI geteilt. Eine Stunde Warten zählt nur einmal, egal welcher Agent dich am Stuhl gehalten hat. Der Adapter wurde auf einer echten Installation von Codex CLI 0.149.1 unter macOS ausgeführt.

Häufige Fragen

Ich habe es installiert, aber nichts passiert. Warum?
Codex führt die Hooks eines Plugins erst aus, wenn du ihnen vertraust. Öffne /hooks und vertraue den drei Einträgen von vibestretch.
Jeder Hook läuft doppelt. Warum?
Wahrscheinlich hast du sowohl das Plugin als auch handgemachte Einträge in ~/.codex/hooks.json. Behalte nur eins von beiden.
Kann ich es mit codex exec nutzen?
Setze in dieser Umgebung VIBESTRETCH_DISABLE=1. Unbeaufsichtigte Läufe sollten nicht als Zeit zählen, die du abgesessen hast.
