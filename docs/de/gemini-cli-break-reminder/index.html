So richtest du eine Pausen-Erinnerung in Gemini CLI ein

Gemini CLI hat Hooks seit v0.26 standardmäßig aktiviert. vibestretch fügt drei davon hinzu, um dich bei langen Durchläufen ans Dehnen zu erinnern.

Installation

Klone das Repository:

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

Kopiere dann das Objekt hooks aus ~/.gemini/vibestretch/hooks/gemini-hooks.json in ~/.gemini/settings.json. Diese Datei enthält deine gesamte Gemini-Konfiguration. Führe die Inhalte also zusammen und ersetze die Datei nicht. Mit jq geht das in einer Zeile:

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

Welche Hooks es nutzt

  • BeforeAgent: Der Agent beginnt mit deinem Prompt.
  • AfterTool: Ein Tool ist fertig. Die Wartezeit wird addiert, und wenn eine Erinnerung fällig ist, kommt sie.
  • AfterAgent: Der Durchlauf ist vorbei. Die Abrechnung wird abgeschlossen.

Was du in Gemini CLI bekommst

Du bekommst die Zeile in der Sitzung und den Ton. Eine Benachrichtigung gibt es nicht. Gemini reserviert die Standardausgabe eines Hooks ausschließlich für JSON, es gibt also keinen Platz für eine Escape-Sequenz.

Der Adapter wurde auf einer echten Installation von Gemini CLI 0.56.0 unter macOS ausgeführt. Der Zähler wird mit Claude Code und Codex CLI geteilt.

Häufige Fragen

Welche Version von Gemini CLI brauche ich?
Hooks sind seit Gemini CLI v0.26 standardmäßig aktiviert.
Überschreibt das Zusammenführen meine Einstellungen?
Der jq-Befehl fügt das Objekt hooks in deine bestehende settings.json ein. Wenn du sichergehen willst, leg vorher eine Sicherung der Datei an.
Kann ich es mit gemini -p nutzen?
Setze VIBESTRETCH_DISABLE=1, wenn du Gemini aus einem Skript, per cron oder über einen Bot startest.
