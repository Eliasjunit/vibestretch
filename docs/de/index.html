Dehnen, während dein Coding-Agent arbeitet

vibestretch zeigt dir eine kurze Dehnübung, ein Mini-Workout oder eine Augenpause, während du auf einen langen Agent-Durchlauf wartest. Es funktioniert mit Claude Code, Codex CLI und Gemini CLI.

claude plugin marketplace add Eliasjunit/vibestretch && claude plugin install vibestretch@vibestretch

Damit installierst du das Plugin in Claude Code. Die Seiten zu Codex CLI und Gemini CLI zeigen die jeweiligen Installationsschritte.

So sieht eine Erinnerung aus

🧘 Wrist circles, 10 each way. Your tendons will thank you. · vibestretch · 7 min of agent time

In der Sitzung erscheint eine Zeile. Ein leiser Ton erklingt. In Terminals, die das unterstützen, erscheint zusätzlich eine Benachrichtigung.

Wann es dich erinnert

vibestretch hat keinen Zeitplan. Es zählt nur eines: die Minuten, die du am Rechner auf einen Agent-Durchlauf gewartet hast. Eine Erinnerung kommt nur, wenn alle drei Bedingungen erfüllt sind:

  1. Der aktuelle Durchlauf läuft seit 2 Minuten oder länger.
  2. Deine Agent-Zeit seit der letzten Erinnerung summiert sich auf 5 Minuten oder mehr.
  3. Die letzte Erinnerung liegt mindestens 15 Minuten zurück.

Kurze Durchläufe lösen nichts aus. Ein Tag mit lauter kurzen Durchläufen bleibt ganz still. Es gibt nichts zu verschieben, denn es meldet sich nur, wenn du ohnehin wartest. Mehr dazu unter Dehnpausen während KI-Coding-Agents arbeiten.

Was du bekommst

  • Zwölf eingebaute Übungen: Dehnübungen, Mini-Workouts und Augenpausen wie 20-20-20.
  • Eine Reihenfolge, die nie dieselbe Übung zweimal hintereinander bringt.
  • Auf Wunsch deine eigene Übungsliste. Siehe Dehnübungen am Schreibtisch für Programmierer.
  • Ein optionales Segment in der Statuszeile von Claude Code.

Datenschutz

vibestretch besteht aus ein paar kleinen POSIX-Shell-Skripten und einem mitgelieferten Ton. Es baut keine Netzwerkverbindungen auf. Es sendet keine Telemetrie. Es zeigt keine Werbung und setzt keine Links in dein Terminal. Es fügt dem Kontext des Modells nichts hinzu. Sein Zustand liegt in ~/.cache/vibestretch/.

Häufige Fragen

Was ist vibestretch?
vibestretch ist ein Plugin für Coding-Agents. Es erinnert dich daran, dich zu dehnen, zu bewegen oder die Augen auszuruhen, während du auf einen langen Agent-Durchlauf wartest.
Welche Coding-Agents werden unterstützt?
Claude Code, OpenAI Codex CLI und Gemini CLI. Alle drei nutzen denselben Zähler. Eine Stunde Warten zählt also nur einmal, egal welcher Agent dich am Stuhl gehalten hat.
Ist das ein Pausen-Timer?
Nein. Ein Timer läuft nach Zeitplan. vibestretch zählt nur die Zeit, in der du auf einen Agent-Durchlauf gewartet hast, und erinnert dich nur während dieser Wartezeit.
Sendet es irgendwohin Daten?
Nein. Es baut keine Netzwerkverbindungen auf und sendet keine Telemetrie. Nichts verlässt deinen Rechner.
Was kostet es?
Es ist Open Source unter der MIT-Lizenz. Der Code liegt auf GitHub.
Wie schalte ich es stumm?
Setze VIBESTRETCH_DISABLE auf einen beliebigen Wert, um die Erinnerungen abzuschalten. VIBESTRETCH_SOUND=0 schaltet den Ton ab. VIBESTRETCH_NOTIFY=0 entfernt die Benachrichtigung.
