Πώς βάζετε υπενθύμιση διαλείμματος στο Claude Code

Το vibestretch είναι plugin για το Claude Code. Χρησιμοποιεί τρία hooks για να εντοπίζει τους μεγάλους γύρους και να σας θυμίζει να κινηθείτε.

Εγκατάσταση

Εκτελέστε αυτές τις δύο εντολές μέσα στο Claude Code:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

Δεν έχει εξαρτήσεις, daemon ή τηλεμετρία. Δεν χρειάζεται καμία άλλη ρύθμιση.

Πού εμφανίζεται η υπενθύμιση

  • Μια γραμμή στη συνεδρία.
  • Ένας απαλός ενσωματωμένος ήχος.
  • Μια ειδοποίηση στα Warp, Ghostty, iTerm2, WezTerm και kitty. Στο VS Code χρειάζεται επέκταση ειδοποιήσεων.
  • Η γραμμή κατάστασης, αν τη ρυθμίσετε.

Προσθήκη στη γραμμή κατάστασης

/vibestretch:statusline

Αυτή η εντολή κρατά αντίγραφο ασφαλείας των ρυθμίσεών σας και τυλίγει την υπάρχουσα εντολή της γραμμής κατάστασης. Αν δεν έχετε, εγκαθιστά μια απλή. Μετά από μια υπενθύμιση, η άσκηση μένει εκεί για 5 λεπτά. Για αναίρεση εκτελέστε /vibestretch:statusline off. Εκτελέστε το off πριν απεγκαταστήσετε το plugin.

VS Code

Στο ενσωματωμένο τερματικό λειτουργούν η γραμμή, ο ήχος και η γραμμή κατάστασης. Στο πάνελ συνομιλίας της επέκτασης φτάνει σε εσάς μόνο ο ήχος. Η ειδοποίηση χρειάζεται επέκταση ειδοποιήσεων και στα δύο σημεία. Αυτό ελέγχθηκε στο Claude Code 2.1.234.

Ρυθμίσεις

Όλες οι ρυθμίσεις είναι προαιρετικές μεταβλητές περιβάλλοντος. Οι χρόνοι είναι σε δευτερόλεπτα.

ΜεταβλητήΠροεπιλογήΣημασία
VIBESTRETCH_MIN_TURN120Ο τρέχων γύρος πρέπει να διαρκέσει τουλάχιστον τόσο.
VIBESTRETCH_MIN_ACTIVE300Χρόνος agent που χρειάζεται από το τελευταίο διάλειμμα.
VIBESTRETCH_COOLDOWN900Ελάχιστο διάστημα ανάμεσα στις υπενθυμίσεις.
VIBESTRETCH_AWAY300Αν δεν αγγίξετε πληκτρολόγιο ή ποντίκι για τόσο χρόνο, θεωρείστε απόντες. Μόνο macOS. Το 0 απενεργοποιεί τον έλεγχο.
VIBESTRETCH_DISABLEunsetΟρίστε οποιαδήποτε τιμή για σίγαση των υπενθυμίσεων.
VIBESTRETCH_NOTIFY1Ορίστε 0 για να καταργηθεί η ειδοποίηση επιφάνειας εργασίας.
VIBESTRETCH_SOUND1Ορίστε 0 για σίγαση του ήχου.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtΔιαδρομή προς τη δική σας λίστα ασκήσεων.

Τρέχετε το Claude Code headless με claude -p από script; Ορίστε εκεί VIBESTRETCH_DISABLE=1.

Συχνές ερωτήσεις

Πώς αφαιρώ το τμήμα της γραμμής κατάστασης;
Εκτελέστε /vibestretch:statusline off. Κάντε το πριν απεγκαταστήσετε το plugin, αλλιώς το τμήμα μένει ρυθμισμένο αλλά παγωμένο.
Φτάνει η υπενθύμιση στο μοντέλο;
Όχι. Η υπενθύμιση είναι ένα systemMessage. Εμφανίζεται σε εσάς και δεν προστίθεται ποτέ στο context του μοντέλου.
Γιατί ακούω δύο ήχους;
Κάποια τερματικά, όπως το iTerm2, παίζουν δικό τους ήχο για τις ειδοποιήσεις. Ορίστε VIBESTRETCH_SOUND=0 για να μείνει μόνο ο ήχος του τερματικού.
