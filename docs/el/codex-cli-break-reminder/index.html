Πώς βάζετε υπενθύμιση διαλείμματος στο Codex CLI

Το vibestretch εγκαθίσταται στο OpenAI Codex CLI από το marketplace των plugins. Δείχνει μια γραμμή για διάταση και παίζει έναν ήχο στους μεγάλους γύρους.

Εγκατάσταση ως plugin

codex plugin marketplace add Eliasjunit/vibestretch
codex plugin add vibestretch@vibestretch

Το Codex δεν εκτελεί τα hooks ενός plugin μέχρι να τα ελέγξετε. Ανοίξτε το /hooks και εγκρίνετε ως αξιόπιστες τις τρεις καταχωρίσεις του vibestretch. Μέχρι τότε το plugin είναι εγκατεστημένο αλλά σιωπηλό.

Χειροκίνητη εγκατάσταση

Ένα clone και ένα αρχείο ρυθμίσεων κάνουν την ίδια δουλειά:

git clone https://github.com/Eliasjunit/vibestretch ~/.codex/vibestretch
cp ~/.codex/vibestretch/hooks/codex-hooks.json ~/.codex/hooks.json

Έχετε ήδη ένα ~/.codex/hooks.json; Συγχωνεύστε μέσα του τις τρεις καταχωρίσεις από το δικό μας. Μην αντικαταστήσετε το δικό σας. Το Codex σάς ζητά να εγκρίνετε μια νέα ρύθμιση hooks την πρώτη φορά που εκτελείται. Αυτό το μήνυμα είναι αναμενόμενο.

Διαλέξτε έναν τρόπο. Αν υπάρχουν και το plugin και οι χειροκίνητες καταχωρίσεις, κάθε hook εκτελείται δύο φορές. Αν κάνατε χειροκίνητη εγκατάσταση πριν από την 0.8.0, αφαιρέστε τις καταχωρίσεις μας από το ~/.codex/hooks.json όταν περάσετε στο plugin.

Τι έχετε στο Codex

Έχετε τη γραμμή στη συνεδρία και τον ήχο. Δεν υπάρχει ειδοποίηση, γιατί το Codex δεν έχει πεδίο εξόδου hook για ακολουθία τερματικού. Δεν υπάρχει ούτε τμήμα στη γραμμή κατάστασης. Αυτή η μπάρα δεν ελέγχεται με scripts στο Codex.

Ο μετρητής είναι κοινός με το Claude Code και το Gemini CLI. Μια ώρα αναμονής μετράει μία φορά, όποιος agent κι αν σας κράτησε στην καρέκλα. Ο adapter δοκιμάστηκε σε πραγματική εγκατάσταση του Codex CLI 0.149.1 σε macOS.
