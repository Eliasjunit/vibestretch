Πώς βάζετε υπενθύμιση διαλείμματος στο Gemini CLI

Το Gemini CLI έχει τα hooks ενεργά από την v0.26. Το vibestretch προσθέτει τρία από αυτά για να σας θυμίζει διατάσεις στους μεγάλους γύρους.

Εγκατάσταση

Κάντε clone το αποθετήριο:

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

Μετά αντιγράψτε το αντικείμενο hooks από το ~/.gemini/vibestretch/hooks/gemini-hooks.json στο ~/.gemini/settings.json. Εκείνο το αρχείο περιέχει όλη τη ρύθμιση του Gemini, οπότε κάντε συγχώνευση. Μην το αντικαταστήσετε. Με το jq είναι μία γραμμή:

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

Ποια hooks χρησιμοποιεί

  • BeforeAgent: ο agent αρχίζει να δουλεύει πάνω στο prompt σας.
  • AfterTool: ένα εργαλείο τελείωσε. Προστίθεται χρόνος αναμονής και εμφανίζεται υπενθύμιση αν είναι η ώρα.
  • AfterAgent: ο γύρος τελείωσε. Η καταμέτρηση κλείνει.

Τι έχετε στο Gemini CLI

Έχετε τη γραμμή στη συνεδρία και τον ήχο. Δεν υπάρχει ειδοποίηση. Το Gemini κρατά το stdout ενός hook μόνο για JSON, οπότε δεν υπάρχει πού να τυπωθεί μια ακολουθία escape.

Ο adapter δοκιμάστηκε σε πραγματική εγκατάσταση του Gemini CLI 0.56.0 σε macOS. Ο μετρητής είναι κοινός με το Claude Code και το Codex CLI.

Συχνές ερωτήσεις

Ποια έκδοση του Gemini CLI χρειάζομαι;
Τα hooks είναι ενεργά από το Gemini CLI v0.26.
Θα αντικαταστήσει η συγχώνευση τις ρυθμίσεις μου;
Η εντολή jq συγχωνεύει το αντικείμενο hooks στο υπάρχον settings.json σας. Κρατήστε πρώτα αντίγραφο του αρχείου αν θέλετε να είστε σίγουροι.
Μπορώ να το χρησιμοποιήσω με το gemini -p;
Ορίστε VIBESTRETCH_DISABLE=1 όταν τρέχετε το Gemini από script, cron ή bot.
