Κάντε διατάσεις όσο δουλεύει ο AI agent σας

Το vibestretch δείχνει μια σύντομη διάταση, μια μικρή άσκηση ή ένα διάλειμμα για τα μάτια όσο ένας μεγάλος γύρος του agent σάς κρατά σε αναμονή. Λειτουργεί με Claude Code, Codex CLI και Gemini CLI.

claude plugin marketplace add Eliasjunit/vibestretch && claude plugin install vibestretch@vibestretch

Αυτό εγκαθιστά το plugin στο Claude Code. Οι σελίδες για το Codex CLI και το Gemini CLI δείχνουν τα δικά τους βήματα εγκατάστασης.

Πώς μοιάζει μια υπενθύμιση

🧘 Wrist circles, 10 each way. Your tendons will thank you. · vibestretch · 7 min of agent time

Μια γραμμή εμφανίζεται στη συνεδρία. Ακούγεται ένας απαλός ήχος. Στα τερματικά που το υποστηρίζουν εμφανίζεται και ειδοποίηση.

Πώς αποφασίζει πότε να σας υπενθυμίσει

Το vibestretch δεν έχει πρόγραμμα. Μετράει ένα πράγμα: τα λεπτά που ένας γύρος του agent σάς κράτησε να περιμένετε μπροστά στον υπολογιστή. Μια υπενθύμιση εμφανίζεται μόνο όταν ισχύουν και τα τρία:

  1. Ο τρέχων γύρος τρέχει 2 λεπτά ή περισσότερο.
  2. Ο χρόνος agent από την τελευταία υπενθύμιση φτάνει τα 5 λεπτά ή περισσότερο.
  3. Η τελευταία υπενθύμιση ήταν πριν από τουλάχιστον 15 λεπτά.

Οι γρήγοροι γύροι δεν την ενεργοποιούν ποτέ. Μια μέρα με σύντομους γύρους περνάει χωρίς καμία υπενθύμιση. Δεν υπάρχει τίποτα για αναβολή, γιατί μιλάει μόνο όταν ήδη περιμένετε. Διαβάστε περισσότερα στο διαλείμματα για διατάσεις όσο τρέχουν οι AI agents.

Τι περιλαμβάνει

  • Δώδεκα ενσωματωμένες ασκήσεις: διατάσεις, μικρές ασκήσεις και διαλείμματα για τα μάτια, όπως το 20-20-20.
  • Εναλλαγή που δεν επαναλαμβάνει ποτέ την ίδια άσκηση δύο φορές στη σειρά.
  • Τη δική σας λίστα ασκήσεων, αν την προτιμάτε. Δείτε διατάσεις γραφείου για προγραμματιστές.
  • Ένα προαιρετικό τμήμα στη γραμμή κατάστασης του Claude Code.

Απόρρητο

Το vibestretch είναι μερικά μικρά POSIX shell scripts και ένας ενσωματωμένος ήχος. Δεν κάνει κλήσεις δικτύου. Δεν στέλνει τηλεμετρία. Δεν δείχνει διαφημίσεις και δεν βάζει συνδέσμους στο τερματικό σας. Δεν προσθέτει τίποτα στο context του μοντέλου. Η κατάστασή του αποθηκεύεται στο ~/.cache/vibestretch/.

Συχνές ερωτήσεις

Τι είναι το vibestretch;
Το vibestretch είναι ένα plugin για AI agents προγραμματισμού. Σας θυμίζει να κάνετε διατάσεις, να κινηθείτε ή να ξεκουράσετε τα μάτια σας όσο ένας μεγάλος γύρος του agent σάς κρατά σε αναμονή.
Ποιους agents προγραμματισμού υποστηρίζει;
Claude Code, OpenAI Codex CLI και Gemini CLI. Και οι τρεις χρησιμοποιούν τον ίδιο μετρητή, οπότε μια ώρα αναμονής μετράει μία φορά, όποιος agent κι αν σας κράτησε στην καρέκλα.
Είναι χρονόμετρο διαλειμμάτων;
Όχι. Ένα χρονόμετρο λειτουργεί με πρόγραμμα. Το vibestretch μετράει μόνο τον χρόνο που ένας γύρος του agent σάς κράτησε σε αναμονή και υπενθυμίζει μόνο κατά τη διάρκεια αυτής της αναμονής.
Στέλνει δεδομένα κάπου;
Όχι. Δεν κάνει κλήσεις δικτύου και δεν στέλνει τηλεμετρία. Τίποτα δεν φεύγει από τον υπολογιστή σας.
Πόσο κοστίζει;
Είναι δωρεάν. Το vibestretch είναι ανοιχτού κώδικα με άδεια MIT και ο κώδικας βρίσκεται στο GitHub.
Πώς το βάζω σε σίγαση;
Ορίστε το VIBESTRETCH_DISABLE σε οποιαδήποτε τιμή για να σταματήσουν οι υπενθυμίσεις. Το VIBESTRETCH_SOUND=0 κλείνει τον ήχο. Το VIBESTRETCH_NOTIFY=0 αφαιρεί την ειδοποίηση.
