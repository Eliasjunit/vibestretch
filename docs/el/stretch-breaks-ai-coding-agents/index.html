Διαλείμματα για διατάσεις όσο τρέχουν οι AI agents προγραμματισμού

Ένας AI agent προγραμματισμού μπορεί να δουλεύει για αρκετά λεπτά. Εσείς κάθεστε και κοιτάτε. Το vibestretch κάνει αυτή την αναμονή ένα σύντομο διάλειμμα.

Γιατί η αναμονή είναι καλή στιγμή

Τα χρονόμετρα διαλειμμάτων λειτουργούν με πρόγραμμα. Συχνά πέφτουν στη μέση μιας σκέψης και πολλοί καταλήγουν να τα απενεργοποιούν. Ο χρόνος που ο agent είναι απασχολημένος είναι διαφορετικός. Περιμένετε ούτως ή άλλως. Μια διάταση σε αυτό το κενό δεν σας κοστίζει συγκέντρωση.

Τι μετράει το vibestretch

Μετράει τον χρόνο agent: τα λεπτά που έτρεχε ένας γύρος του agent ενώ ήσασταν στον υπολογιστή. Τα αθροίζει από την τελευταία υπενθύμιση. Αυτό δεν είναι το πόση ώρα κάθεστε στο γραφείο. Μια ώρα διαβάσματος και πληκτρολόγησης με γρήγορους γύρους ενδιάμεσα δεν προσθέτει σχεδόν τίποτα.

Πότε εμφανίζεται μια υπενθύμιση

Πρέπει να ισχύουν και οι τρεις συνθήκες:

  1. Ο τρέχων γύρος τρέχει τουλάχιστον 2 λεπτά.
  2. Ο χρόνος agent από την τελευταία υπενθύμιση είναι τουλάχιστον 5 λεπτά. Μετράει είτε μία μεγάλη εργασία είτε αρκετές μεσαίες.
  3. Η τελευταία υπενθύμιση ήταν πριν από τουλάχιστον 15 λεπτά.

Μπορείτε να αλλάξετε κάθε αριθμό με μια μεταβλητή περιβάλλοντος. Δείτε τη σελίδα του Claude Code για την πλήρη λίστα.

Όταν απομακρύνεστε

Αν λείψετε από το πληκτρολόγιο 45 λεπτά ή περισσότερο, το χρέος μηδενίζεται. Το διάλειμμά σας το κάνατε ήδη. Στο macOS τα hooks διαβάζουν το ρολόι αδράνειας πληκτρολογίου και ποντικιού του συστήματος. Έτσι ένας agent που δουλεύει όλη τη νύχτα δεν προσθέτει χρόνο agent και δεν χτυπά ποτέ για μια άδεια καρέκλα. Το Linux δεν έχει φορητό ρολόι αδράνειας, οπότε εκεί ισχύει μόνο ο μηδενισμός των 45 λεπτών.

Τι σας ζητά η υπενθύμιση

Κάθε υπενθύμιση είναι μία άσκηση από μια λίστα δώδεκα. Καλύπτουν διατάσεις, μικρές ασκήσεις και διαλείμματα για τα μάτια. Δείτε διατάσεις γραφείου για προγραμματιστές για όλη τη λίστα.

Συχνές ερωτήσεις

Θα με ειδοποιεί σε σύντομους γύρους;
Όχι. Ένας γύρος πρέπει να τρέξει τουλάχιστον 2 λεπτά και πρέπει να μαζευτεί αρκετός χρόνος agent πριν εμφανιστεί υπενθύμιση.
Ένα γρήγορο μοντέλο σημαίνει λιγότερες υπενθυμίσεις;
Ναι. Τα γρήγορα μοντέλα τελειώνουν τους γύρους πριν φτάσουν τα όρια, οπότε δεν υπάρχει τίποτα για σίγαση.
Τι γίνεται με agents που τρέχουν από scripts ή cron;
Ορίστε VIBESTRETCH_DISABLE=1 σε εκείνο το περιβάλλον. Αλλιώς οι συνεδρίες χωρίς επίβλεψη μετράνε ως χρόνος που δεν περάσατε ποτέ περιμένοντας.
