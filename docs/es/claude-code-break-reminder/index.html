Cómo añadir un recordatorio de pausas a Claude Code

vibestretch es un plugin de Claude Code. Usa tres hooks para detectar los turnos largos y recordarte que te muevas.

Instalación

Ejecuta estos dos comandos dentro de Claude Code:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

No tiene dependencias, ni daemon, ni telemetría. No hay nada más que configurar.

Dónde aparece el aviso

  • Una línea en la sesión.
  • Un tono suave incluido.
  • Una notificación en Warp, Ghostty, iTerm2, WezTerm y kitty. En VS Code necesita una extensión de notificaciones.
  • Tu línea de estado, si la configuras.

Añádelo a tu línea de estado

/vibestretch:statusline

Este comando hace una copia de seguridad de tus ajustes y envuelve el comando de línea de estado que ya tengas. Si no tienes ninguno, instala uno mínimo. Después de un aviso, el ejercicio se queda ahí 5 minutos. Para deshacerlo, usa /vibestretch:statusline off. Ejecuta off antes de desinstalar el plugin.

VS Code

En el terminal integrado funcionan la línea, el tono y la línea de estado. En el panel de chat de la extensión solo te llega el tono. La notificación necesita una extensión de notificaciones en ambos casos. Esto se comprobó en Claude Code 2.1.234.

Ajustes

Todos los ajustes son variables de entorno opcionales. Los tiempos van en segundos.

VariableValor por defectoSignificado
VIBESTRETCH_MIN_TURN120El turno actual debe durar al menos este tiempo.
VIBESTRETCH_MIN_ACTIVE300Tiempo de agente necesario desde tu última pausa.
VIBESTRETCH_COOLDOWN900Intervalo mínimo entre avisos.
VIBESTRETCH_AWAY300Sin teclado ni ratón durante este tiempo, se considera que te has ido. Solo macOS. 0 desactiva esta comprobación.
VIBESTRETCH_DISABLEunsetAsigna cualquier valor para silenciar los avisos.
VIBESTRETCH_NOTIFY1Pon 0 para quitar la notificación de escritorio.
VIBESTRETCH_SOUND1Pon 0 para silenciar el sonido.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtRuta a tu propia lista de ejercicios.

¿Ejecutas Claude Code sin interfaz con claude -p desde un script? Define VIBESTRETCH_DISABLE=1 allí.

Preguntas frecuentes

¿Cómo quito el segmento de la línea de estado?
Ejecuta /vibestretch:statusline off. Hazlo antes de desinstalar el plugin, o el segmento seguirá configurado pero congelado.
¿El aviso llega al modelo?
No. El aviso es un systemMessage. Se te muestra a ti y nunca se añade al contexto del modelo.
¿Por qué oigo dos sonidos?
Algunos terminales, como iTerm2, reproducen su propio sonido con las notificaciones. Define VIBESTRETCH_SOUND=0 para quedarte solo con el sonido del terminal.
