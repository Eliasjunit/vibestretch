Cómo añadir un recordatorio de pausas a Gemini CLI

Gemini CLI trae los hooks activados desde la v0.26. vibestretch añade tres para recordarte que te estires durante los turnos largos.

Instalación

Clona el repositorio:

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

Después copia el objeto hooks de ~/.gemini/vibestretch/hooks/gemini-hooks.json en ~/.gemini/settings.json. Ese archivo contiene toda tu configuración de Gemini, así que combínalo. No lo reemplaces. Con jq basta una línea:

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

Si ya tienes hooks propios en BeforeAgent, AfterTool o AfterAgent, este comando los sustituye por los nuestros. En ese caso añade nuestras tres entradas a tus listas a mano.

Qué hooks usa

  • BeforeAgent: el agente empieza a trabajar en tu prompt.
  • AfterTool: una herramienta terminó. Se suma el tiempo de espera y salta un aviso si toca.
  • AfterAgent: el turno terminó. Se cierra la cuenta.

Qué obtienes en Gemini CLI

Obtienes la línea en la sesión y el tono. No hay notificación. Gemini reserva la salida estándar de un hook solo para JSON, así que no hay dónde imprimir una secuencia de escape.

El adaptador se probó en una instalación real de Gemini CLI 0.56.0 en macOS. El contador se comparte con Claude Code y Codex CLI.

Preguntas frecuentes

¿Qué versión de Gemini CLI necesito?
Los hooks vienen activados desde Gemini CLI v0.26.
¿La combinación sobrescribirá mis ajustes?
Tus demás ajustes se conservan. Si ya tienes hooks propios en BeforeAgent, AfterTool o AfterAgent, jq sustituye esas listas por las nuestras. En ese caso añade nuestras tres entradas a mano. Haz antes una copia de seguridad del archivo.
¿Puedo usarlo con gemini -p?
Define VIBESTRETCH_DISABLE=1 cuando ejecutes Gemini desde un script, cron o un bot.
