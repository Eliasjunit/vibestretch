Näin lisäät taukomuistutuksen Claude Codeen

vibestretch on Claude Code -lisäosa. Se huomaa pitkät vuorot kolmen hookin avulla ja muistuttaa sinua liikkumaan.

Asennus

Suorita nämä kaksi komentoa Claude Codessa:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

Riippuvuuksia, taustaprosessia tai telemetriaa ei ole. Muuta määritettävää ei ole.

Missä muistutus näkyy

  • Rivinä istunnossa.
  • Pehmeänä merkkiäänenä, joka tulee lisäosan mukana.
  • Ilmoitusbannerina päätteissä Warp, Ghostty, iTerm2, WezTerm ja kitty. VS Codessa se vaatii ilmoituslaajennuksen.
  • Tilarivilläsi, jos otat sen käyttöön.

Lisää se tilariville

/vibestretch:statusline

Tämä komento varmuuskopioi asetuksesi ja käärii nykyisen tilarivikomentosi. Jos sinulla ei ole sellaista, se asentaa yksinkertaisen. Muistutuksen jälkeen harjoitus pysyy näkyvissä 5 minuuttia. Kumoa se komennolla /vibestretch:statusline off. Suorita off ennen kuin poistat lisäosan.

VS Code

Integroidussa päätteessä rivi, merkkiääni ja tilarivi toimivat kaikki. Laajennuksen chat-paneelissa sinulle asti tulee vain merkkiääni. Banneri vaatii ilmoituslaajennuksen molemmissa. Tämä on tarkistettu Claude Coden versiolla 2.1.234.

Asetukset

Kaikki asetukset ovat valinnaisia ympäristömuuttujia. Ajat ovat sekunteina.

MuuttujaOletusMerkitys
VIBESTRETCH_MIN_TURN120Nykyisen vuoron on kestettävä vähintään näin kauan.
VIBESTRETCH_MIN_ACTIVE300Tarvittava agenttiaika edellisen tauon jälkeen.
VIBESTRETCH_COOLDOWN900Muistutusten välinen vähimmäisaika.
VIBESTRETCH_AWAY300Jos näppäimistöä tai hiirtä ei käytetä näin pitkään aikaan, olet poissa. Vain macOS. 0 kytkee tarkistuksen pois.
VIBESTRETCH_DISABLEunsetAseta mihin tahansa arvoon, niin muistutukset mykistyvät.
VIBESTRETCH_NOTIFY1Aseta arvoon 0, niin työpöytäilmoitus jää pois.
VIBESTRETCH_SOUND1Aseta arvoon 0, niin ääni mykistyy.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtPolku omaan harjoituslistaasi.

Ajatko Claude Codea ilman käyttöliittymää komennolla claude -p skriptistä? Aseta siellä VIBESTRETCH_DISABLE=1.

Usein kysyttyä

Miten poistan tilarivin osion?
Suorita /vibestretch:statusline off. Tee tämä ennen kuin poistat lisäosan, muuten osio jää määritetyksi mutta jumiin.
Päätyykö muistutus mallille?
Ei. Muistutus on systemMessage. Se näytetään sinulle, eikä sitä koskaan lisätä mallin kontekstiin.
Miksi kuulen kaksi ääntä?
Jotkin päätteet, kuten iTerm2, soittavat ilmoituksille oman äänensä. Aseta VIBESTRETCH_SOUND=0, niin kuuluu vain päätteen ääni.
