Näin lisäät taukomuistutuksen Codex CLI:hin

vibestretch asennetaan OpenAI Codex CLI:hin lisäosien markkinapaikalta. Se näyttää venyttelyrivin ja soittaa merkkiäänen pitkien vuorojen aikana.

Asennus lisäosana

codex plugin marketplace add Eliasjunit/vibestretch
codex plugin add vibestretch@vibestretch

Codex ei aja lisäosan hookeja ennen kuin olet tarkistanut ne. Avaa /hooks ja merkitse kolme vibestretch-merkintää luotetuiksi. Siihen asti lisäosa on asennettu mutta hiljaa.

Asennus käsin

Kloonaus ja asetustiedosto hoitavat saman asian:

git clone https://github.com/Eliasjunit/vibestretch ~/.codex/vibestretch
cp ~/.codex/vibestretch/hooks/codex-hooks.json ~/.codex/hooks.json

Onko sinulla jo ~/.codex/hooks.json? Yhdistä siihen meidän tiedostomme kolme merkintää. Älä korvaa omaasi. Codex pyytää luottamaan uuteen hook-määritykseen, kun se ajetaan ensimmäisen kerran. Kehote on odotettu.

Valitse yksi tapa. Jos sekä lisäosa että käsin tehdyt merkinnät ovat käytössä, jokainen hook ajetaan kahdesti. Jos asensit käsin ennen versiota 0.8.0, poista merkintämme tiedostosta ~/.codex/hooks.json, kun siirryt lisäosaan.

Mitä saat Codexissa

Saat rivin istuntoon ja merkkiäänen. Ilmoitusbanneria ei ole, koska Codexissa ei ole hookin tulostekenttää päätteen ohjaussekvenssille. Tilarivin osiotakaan ei ole. Sitä palkkia ei voi skriptata Codexissa.

Laskuri on yhteinen Claude Coden ja Gemini CLI:n kanssa. Tunnin odotus lasketaan kerran, piti sinua tuolissa mikä agentti tahansa. Sovitinta ajettiin oikeassa Codex CLI 0.149.1 -asennuksessa macOS:llä.

Usein kysyttyä

Asensin sen, mutta mitään ei tapahdu. Miksi?
Codex ajaa lisäosan hookit vasta, kun olet merkinnyt ne luotetuiksi. Avaa /hooks ja luota kolmeen vibestretch-merkintään.
Jokainen hook ajetaan kahdesti. Miksi?
Sinulla on todennäköisesti sekä lisäosa että käsin tehdyt merkinnät tiedostossa ~/.codex/hooks.json. Pidä niistä vain toinen.
Voinko käyttää sitä codex exec -komennon kanssa?
Aseta siinä ympäristössä VIBESTRETCH_DISABLE=1. Valvomattomia ajoja ei pidä laskea ajaksi, jonka istuit läpi.
