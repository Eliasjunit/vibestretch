Näin lisäät taukomuistutuksen Gemini CLI:hin

Gemini CLI:ssä hookit ovat olleet oletuksena käytössä versiosta v0.26 lähtien. vibestretch lisää niistä kolme ja muistuttaa venyttelemään pitkien vuorojen aikana.

Asennus

Kloonaa repositorio:

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

Kopioi sitten hooks-objekti tiedostosta ~/.gemini/vibestretch/hooks/gemini-hooks.json tiedostoon ~/.gemini/settings.json. Siinä tiedostossa on koko Gemini-määrityksesi, joten yhdistä se. Älä korvaa sitä. Työkalulla jq se onnistuu yhdellä rivillä:

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

Jos sinulla on jo omia hookeja kohdissa BeforeAgent, AfterTool tai AfterAgent, tämä komento korvaa ne meidän hookeillamme. Lisää silloin kolme merkintäämme listoihisi käsin.

Mitä hookeja se käyttää

  • BeforeAgent: agentti alkaa työstää kehotettasi.
  • AfterTool: työkalu valmistui. Odotusaika lisätään, ja muistutus tulee, jos sen aika on.
  • AfterAgent: vuoro on ohi. Kirjanpito suljetaan.

Mitä saat Gemini CLI:ssä

Saat rivin istuntoon ja merkkiäänen. Ilmoitusbanneria ei ole. Gemini varaa hookin stdoutin pelkälle JSONille, joten ohjaussekvenssiä ei voi tulostaa mihinkään.

Sovitinta ajettiin oikeassa Gemini CLI 0.56.0 -asennuksessa macOS:llä. Laskuri on yhteinen Claude Coden ja Codex CLI:n kanssa.

Usein kysyttyä

Mikä Gemini CLI -versio tarvitaan?
Hookit ovat olleet oletuksena käytössä Gemini CLI:n versiosta v0.26 lähtien.
Korvaako yhdistäminen asetukseni?
Muut asetuksesi säilyvät. Jos sinulla on jo omia BeforeAgent-, AfterTool- tai AfterAgent-hookeja, jq korvaa ne listat meidän listoillamme. Lisää silloin kolme merkintäämme käsin. Ota tiedostosta ensin varmuuskopio.
Voinko käyttää sitä gemini -p -komennon kanssa?
Aseta VIBESTRETCH_DISABLE=1, kun ajat Geminiä skriptistä, cronista tai botista.
