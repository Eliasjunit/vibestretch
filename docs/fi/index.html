Venyttele, kun koodausagenttisi työskentelee

vibestretch näyttää lyhyen venyttelyn, minitreenin tai silmätauon, kun pitkä agentin vuoro pitää sinut odottamassa. Se toimii Claude Coden, Codex CLI:n ja Gemini CLI:n kanssa.

claude plugin marketplace add Eliasjunit/vibestretch && claude plugin install vibestretch@vibestretch

Tämä asentaa lisäosan Claude Codeen. Codex CLI:n ja Gemini CLI:n sivuilla on niiden asennusohjeet.

Miltä muistutus näyttää

🧘 Wrist circles, 10 each way. Your tendons will thank you. · vibestretch · 7 min of agent time

Istuntoon ilmestyy yksi rivi. Kuuluu pehmeä merkkiääni. Päätteissä, jotka tukevat sitä, näkyy myös ilmoitusbanneri.

Miten se päättää, milloin muistuttaa

vibestretchillä ei ole aikataulua. Se laskee yhtä asiaa: minuutteja, jotka agentin vuoro piti sinut odottamassa koneen ääressä. Muistutus tulee vain, kun kaikki kolme ehtoa täyttyvät:

  1. Nykyinen vuoro on kestänyt vähintään 2 minuuttia.
  2. Agenttiaikaa on kertynyt edellisen muistutuksen jälkeen yhteensä vähintään 5 minuuttia.
  3. Edellisestä muistutuksesta on kulunut vähintään 15 minuuttia.

Nopeat vuorot eivät koskaan laukaise sitä. Lyhyiden vuorojen päivänä se pysyy täysin hiljaa. Torkuttavaa ei ole, koska se puhuu vain silloin, kun odotat jo valmiiksi. Lue lisää: venyttelytauot AI-koodausagenttien työskennellessä.

Mitä saat

  • Kaksitoista valmista harjoitusta: venyttelyjä, minitreenejä ja silmätaukoja, kuten 20-20-20.
  • Kierto, joka ei koskaan toista samaa harjoitusta kahdesti peräkkäin.
  • Halutessasi oma harjoituslista. Katso taukojumppa ohjelmoijille.
  • Valinnainen tilarivin osio Claude Codessa.

Yksityisyys

vibestretch koostuu muutamasta pienestä POSIX-shell-skriptistä ja yhdestä mukana tulevasta äänestä. Se ei ota verkkoyhteyksiä. Se ei lähetä telemetriaa. Se ei näytä mainoksia eikä lisää linkkejä päätteeseesi. Se ei lisää mitään mallin kontekstiin. Sen tila on hakemistossa ~/.cache/vibestretch/.

Usein kysyttyä

Mikä vibestretch on?
vibestretch on lisäosa koodausagenteille. Se muistuttaa venyttelemään, liikkumaan tai lepuuttamaan silmiä, kun pitkä agentin vuoro pitää sinut odottamassa.
Mitä koodausagentteja se tukee?
Claude Code, OpenAI Codex CLI ja Gemini CLI. Kaikki kolme käyttävät samaa laskuria, joten tunnin odotus lasketaan kerran, piti sinua tuolissa mikä agentti tahansa.
Onko se taukoajastin?
Ei. Ajastin toimii aikataulun mukaan. vibestretch laskee vain ajan, jonka agentin vuoro piti sinut odottamassa, ja muistuttaa vain tuon odotuksen aikana.
Lähettääkö se tietoja minnekään?
Ei. Se ei ota verkkoyhteyksiä eikä lähetä telemetriaa. Mikään ei lähde koneeltasi.
Paljonko se maksaa?
Se on ilmainen. vibestretch on avointa lähdekoodia MIT-lisenssillä, ja koodi on GitHubissa.
Miten mykistän sen?
Aseta VIBESTRETCH_DISABLE mihin tahansa arvoon, niin muistutukset mykistyvät. VIBESTRETCH_SOUND=0 mykistää äänen. VIBESTRETCH_NOTIFY=0 poistaa bannerin.
