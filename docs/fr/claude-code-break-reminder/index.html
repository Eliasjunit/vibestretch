Comment ajouter un rappel de pause à Claude Code

vibestretch est un plugin Claude Code. Il utilise trois hooks pour repérer les longs tours et vous inviter à bouger.

Installation

Lancez ces deux commandes dans Claude Code :

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

Aucune dépendance, aucun daemon, aucune télémétrie. Il n'y a rien d'autre à configurer.

Où le rappel apparaît

  • Une ligne dans la session.
  • Un son discret fourni.
  • Une notification dans Warp, Ghostty, iTerm2, WezTerm et kitty. Dans VS Code, il faut une extension de notifications.
  • Votre ligne d'état, si vous la configurez.

L'ajouter à votre ligne d'état

/vibestretch:statusline

Cette commande sauvegarde vos réglages et englobe votre commande de ligne d'état existante. Si vous n'en avez pas, elle en installe une minimale. Après un rappel, l'exercice reste affiché 5 minutes. Pour annuler, utilisez /vibestretch:statusline off. Lancez off avant de désinstaller le plugin.

VS Code

Dans le terminal intégré, la ligne, le son et la ligne d'état fonctionnent. Dans le panneau de chat de l'extension, seul le son vous parvient. La notification nécessite une extension de notifications dans les deux cas. Vérifié sur Claude Code 2.1.234.

Réglages

Tous les réglages sont des variables d'environnement facultatives. Les durées sont en secondes.

VariablePar défautSignification
VIBESTRETCH_MIN_TURN120Le tour en cours doit durer au moins ce temps.
VIBESTRETCH_MIN_ACTIVE300Temps d'agent nécessaire depuis votre dernière pause.
VIBESTRETCH_COOLDOWN900Délai minimum entre deux rappels.
VIBESTRETCH_AWAY300Sans clavier ni souris pendant cette durée, vous êtes considéré comme absent. macOS uniquement. 0 désactive cette protection.
VIBESTRETCH_DISABLEunsetDonnez-lui n'importe quelle valeur pour couper les rappels.
VIBESTRETCH_NOTIFY1Mettez 0 pour supprimer la notification de bureau.
VIBESTRETCH_SOUND1Mettez 0 pour couper le son.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtChemin vers votre propre liste d'exercices.

Vous lancez Claude Code en mode headless avec claude -p depuis un script ? Définissez VIBESTRETCH_DISABLE=1 à cet endroit.

Questions fréquentes

Comment retirer le segment de la ligne d'état ?
Lancez /vibestretch:statusline off. Faites-le avant de désinstaller le plugin, sinon le segment reste configuré mais figé.
Le rappel est-il transmis au modèle ?
Non. Le rappel est un systemMessage. Il s'affiche pour vous et n'est jamais ajouté au contexte du modèle.
Pourquoi est-ce que j'entends deux sons ?
Certains terminaux, comme iTerm2, jouent leur propre son pour les notifications. Définissez VIBESTRETCH_SOUND=0 pour ne garder que le son du terminal.
