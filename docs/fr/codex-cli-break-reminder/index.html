Comment ajouter un rappel de pause à Codex CLI

vibestretch s'installe dans OpenAI Codex CLI depuis la marketplace de plugins. Il affiche une ligne d'étirement et joue un son pendant les longs tours.

Installer en plugin

codex plugin marketplace add Eliasjunit/vibestretch
codex plugin add vibestretch@vibestretch

Codex n'exécute pas les hooks d'un plugin tant que vous ne les avez pas examinés. Ouvrez /hooks et approuvez les trois entrées vibestretch. D'ici là, le plugin est installé mais reste muet.

Installer à la main

Un clone et un fichier de configuration font le même travail :

git clone https://github.com/Eliasjunit/vibestretch ~/.codex/vibestretch
cp ~/.codex/vibestretch/hooks/codex-hooks.json ~/.codex/hooks.json

Vous avez déjà un ~/.codex/hooks.json ? Fusionnez-y les trois entrées du nôtre. N'écrasez pas le vôtre. Codex vous demande d'approuver une nouvelle configuration de hooks lors de sa première exécution. Cette demande est normale.

Choisissez une seule méthode. Avec le plugin et les entrées manuelles en même temps, chaque hook s'exécute deux fois. Si vous avez fait l'installation manuelle avant la 0.8.0, retirez nos entrées de ~/.codex/hooks.json en passant au plugin.

Ce que vous obtenez dans Codex

Vous obtenez la ligne dans la session et le son. Il n'y a pas de notification, car Codex n'a pas de champ de sortie de hook pour une séquence de terminal. Il n'y a pas non plus de segment dans la ligne d'état. Cette barre n'est pas scriptable dans Codex.

Le compteur est partagé avec Claude Code et Gemini CLI. Une heure d'attente compte une seule fois, quel que soit l'agent qui vous a gardé sur votre chaise. L'adaptateur a été testé sur une installation réelle de Codex CLI 0.149.1 sous macOS.

Questions fréquentes

Je l'ai installé, mais rien ne se passe. Pourquoi ?
Codex n'exécute les hooks d'un plugin qu'après votre approbation. Ouvrez /hooks et approuvez les trois entrées vibestretch.
Chaque hook s'exécute deux fois. Pourquoi ?
Vous avez sans doute à la fois le plugin et des entrées manuelles dans ~/.codex/hooks.json. Gardez l'un des deux.
Puis-je l'utiliser avec codex exec ?
Définissez VIBESTRETCH_DISABLE=1 dans cet environnement. Les exécutions sans surveillance ne devraient pas compter comme du temps passé à attendre.
