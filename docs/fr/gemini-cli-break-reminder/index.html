Comment ajouter un rappel de pause à Gemini CLI

Gemini CLI active les hooks par défaut depuis la v0.26. vibestretch en ajoute trois pour vous rappeler de vous étirer pendant les longs tours.

Installation

Clonez le dépôt :

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

Copiez ensuite l'objet hooks de ~/.gemini/vibestretch/hooks/gemini-hooks.json dans ~/.gemini/settings.json. Ce fichier contient toute votre configuration Gemini, alors fusionnez. Ne le remplacez pas. Avec jq, une seule ligne suffit :

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

Les hooks utilisés

  • BeforeAgent : l'agent commence à travailler sur votre prompt.
  • AfterTool : un outil a terminé. Le temps d'attente est ajouté, et un rappel se déclenche s'il est dû.
  • AfterAgent : le tour est terminé. Le décompte est clôturé.

Ce que vous obtenez dans Gemini CLI

Vous obtenez la ligne dans la session et le son. Il n'y a pas de notification. Gemini réserve la sortie standard d'un hook au JSON uniquement, donc il n'y a nulle part où écrire une séquence d'échappement.

L'adaptateur a été testé sur une installation réelle de Gemini CLI 0.56.0 sous macOS. Le compteur est partagé avec Claude Code et Codex CLI.

Questions fréquentes

Quelle version de Gemini CLI me faut-il ?
Les hooks sont activés par défaut depuis Gemini CLI v0.26.
La fusion va-t-elle écraser mes réglages ?
La commande jq fusionne l'objet hooks dans votre settings.json existant. Par précaution, sauvegardez le fichier avant.
Puis-je l'utiliser avec gemini -p ?
Définissez VIBESTRETCH_DISABLE=1 quand vous lancez Gemini depuis un script, cron ou un bot.
