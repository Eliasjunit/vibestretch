Étirez-vous pendant que votre agent de code travaille

vibestretch affiche un étirement court, un mini exercice ou une pause pour les yeux quand un long tour de l'agent vous fait attendre. Il fonctionne avec Claude Code, Codex CLI et Gemini CLI.

claude plugin marketplace add Eliasjunit/vibestretch && claude plugin install vibestretch@vibestretch

Cette commande installe le plugin dans Claude Code. Les pages Codex CLI et Gemini CLI décrivent leur installation.

À quoi ressemble un rappel

🧘 Wrist circles, 10 each way. Your tendons will thank you. · vibestretch · 7 min of agent time

Une ligne apparaît dans la session. Un son discret retentit. Dans les terminaux compatibles, une notification s'affiche aussi.

Comment il décide du moment

vibestretch n'a pas d'horaire. Il compte une seule chose : les minutes pendant lesquelles un tour de l'agent vous a fait attendre devant la machine. Un rappel ne se déclenche que si les trois conditions sont réunies :

  1. Le tour en cours dure depuis 2 minutes ou plus.
  2. Votre temps d'agent depuis le dernier rappel atteint 5 minutes ou plus.
  3. Le dernier rappel date d'au moins 15 minutes.

Les tours rapides ne le déclenchent jamais. Une journée de tours courts ne produit aucun rappel. Il n'y a rien à reporter, car il ne parle que lorsque vous attendez déjà. Pour en savoir plus : pauses étirements pendant que les agents IA travaillent.

Ce qui est inclus

  • Douze exercices intégrés : étirements, mini exercices et pauses pour les yeux comme la règle 20-20-20.
  • Une rotation qui ne propose jamais deux fois de suite le même exercice.
  • Votre propre liste d'exercices, si vous préférez. Voir étirements au bureau pour développeurs.
  • Un segment facultatif dans la ligne d'état de Claude Code.

Confidentialité

vibestretch se compose de quelques petits scripts shell POSIX et d'un son fourni. Il ne fait aucun appel réseau. Il n'envoie aucune télémétrie. Il n'affiche aucune publicité et ne met aucun lien dans votre terminal. Il n'ajoute rien au contexte du modèle. Son état est stocké dans ~/.cache/vibestretch/.

Questions fréquentes

Qu'est-ce que vibestretch ?
vibestretch est un plugin pour agents de code. Il vous rappelle de vous étirer, de bouger ou de reposer vos yeux quand un long tour de l'agent vous fait attendre.
Quels agents de code sont pris en charge ?
Claude Code, OpenAI Codex CLI et Gemini CLI. Les trois partagent le même compteur : une heure d'attente compte une seule fois, quel que soit l'agent qui vous a gardé sur votre chaise.
Est-ce un minuteur de pauses ?
Non. Un minuteur suit un horaire. vibestretch compte uniquement le temps pendant lequel un tour de l'agent vous a fait attendre, et il ne vous prévient que pendant cette attente.
Envoie-t-il des données quelque part ?
Non. Il ne fait aucun appel réseau et n'envoie aucune télémétrie. Rien ne quitte votre machine.
Combien ça coûte ?
Il est gratuit. vibestretch est open source sous licence MIT, et le code est sur GitHub.
Comment le rendre muet ?
Donnez n'importe quelle valeur à VIBESTRETCH_DISABLE pour couper les rappels. VIBESTRETCH_SOUND=0 coupe le son. VIBESTRETCH_NOTIFY=0 supprime la notification.
