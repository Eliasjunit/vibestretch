How to add a break reminder to Gemini CLI

Gemini CLI has shipped hooks enabled since v0.26. vibestretch adds three of them to remind you to stretch during long turns.

Install

Clone the repository:

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

Then copy the hooks object from ~/.gemini/vibestretch/hooks/gemini-hooks.json into ~/.gemini/settings.json. That file holds your whole Gemini configuration, so merge it. Do not replace it. With jq it is one line:

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

If you already have your own BeforeAgent, AfterTool or AfterAgent hooks, this command replaces them with ours. In that case add our three entries to your lists by hand.

Which hooks it uses

  • BeforeAgent: the agent starts working on your prompt.
  • AfterTool: a tool finished. Wait time is added, and a nudge fires if one is due.
  • AfterAgent: the turn is over. The accounting closes.

What you get in Gemini CLI

You get the line in the session and the chime. There is no notification banner. Gemini reserves a hook's stdout for JSON alone, so there is nowhere to print an escape sequence.

The adapter was run on a live install of Gemini CLI 0.56.0 on macOS. The counter is shared with Claude Code and Codex CLI.

FAQ

Which Gemini CLI version do I need?
Hooks ship enabled since Gemini CLI v0.26.
Will the merge overwrite my settings?
It keeps your other settings. If you already have your own BeforeAgent, AfterTool or AfterAgent hooks, jq replaces those lists with ours. In that case add our three entries by hand. Back up the file first.
Can I use it with gemini -p?
Set VIBESTRETCH_DISABLE=1 when you run Gemini from a script, cron or a bot.
