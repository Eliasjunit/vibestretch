איך מוסיפים תזכורת להפסקה ל-Claude Code

vibestretch הוא תוסף ל-Claude Code. הוא משתמש בשלושה hooks כדי לזהות תורות ארוכים ולהזכיר לכם לזוז.

התקנה

הריצו את שתי הפקודות האלה בתוך Claude Code:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

אין תלויות, אין דמון ואין טלמטריה. אין שום דבר נוסף להגדיר.

איפה מופיעה התזכורת

  • שורה בסשן.
  • צליל עדין שמגיע עם התוסף.
  • התראה ב-Warp, Ghostty, iTerm2, WezTerm ו-kitty. ב-VS Code צריך לשם כך תוסף התראות.
  • שורת הסטטוס שלכם, אם הגדרתם אותה.

הוספה לשורת הסטטוס

/vibestretch:statusline

הפקודה הזו מגבה את ההגדרות שלכם ועוטפת את פקודת שורת הסטטוס הקיימת. אם אין לכם כזו, היא מתקינה שורה מינימלית. אחרי תזכורת, התרגיל נשאר שם 5 דקות. אפשר לבטל עם /vibestretch:statusline off. הריצו off לפני שאתם מסירים את התוסף.

VS Code

במסוף המשולב עובדים השורה, הצליל ושורת הסטטוס. בחלונית הצ'אט של התוסף רק הצליל מגיע אליכם. בשני המקומות ההתראה דורשת תוסף התראות. זה נבדק על Claude Code 2.1.234.

הגדרות

כל ההגדרות הן משתני סביבה אופציונליים. הזמנים בשניות.

משתנהברירת מחדלמשמעות
VIBESTRETCH_MIN_TURN120התור הנוכחי צריך לרוץ לפחות כל הזמן הזה.
VIBESTRETCH_MIN_ACTIVE300זמן הסוכן הנדרש מאז ההפסקה האחרונה.
VIBESTRETCH_COOLDOWN900הפער המינימלי בין תזכורות.
VIBESTRETCH_AWAY300אם המקלדת והעכבר לא היו בשימוש כל הזמן הזה, אתם נחשבים רחוקים. רק ב-macOS. 0 מכבה את הבדיקה.
VIBESTRETCH_DISABLEunsetהגדירו לערך כלשהו כדי להשתיק תזכורות.
VIBESTRETCH_NOTIFY1הגדירו ל-0 כדי לבטל את התראת שולחן העבודה.
VIBESTRETCH_SOUND1הגדירו ל-0 כדי להשתיק את הצליל.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtנתיב לרשימת התרגילים שלכם.

מריצים את Claude Code בלי ממשק עם claude -p מתוך סקריפט? הגדירו שם VIBESTRETCH_DISABLE=1.

שאלות נפוצות

איך מסירים את המקטע משורת הסטטוס?
הריצו /vibestretch:statusline off. עשו את זה לפני שאתם מסירים את התוסף, אחרת המקטע יישאר מוגדר אבל קפוא.
התזכורת מגיעה למודל?
לא. התזכורת היא systemMessage. היא מוצגת לכם ואף פעם לא נוספת להקשר של המודל.
למה אני שומע שני צלילים?
חלק מהמסופים, כמו iTerm2, משמיעים צליל משלהם להתראות. הגדירו VIBESTRETCH_SOUND=0 כדי להשאיר רק את הצליל של המסוף.
