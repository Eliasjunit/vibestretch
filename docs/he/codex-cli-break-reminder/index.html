איך מוסיפים תזכורת להפסקה ל-Codex CLI

vibestretch מותקן ב-OpenAI Codex CLI מחנות התוספים. הוא מציג שורת מתיחה ומשמיע צליל במהלך תורות ארוכים.

התקנה כתוסף

codex plugin marketplace add Eliasjunit/vibestretch
codex plugin add vibestretch@vibestretch

Codex לא מריץ hooks של תוסף עד שאתם בודקים אותם. פתחו את /hooks וסמנו כמהימנות את שלוש הרשומות של vibestretch. עד אז התוסף מותקן אבל שקט.

התקנה ידנית

שכפול של המאגר וקובץ הגדרות עושים את אותה עבודה:

git clone https://github.com/Eliasjunit/vibestretch ~/.codex/vibestretch
cp ~/.codex/vibestretch/hooks/codex-hooks.json ~/.codex/hooks.json

כבר יש לכם ~/.codex/hooks.json? מזגו לתוכו את שלוש הרשומות מהקובץ שלנו. אל תדרסו את הקובץ שלכם. בפעם הראשונה ש-Codex רץ עם הגדרת hooks חדשה, הוא מבקש מכם לאשר שהיא מהימנה. הבקשה הזו צפויה.

בחרו דרך אחת. אם גם התוסף וגם הרשומות הידניות קיימים, כל hook רץ פעמיים. אם התקנתם ידנית לפני 0.8.0, הסירו את הרשומות שלנו מ-~/.codex/hooks.json כשאתם עוברים לתוסף.

מה מקבלים ב-Codex

מקבלים את השורה בסשן ואת הצליל. אין התראה, כי ב-Codex אין שדה פלט של hook לרצף מסוף. גם אין מקטע בשורת הסטטוס. ב-Codex אי אפשר לתכנת את הסרגל הזה.

המונה משותף עם Claude Code ו-Gemini CLI. שעת המתנה נספרת פעם אחת, לא משנה איזה סוכן השאיר אתכם בכיסא. המתאם הורץ על התקנה חיה של Codex CLI 0.149.1 ב-macOS.

שאלות נפוצות

התקנתי, אבל שום דבר לא קורה. למה?
Codex מריץ hooks של תוסף רק אחרי שסימנתם אותם כמהימנים. פתחו את /hooks וסמנו כמהימנות את שלוש הרשומות של vibestretch.
כל hook רץ פעמיים. למה?
כנראה יש לכם גם את התוסף וגם רשומות ידניות ב-~/.codex/hooks.json. השאירו רק אחד מהשניים.
אפשר להשתמש בו עם codex exec?
הגדירו VIBESTRETCH_DISABLE=1 בסביבה הזו. ריצות ללא השגחה לא אמורות להיספר כזמן שישבתם מולו.
