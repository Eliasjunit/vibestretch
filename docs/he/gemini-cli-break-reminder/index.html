איך מוסיפים תזכורת להפסקה ל-Gemini CLI

ב-Gemini CLI ה-hooks מופעלים כברירת מחדל מאז v0.26. vibestretch מוסיף שלושה מהם כדי להזכיר לכם להתמתח במהלך תורות ארוכים.

התקנה

שכפלו את המאגר:

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

אחר כך העתיקו את האובייקט hooks מ-~/.gemini/vibestretch/hooks/gemini-hooks.json אל ~/.gemini/settings.json. הקובץ הזה מכיל את כל הגדרות Gemini שלכם, אז מזגו אותו. אל תחליפו אותו. עם jq זו שורה אחת:

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

אם כבר יש לכם hooks משלכם ב-BeforeAgent, ב-AfterTool או ב-AfterAgent, הפקודה הזו מחליפה אותם בשלנו. במקרה כזה הוסיפו את שלוש הרשומות שלנו לרשימות שלכם ידנית.

באילו hooks הוא משתמש

  • BeforeAgent: הסוכן מתחיל לעבוד על הפרומפט שלכם.
  • AfterTool: כלי סיים לרוץ. זמן ההמתנה מתווסף, ותזכורת מופיעה אם הגיע הזמן.
  • AfterAgent: התור הסתיים. הספירה נסגרת.

מה מקבלים ב-Gemini CLI

מקבלים את השורה בסשן ואת הצליל. אין התראה. Gemini שומר את ה-stdout של hook ל-JSON בלבד, כך שאין איפה להדפיס רצף escape.

המתאם הורץ על התקנה חיה של Gemini CLI 0.56.0 ב-macOS. המונה משותף עם Claude Code ו-Codex CLI.

שאלות נפוצות

איזו גרסה של Gemini CLI אני צריך?
ה-hooks מופעלים כברירת מחדל מאז Gemini CLI v0.26.
המיזוג ידרוס את ההגדרות שלי?
שאר ההגדרות שלכם נשמרות. אם כבר יש לכם hooks משלכם ב-BeforeAgent, ב-AfterTool או ב-AfterAgent, jq מחליף את הרשימות האלה ברשימות שלנו. במקרה כזה הוסיפו את שלוש הרשומות שלנו ידנית. גבו את הקובץ קודם.
אפשר להשתמש בו עם gemini -p?
הגדירו VIBESTRETCH_DISABLE=1 כשאתם מריצים את Gemini מסקריפט, מ-cron או מבוט.
