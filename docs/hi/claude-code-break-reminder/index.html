Claude Code में ब्रेक रिमाइंडर कैसे जोड़ें

vibestretch एक Claude Code प्लगइन है। यह लंबे टर्न पहचानने और आपको हिलने की याद दिलाने के लिए तीन हुक इस्तेमाल करता है।

इंस्टॉल

Claude Code के अंदर ये दो कमांड चलाएं:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

कोई डिपेंडेंसी नहीं, कोई डेमन नहीं और कोई टेलीमेट्री नहीं। और कुछ कॉन्फ़िगर करने की ज़रूरत नहीं।

रिमाइंडर कहां दिखता है

  • सेशन में एक लाइन।
  • बंडल की गई एक हल्की चाइम।
  • Warp, Ghostty, iTerm2, WezTerm और kitty में एक नोटिफ़िकेशन बैनर। VS Code में इसके लिए एक notifier एक्सटेंशन चाहिए।
  • आपकी स्टेटस लाइन, अगर आपने इसे सेट किया है।

इसे अपनी स्टेटस लाइन में जोड़ें

/vibestretch:statusline

यह कमांड आपकी सेटिंग्स का बैकअप लेता है और आपके मौजूदा स्टेटस लाइन कमांड को रैप करता है। अगर कोई नहीं है, तो यह एक सिंपल स्टेटस लाइन इंस्टॉल करता है। रिमाइंडर के बाद एक्सरसाइज़ 5 मिनट तक वहां दिखती है। इसे /vibestretch:statusline off से हटाएं। प्लगइन अनइंस्टॉल करने से पहले off चलाएं।

VS Code

इंटीग्रेटेड टर्मिनल में लाइन, चाइम और स्टेटस लाइन तीनों काम करते हैं। एक्सटेंशन के चैट पैनल में सिर्फ़ चाइम आप तक पहुंचती है। दोनों जगह बैनर के लिए notifier एक्सटेंशन चाहिए। इसे Claude Code 2.1.234 पर जांचा गया था।

सेटिंग्स

सभी सेटिंग्स वैकल्पिक एनवायरनमेंट वेरिएबल हैं। समय सेकंड में है।

वेरिएबलडिफ़ॉल्टमतलब
VIBESTRETCH_MIN_TURN120मौजूदा टर्न कम से कम इतनी देर चलना चाहिए।
VIBESTRETCH_MIN_ACTIVE300पिछले ब्रेक के बाद से ज़रूरी एजेंट टाइम।
VIBESTRETCH_COOLDOWN900दो रिमाइंडर के बीच कम से कम अंतर।
VIBESTRETCH_AWAY300इतनी देर कीबोर्ड या माउस न चले, तो माना जाता है कि आप दूर हैं। सिर्फ़ macOS। 0 से यह जांच बंद होती है।
VIBESTRETCH_DISABLEunsetरिमाइंडर म्यूट करने के लिए कोई भी वैल्यू सेट करें।
VIBESTRETCH_NOTIFY1डेस्कटॉप नोटिफ़िकेशन हटाने के लिए 0 सेट करें।
VIBESTRETCH_SOUND1साउंड म्यूट करने के लिए 0 सेट करें।
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtआपकी अपनी एक्सरसाइज़ लिस्ट का पाथ।

किसी स्क्रिप्ट से claude -p के साथ Claude Code headless चला रहे हैं? वहां VIBESTRETCH_DISABLE=1 सेट करें।

अक्सर पूछे जाने वाले सवाल

स्टेटस लाइन सेगमेंट कैसे हटाएं?
/vibestretch:statusline off चलाएं। प्लगइन अनइंस्टॉल करने से पहले ऐसा करें, वरना सेगमेंट कॉन्फ़िगर रहेगा लेकिन अटका रहेगा।
क्या रिमाइंडर मॉडल तक पहुंचता है?
नहीं। रिमाइंडर एक systemMessage है। यह आपको दिखाया जाता है और कभी मॉडल के कॉन्टेक्स्ट में नहीं जोड़ा जाता।
मुझे दो आवाज़ें क्यों सुनाई देती हैं?
कुछ टर्मिनल, जैसे iTerm2, नोटिफ़िकेशन के लिए अपनी आवाज़ बजाते हैं। सिर्फ़ टर्मिनल की आवाज़ रखने के लिए VIBESTRETCH_SOUND=0 सेट करें।
