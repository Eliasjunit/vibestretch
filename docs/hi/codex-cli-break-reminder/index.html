Codex CLI में ब्रेक रिमाइंडर कैसे जोड़ें

vibestretch को OpenAI Codex CLI में प्लगइन मार्केटप्लेस से इंस्टॉल किया जाता है। यह लंबे टर्न के दौरान एक स्ट्रेच लाइन दिखाता है और चाइम बजाता है।

प्लगइन के रूप में इंस्टॉल करें

codex plugin marketplace add Eliasjunit/vibestretch
codex plugin add vibestretch@vibestretch

जब तक आप किसी प्लगइन के हुक रिव्यू नहीं करते, Codex उन्हें नहीं चलाता। /hooks खोलें और vibestretch की तीनों एंट्री को trust करें। तब तक प्लगइन इंस्टॉल रहता है लेकिन चुप रहता है।

मैन्युअली इंस्टॉल करें

एक clone और एक कॉन्फ़िग फ़ाइल से भी यही काम होता है:

git clone https://github.com/Eliasjunit/vibestretch ~/.codex/vibestretch
cp ~/.codex/vibestretch/hooks/codex-hooks.json ~/.codex/hooks.json

क्या आपके पास पहले से ~/.codex/hooks.json है? हमारी फ़ाइल की तीनों एंट्री उसमें मर्ज करें। अपनी फ़ाइल ओवरराइट न करें। नई हुक कॉन्फ़िग पहली बार चलने पर Codex आपसे उसे trust करने को कहता है। यह प्रॉम्प्ट आना सामान्य है।

एक ही तरीका चुनें। अगर प्लगइन और मैन्युअल एंट्री दोनों मौजूद हैं, तो हर हुक दो बार चलता है। अगर आपने 0.8.0 से पहले मैन्युअली इंस्टॉल किया था, तो प्लगइन पर जाते समय ~/.codex/hooks.json से हमारी एंट्री हटा दें।

Codex में आपको क्या मिलता है

आपको सेशन में लाइन और चाइम मिलती है। नोटिफ़िकेशन बैनर नहीं है, क्योंकि Codex में टर्मिनल सीक्वेंस के लिए कोई हुक आउटपुट फ़ील्ड नहीं है। स्टेटस लाइन सेगमेंट भी नहीं है। Codex में वह बार स्क्रिप्ट नहीं किया जा सकता।

काउंटर Claude Code और Gemini CLI के साथ शेयर होता है। एक घंटे का इंतज़ार एक ही बार गिना जाता है, चाहे किसी भी एजेंट ने आपको कुर्सी पर बैठाए रखा हो। अडैप्टर को macOS पर Codex CLI 0.149.1 के लाइव इंस्टॉल पर चलाया गया था।

अक्सर पूछे जाने वाले सवाल

मैंने इंस्टॉल किया, लेकिन कुछ नहीं होता। क्यों?
Codex किसी प्लगइन के हुक तभी चलाता है जब आप उन्हें trust करते हैं। /hooks खोलें और vibestretch की तीनों एंट्री को trust करें।
हर हुक दो बार चलता है। क्यों?
शायद आपके पास प्लगइन और ~/.codex/hooks.json में मैन्युअल एंट्री, दोनों हैं। इनमें से एक ही रखें।
क्या मैं इसे codex exec के साथ इस्तेमाल कर सकता हूं?
उस एनवायरनमेंट में VIBESTRETCH_DISABLE=1 सेट करें। बिना निगरानी वाले रन को ऐसे समय के रूप में नहीं गिना जाना चाहिए जो आपने बैठकर बिताया।
