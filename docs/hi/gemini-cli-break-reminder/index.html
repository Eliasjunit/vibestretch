Gemini CLI में ब्रेक रिमाइंडर कैसे जोड़ें

Gemini CLI में v0.26 से हुक डिफ़ॉल्ट रूप से चालू आते हैं। vibestretch इनमें से तीन जोड़ता है, ताकि लंबे टर्न के दौरान आपको स्ट्रेच करने की याद दिलाई जा सके।

इंस्टॉल

रिपॉज़िटरी clone करें:

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

फिर ~/.gemini/vibestretch/hooks/gemini-hooks.json से hooks ऑब्जेक्ट को ~/.gemini/settings.json में कॉपी करें। उस फ़ाइल में आपकी पूरी Gemini कॉन्फ़िगरेशन होती है, इसलिए उसे मर्ज करें। उसे बदलें नहीं। jq के साथ यह एक लाइन का काम है:

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

अगर BeforeAgent, AfterTool या AfterAgent में आपके अपने हुक पहले से हैं, तो यह कमांड उन्हें हमारे हुक से बदल देता है। ऐसे में हमारी तीनों एंट्री अपनी लिस्ट में हाथ से जोड़ें।

यह कौन से हुक इस्तेमाल करता है

  • BeforeAgent: एजेंट आपके प्रॉम्प्ट पर काम शुरू करता है।
  • AfterTool: कोई टूल पूरा हुआ। इंतज़ार का समय जुड़ता है, और अगर रिमाइंडर का समय हो गया है तो वह आता है।
  • AfterAgent: टर्न खत्म हो गया। गिनती बंद होती है।

Gemini CLI में आपको क्या मिलता है

आपको सेशन में लाइन और चाइम मिलती है। नोटिफ़िकेशन बैनर नहीं है। Gemini हुक के stdout को सिर्फ़ JSON के लिए रखता है, इसलिए escape sequence प्रिंट करने की कोई जगह नहीं है।

अडैप्टर को macOS पर Gemini CLI 0.56.0 के लाइव इंस्टॉल पर चलाया गया था। काउंटर Claude Code और Codex CLI के साथ शेयर होता है।

अक्सर पूछे जाने वाले सवाल

मुझे Gemini CLI का कौन सा वर्ज़न चाहिए?
Gemini CLI v0.26 से हुक डिफ़ॉल्ट रूप से चालू आते हैं।
क्या मर्ज से मेरी सेटिंग्स ओवरराइट हो जाएंगी?
आपकी बाकी सेटिंग्स बनी रहती हैं। अगर BeforeAgent, AfterTool या AfterAgent में आपके अपने हुक पहले से हैं, तो jq उन लिस्ट को हमारी लिस्ट से बदल देता है। ऐसे में हमारी तीनों एंट्री हाथ से जोड़ें। पहले फ़ाइल का बैकअप ले लें।
क्या मैं इसे gemini -p के साथ इस्तेमाल कर सकता हूं?
जब आप Gemini को किसी स्क्रिप्ट, cron या बॉट से चलाएं, तो VIBESTRETCH_DISABLE=1 सेट करें।
