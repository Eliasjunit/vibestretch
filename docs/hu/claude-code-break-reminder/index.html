Hogyan adj szünetemlékeztetőt a Claude Code-hoz

A vibestretch egy Claude Code bővítmény. Három hookkal észleli a hosszú futásokat, és mozgásra emlékeztet.

Telepítés

Futtasd ezt a két parancsot a Claude Code-ban:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

Nincsenek függőségek, nincs háttérfolyamat és nincs telemetria. Mást nem kell beállítani.

Hol jelenik meg az emlékeztető

  • Egy sorként a munkamenetben.
  • Egy halk, mellékelt hangjelzésként.
  • Értesítési bannerként a Warp, Ghostty, iTerm2, WezTerm és kitty terminálokban. A VS Code-ban ehhez értesítő bővítmény kell.
  • Az állapotsorodban, ha beállítod.

Add hozzá az állapotsorhoz

/vibestretch:statusline

Ez a parancs biztonsági mentést készít a beállításaidról, és becsomagolja a meglévő állapotsor-parancsodat. Ha nincs ilyen, telepít egy minimálisat. Egy emlékeztető után a gyakorlat 5 percig ott marad. Visszavonni a /vibestretch:statusline off paranccsal tudod. Az off parancsot a bővítmény eltávolítása előtt futtasd.

VS Code

Az integrált terminálban a sor, a hangjelzés és az állapotsor is működik. A bővítmény csevegőpaneljén csak a hangjelzés jut el hozzád. A bannerhez mindkét helyen értesítő bővítmény kell. Ezt a Claude Code 2.1.234 verzión ellenőriztük.

Beállítások

Minden beállítás opcionális környezeti változó. Az idők másodpercben értendők.

VáltozóAlapértékJelentés
VIBESTRETCH_MIN_TURN120Az aktuális futásnak legalább ennyi ideig kell tartania.
VIBESTRETCH_MIN_ACTIVE300Szükséges ügynökidő az utolsó szünet óta.
VIBESTRETCH_COOLDOWN900Minimális idő két emlékeztető között.
VIBESTRETCH_AWAY300Ha ennyi ideig nincs billentyűzet- vagy egérhasználat, távol vagy. Csak macOS. A 0 kikapcsolja ezt a védelmet.
VIBESTRETCH_DISABLEunsetBármilyen értékre állítva elnémítja az emlékeztetőket.
VIBESTRETCH_NOTIFY10 értékkel kikapcsolja az asztali értesítést.
VIBESTRETCH_SOUND10 értékkel elnémítja a hangot.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtA saját gyakorlatlistád útvonala.

Szkriptből, felület nélkül futtatod a Claude Code-ot a claude -p paranccsal? Ott állítsd be: VIBESTRETCH_DISABLE=1.

GYIK

Hogyan távolítom el az állapotsor-elemet?
Futtasd: /vibestretch:statusline off. Ezt a bővítmény eltávolítása előtt tedd meg, különben az elem beállítva marad, de lefagy.
Eljut az emlékeztető a modellhez?
Nem. Az emlékeztető egy systemMessage. Neked jelenik meg, és sosem kerül a modell kontextusába.
Miért hallok két hangot?
Egyes terminálok, például az iTerm2, saját hangot játszanak le az értesítésekhez. Állítsd be a VIBESTRETCH_SOUND=0 értéket, hogy csak a terminál hangja maradjon.
