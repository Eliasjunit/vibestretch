Cara menambah pengingat istirahat di Claude Code

vibestretch adalah plugin Claude Code. Ia memakai tiga hook untuk mengenali giliran panjang dan mengingatkan Anda untuk bergerak.

Instalasi

Jalankan dua perintah ini di dalam Claude Code:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

Tidak ada dependensi, tidak ada daemon dan tidak ada telemetri. Tidak ada lagi yang perlu dikonfigurasi.

Di mana pengingat muncul

  • Satu baris di sesi.
  • Bunyi lembut bawaan.
  • Banner notifikasi di Warp, Ghostty, iTerm2, WezTerm dan kitty. Di VS Code perlu ekstensi notifikasi.
  • Status line Anda, jika Anda mengaturnya.

Tambahkan ke status line

/vibestretch:statusline

Perintah ini mencadangkan pengaturan Anda dan membungkus perintah status line yang sudah ada. Jika Anda belum punya, ia memasang versi minimal. Setelah pengingat muncul, latihannya tetap tampil di sana selama 5 menit. Batalkan dengan /vibestretch:statusline off. Jalankan off sebelum Anda menghapus plugin.

VS Code

Di terminal terintegrasi, baris pengingat, bunyi dan status line semuanya berfungsi. Di panel chat ekstensi, hanya bunyi yang sampai ke Anda. Banner perlu ekstensi notifikasi di kedua tempat. Ini sudah dicek di Claude Code 2.1.234.

Pengaturan

Semua pengaturan adalah variabel lingkungan opsional. Waktu dalam detik.

VariabelBawaanArti
VIBESTRETCH_MIN_TURN120Giliran saat ini harus berjalan paling tidak selama ini.
VIBESTRETCH_MIN_ACTIVE300Waktu agen yang dibutuhkan sejak istirahat terakhir.
VIBESTRETCH_COOLDOWN900Jeda minimum antar pengingat.
VIBESTRETCH_AWAY300Tanpa aktivitas keyboard atau mouse selama ini berarti Anda sedang pergi. Hanya macOS. 0 mematikan fitur ini.
VIBESTRETCH_DISABLEunsetIsi dengan nilai apa saja untuk mematikan pengingat.
VIBESTRETCH_NOTIFY1Atur ke 0 untuk menghilangkan notifikasi desktop.
VIBESTRETCH_SOUND1Atur ke 0 untuk mematikan suara.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtPath ke daftar latihan Anda sendiri.

Menjalankan Claude Code secara headless dengan claude -p dari skrip? Atur VIBESTRETCH_DISABLE=1 di sana.

Tanya jawab

Bagaimana cara menghapus segmen status line?
Jalankan /vibestretch:statusline off. Lakukan ini sebelum menghapus plugin. Jika tidak, segmennya tetap terkonfigurasi tetapi membeku.
Apakah pengingat sampai ke model?
Tidak. Pengingat adalah systemMessage. Ia ditampilkan kepada Anda dan tidak pernah ditambahkan ke konteks model.
Kenapa saya mendengar dua bunyi?
Beberapa terminal, seperti iTerm2, memutar bunyi sendiri untuk notifikasi. Atur VIBESTRETCH_SOUND=0 agar hanya bunyi terminal yang terdengar.
