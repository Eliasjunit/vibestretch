Cara menambah pengingat istirahat di Codex CLI

vibestretch bisa dipasang di OpenAI Codex CLI dari marketplace plugin. Ia menampilkan baris peregangan dan memutar bunyi saat giliran panjang.

Pasang sebagai plugin

codex plugin marketplace add Eliasjunit/vibestretch
codex plugin add vibestretch@vibestretch

Codex tidak menjalankan hook plugin sampai Anda meninjaunya. Buka /hooks dan percayai tiga entri vibestretch. Sebelum itu, plugin sudah terpasang tetapi diam.

Pasang secara manual

Clone repositori dan satu file konfigurasi memberi hasil yang sama:

git clone https://github.com/Eliasjunit/vibestretch ~/.codex/vibestretch
cp ~/.codex/vibestretch/hooks/codex-hooks.json ~/.codex/hooks.json

Sudah punya ~/.codex/hooks.json? Gabungkan tiga entri dari file kami ke dalamnya. Jangan menimpa file Anda. Codex meminta Anda memercayai konfigurasi hook baru saat pertama kali berjalan. Permintaan itu memang normal.

Pilih satu cara. Jika plugin dan entri manual sama-sama terpasang, setiap hook berjalan dua kali. Jika Anda memasang secara manual sebelum 0.8.0, hapus entri kami dari ~/.codex/hooks.json saat beralih ke plugin.

Yang Anda dapatkan di Codex

Anda mendapat baris di sesi dan bunyi. Tidak ada banner notifikasi, karena Codex tidak punya field output hook untuk sequence terminal. Tidak ada segmen status line juga. Bar itu tidak bisa diatur dengan skrip di Codex.

Penghitungnya dipakai bersama dengan Claude Code dan Gemini CLI. Satu jam menunggu hanya dihitung sekali, agen mana pun yang membuat Anda tetap duduk. Adapter ini sudah dijalankan pada instalasi nyata Codex CLI 0.149.1 di macOS.

Tanya jawab

Saya sudah memasangnya, tetapi tidak terjadi apa-apa. Kenapa?
Codex hanya menjalankan hook plugin setelah Anda memercayainya. Buka /hooks dan percayai tiga entri vibestretch.
Setiap hook berjalan dua kali. Kenapa?
Kemungkinan Anda memasang plugin sekaligus entri manual di ~/.codex/hooks.json. Pertahankan salah satunya saja.
Bisakah dipakai dengan codex exec?
Atur VIBESTRETCH_DISABLE=1 di lingkungan tersebut. Proses tanpa pengawasan sebaiknya tidak dihitung sebagai waktu yang Anda jalani.
