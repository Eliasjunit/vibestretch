Cara menambah pengingat istirahat di Gemini CLI

Gemini CLI sudah mengaktifkan hook secara bawaan sejak v0.26. vibestretch menambahkan tiga hook untuk mengingatkan Anda meregangkan badan saat giliran panjang.

Instalasi

Clone repositorinya:

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

Lalu salin objek hooks dari ~/.gemini/vibestretch/hooks/gemini-hooks.json ke ~/.gemini/settings.json. File itu menyimpan seluruh konfigurasi Gemini Anda, jadi gabungkan isinya. Jangan menggantinya. Dengan jq cukup satu baris:

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

Jika Anda sudah punya hook sendiri di BeforeAgent, AfterTool atau AfterAgent, perintah ini menggantinya dengan milik kami. Dalam hal itu, tambahkan tiga entri kami ke daftar Anda secara manual.

Hook yang dipakai

  • BeforeAgent: agen mulai mengerjakan prompt Anda.
  • AfterTool: sebuah tool selesai. Waktu tunggu ditambahkan, dan pengingat muncul jika sudah waktunya.
  • AfterAgent: giliran selesai. Penghitungan ditutup.

Yang Anda dapatkan di Gemini CLI

Anda mendapat baris di sesi dan bunyi. Tidak ada banner notifikasi. Gemini memakai stdout hook khusus untuk JSON, jadi tidak ada tempat untuk mencetak escape sequence.

Adapter ini sudah dijalankan pada instalasi nyata Gemini CLI 0.56.0 di macOS. Penghitungnya dipakai bersama dengan Claude Code dan Codex CLI.

Tanya jawab

Versi Gemini CLI berapa yang saya perlukan?
Hook aktif secara bawaan sejak Gemini CLI v0.26.
Apakah penggabungan akan menimpa pengaturan saya?
Pengaturan lain Anda tetap ada. Jika Anda sudah punya hook sendiri di BeforeAgent, AfterTool atau AfterAgent, jq mengganti daftar itu dengan milik kami. Dalam hal itu, tambahkan tiga entri kami secara manual. Cadangkan file itu dulu.
Bisakah dipakai dengan gemini -p?
Atur VIBESTRETCH_DISABLE=1 saat Anda menjalankan Gemini dari skrip, cron atau bot.
