Stretch while your coding agent works

vibestretch shows a short stretch, a micro-workout or an eye break while a long agent turn keeps you waiting. It works with Claude Code, Codex CLI and Gemini CLI.

claude plugin marketplace add Eliasjunit/vibestretch && claude plugin install vibestretch@vibestretch

This installs the plugin in Claude Code. The pages for Codex CLI and Gemini CLI show their install steps.

What a nudge looks like

🧘 Wrist circles, 10 each way. Your tendons will thank you. · vibestretch · 7 min of agent time

One line appears in the session. A soft chime plays. In terminals that support it, a notification banner shows up too.

How it decides when to nudge

vibestretch has no schedule. It counts one thing: the minutes an agent turn kept you waiting at the machine. A nudge fires only when all three are true:

  1. The current turn has run for 2 minutes or more.
  2. Your agent time since the last nudge adds up to 5 minutes or more.
  3. The last nudge was at least 15 minutes ago.

Quick turns never trigger it. A day of short turns says nothing at all. There is nothing to snooze, because it only speaks while you are already waiting. Read more in stretch breaks while AI coding agents run.

What you get

  • Twelve built-in exercises: stretches, micro-workouts and eye breaks such as 20-20-20.
  • A rotation that never repeats the same exercise twice in a row.
  • Your own exercise list, if you prefer it. See desk stretches for programmers.
  • An optional status line segment in Claude Code.

Privacy

vibestretch is a few small POSIX shell scripts and one bundled sound. It makes no network calls. It sends no telemetry. It shows no ads and puts no links in your terminal. It adds nothing to the model's context. Its state lives in ~/.cache/vibestretch/.

FAQ

What is vibestretch?
vibestretch is a plugin for coding agents. It reminds you to stretch, move or rest your eyes while a long agent turn keeps you waiting.
Which coding agents does it support?
Claude Code, OpenAI Codex CLI and Gemini CLI. All three use the same counter, so an hour of waiting counts once, whichever agent kept you in the chair.
Is it a break timer?
No. A timer runs on a schedule. vibestretch counts only the time an agent turn kept you waiting, and it nudges only during that wait.
Does it send data anywhere?
No. It makes no network calls and sends no telemetry. Nothing leaves your machine.
How much does it cost?
It is open source under the MIT license. The code is on GitHub.
How do I mute it?
Set VIBESTRETCH_DISABLE to any value to mute nudges. VIBESTRETCH_SOUND=0 mutes the sound. VIBESTRETCH_NOTIFY=0 drops the banner.
