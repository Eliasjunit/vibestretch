Come aggiungere un promemoria per le pause a Claude Code

vibestretch è un plugin per Claude Code. Usa tre hook per accorgersi dei turni lunghi e invitarti a muoverti.

Installazione

Esegui questi due comandi dentro Claude Code:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

Niente dipendenze, niente daemon e niente telemetria. Non c'è altro da configurare.

Dove compare il promemoria

  • Una riga nella sessione.
  • Un leggero segnale acustico incluso.
  • Una notifica in Warp, Ghostty, iTerm2, WezTerm e kitty. In VS Code serve un'estensione per le notifiche.
  • La tua barra di stato, se la configuri.

Aggiungilo alla barra di stato

/vibestretch:statusline

Questo comando fa un backup delle impostazioni e avvolge il comando che già usi per la barra di stato. Se non ne hai uno, ne installa uno minimo. Dopo un promemoria, l'esercizio resta visibile per 5 minuti. Per annullare usa /vibestretch:statusline off. Esegui off prima di disinstallare il plugin.

VS Code

Nel terminale integrato funzionano la riga, il segnale acustico e la barra di stato. Nel pannello chat dell'estensione ti arriva solo il segnale acustico. La notifica richiede in entrambi i casi un'estensione per le notifiche. Verificato con Claude Code 2.1.234.

Impostazioni

Tutte le impostazioni sono variabili d'ambiente facoltative. I tempi sono in secondi.

VariabilePredefinitoSignificato
VIBESTRETCH_MIN_TURN120Durata minima del turno attuale.
VIBESTRETCH_MIN_ACTIVE300Tempo dell'agente necessario dall'ultima pausa.
VIBESTRETCH_COOLDOWN900Intervallo minimo tra due promemoria.
VIBESTRETCH_AWAY300Dopo questo tempo senza tastiera né mouse sei considerato assente. Solo macOS. 0 disattiva il controllo.
VIBESTRETCH_DISABLEunsetImpostala a un valore qualsiasi per disattivare i promemoria.
VIBESTRETCH_NOTIFY1Impostala a 0 per eliminare la notifica desktop.
VIBESTRETCH_SOUND1Impostala a 0 per disattivare il suono.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtPercorso della tua lista di esercizi.

Usi Claude Code in modalità headless con claude -p da uno script? Lì imposta VIBESTRETCH_DISABLE=1.

Domande frequenti

Come rimuovo il segmento dalla barra di stato?
Esegui /vibestretch:statusline off. Fallo prima di disinstallare il plugin, altrimenti il segmento resta configurato ma bloccato.
Il promemoria arriva al modello?
No. Il promemoria è un systemMessage. Viene mostrato a te e non viene mai aggiunto al contesto del modello.
Perché sento due suoni?
Alcuni terminali, come iTerm2, riproducono un proprio suono per le notifiche. Imposta VIBESTRETCH_SOUND=0 per tenere solo il suono del terminale.
