Come aggiungere un promemoria per le pause a Codex CLI

vibestretch si installa in OpenAI Codex CLI dal marketplace dei plugin. Durante i turni lunghi mostra una riga di stretching e riproduce un segnale acustico.

Installazione come plugin

codex plugin marketplace add Eliasjunit/vibestretch
codex plugin add vibestretch@vibestretch

Codex non esegue gli hook di un plugin finché non li hai esaminati. Apri /hooks e dai la tua fiducia alle tre voci di vibestretch. Fino ad allora il plugin è installato ma resta in silenzio.

Installazione manuale

Un clone e un file di configurazione fanno lo stesso lavoro:

git clone https://github.com/Eliasjunit/vibestretch ~/.codex/vibestretch
cp ~/.codex/vibestretch/hooks/codex-hooks.json ~/.codex/hooks.json

Hai già un ~/.codex/hooks.json? Unisci le tre voci del nostro file al tuo. Non sovrascrivere il tuo file. Al primo avvio Codex ti chiede se ti fidi della nuova configurazione degli hook. Questa richiesta è normale.

Scegli un solo metodo. Se ci sono sia il plugin sia le voci aggiunte a mano, ogni hook viene eseguito due volte. Se hai installato a mano prima della 0.8.0, rimuovi le nostre voci da ~/.codex/hooks.json quando passi al plugin.

Cosa ottieni in Codex

Ottieni la riga nella sessione e il segnale acustico. Non c'è la notifica, perché Codex non ha un campo di output degli hook per una sequenza di terminale. Non c'è nemmeno il segmento nella barra di stato. In Codex quella barra non si può controllare con script.

Il contatore è condiviso con Claude Code e Gemini CLI. Un'ora di attesa conta una volta sola, qualunque agente ti abbia tenuto sulla sedia. L'adattatore è stato eseguito su un'installazione reale di Codex CLI 0.149.1 su macOS.

Domande frequenti

L'ho installato ma non succede nulla. Perché?
Codex esegue gli hook di un plugin solo dopo che gli hai dato la tua fiducia. Apri /hooks e conferma le tre voci di vibestretch.
Ogni hook viene eseguito due volte. Perché?
Probabilmente hai sia il plugin sia voci aggiunte a mano in ~/.codex/hooks.json. Tieni solo una delle due.
Posso usarlo con codex exec?
Imposta VIBESTRETCH_DISABLE=1 in quell'ambiente. Le esecuzioni senza supervisione non dovrebbero contare come tempo passato in attesa.
