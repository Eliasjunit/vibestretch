Come aggiungere un promemoria per le pause a Gemini CLI

Gemini CLI ha gli hook attivi di default dalla v0.26. vibestretch ne aggiunge tre per ricordarti di fare stretching durante i turni lunghi.

Installazione

Clona il repository:

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

Poi copia l'oggetto hooks da ~/.gemini/vibestretch/hooks/gemini-hooks.json in ~/.gemini/settings.json. Quel file contiene tutta la tua configurazione di Gemini, quindi unisci i contenuti. Non sostituirlo. Con jq basta una riga:

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

Se hai già hook tuoi in BeforeAgent, AfterTool o AfterAgent, questo comando li sostituisce con i nostri. In quel caso aggiungi a mano le nostre tre voci alle tue liste.

Quali hook usa

  • BeforeAgent: l'agente inizia a lavorare sul tuo prompt.
  • AfterTool: uno strumento ha finito. Il tempo di attesa viene sommato e, se è il momento, arriva un promemoria.
  • AfterAgent: il turno è finito. Il conteggio si chiude.

Cosa ottieni in Gemini CLI

Ottieni la riga nella sessione e il segnale acustico. Non c'è la notifica. Gemini riserva lo stdout di un hook solo al JSON, quindi non c'è modo di stampare una sequenza di escape.

L'adattatore è stato eseguito su un'installazione reale di Gemini CLI 0.56.0 su macOS. Il contatore è condiviso con Claude Code e Codex CLI.

Domande frequenti

Quale versione di Gemini CLI mi serve?
Gli hook sono attivi di default da Gemini CLI v0.26.
L'unione sovrascrive le mie impostazioni?
Le altre impostazioni restano. Se hai già hook tuoi in BeforeAgent, AfterTool o AfterAgent, jq sostituisce quelle liste con le nostre. In quel caso aggiungi a mano le nostre tre voci. Fai prima un backup del file.
Posso usarlo con gemini -p?
Imposta VIBESTRETCH_DISABLE=1 quando avvii Gemini da uno script, da cron o da un bot.
