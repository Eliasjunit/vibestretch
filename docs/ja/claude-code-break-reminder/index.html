Claude Code に休憩リマインダーを追加する方法

vibestretch は Claude Code のプラグインです。3 つのフックで長いターンを検知し、体を動かすよう促します。

インストール

Claude Code の中で次の 2 つのコマンドを実行します。

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

依存関係もデーモンもテレメトリもありません。ほかに設定するものもありません。

通知が出る場所

  • セッション内の 1 行。
  • 同梱の控えめなチャイム。
  • Warp、Ghostty、iTerm2、WezTerm、kitty の通知バナー。VS Code では通知用の拡張機能が必要です。
  • 設定した場合はステータスライン。

ステータスラインに追加する

/vibestretch:statusline

このコマンドは設定をバックアップし、既存のステータスラインのコマンドをラップします。ステータスラインがない場合は、最小限のものをインストールします。通知のあと、エクササイズが 5 分間そこに表示されます。元に戻すには /vibestretch:statusline off を実行します。プラグインをアンインストールする前に off を実行してください。

VS Code

統合ターミナルでは、セッションの 1 行、チャイム、ステータスラインがすべて動きます。拡張機能のチャットパネルでは、チャイムだけが届きます。バナーはどちらの場合も通知用の拡張機能が必要です。この内容は Claude Code 2.1.234 で確認しました。

設定

設定はすべて任意の環境変数です。時間の単位は秒です。

変数初期値説明
VIBESTRETCH_MIN_TURN120現在のターンがこの時間以上続く必要があります。
VIBESTRETCH_MIN_ACTIVE300前回の休憩から必要なエージェント時間。
VIBESTRETCH_COOLDOWN900通知と通知の最小間隔。
VIBESTRETCH_AWAY300キーボードとマウスの操作がこの時間ないと、離席とみなします。macOS のみ。0 でこの判定をオフにします。
VIBESTRETCH_DISABLEunset何か値を設定すると通知を止めます。
VIBESTRETCH_NOTIFY10 にするとデスクトップ通知を出しません。
VIBESTRETCH_SOUND10 にすると音を消します。
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txt自分のエクササイズリストのパス。

スクリプトから claude -p で Claude Code をヘッドレス実行する場合は、その環境で VIBESTRETCH_DISABLE=1 を設定してください。

よくある質問

ステータスラインの項目を外すには？
/vibestretch:statusline off を実行します。プラグインをアンインストールする前に実行してください。そうしないと、項目が設定に残ったまま更新されなくなります。
通知はモデルに伝わりますか？
いいえ。通知は systemMessage です。あなたに表示されるだけで、モデルのコンテキストには追加されません。
音が 2 回鳴るのはなぜですか？
iTerm2 など一部のターミナルは、通知のときに独自の音を鳴らします。ターミナルの音だけにしたい場合は VIBESTRETCH_SOUND=0 を設定してください。
