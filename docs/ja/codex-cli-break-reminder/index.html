Codex CLI に休憩リマインダーを追加する方法

vibestretch は OpenAI Codex CLI のプラグインマーケットプレイスからインストールできます。長いターンの間に、ストレッチの 1 行を表示してチャイムを鳴らします。

プラグインとしてインストール

codex plugin marketplace add Eliasjunit/vibestretch
codex plugin add vibestretch@vibestretch

Codex は、プラグインのフックを確認するまで実行しません。/hooks を開き、vibestretch の 3 つのエントリを信頼してください。それまではプラグインがインストールされていても何も起きません。

手動でインストール

クローンと設定ファイル 1 つでも同じことができます。

git clone https://github.com/Eliasjunit/vibestretch ~/.codex/vibestretch
cp ~/.codex/vibestretch/hooks/codex-hooks.json ~/.codex/hooks.json

すでに ~/.codex/hooks.json がある場合は、こちらの 3 つのエントリをそのファイルにマージしてください。上書きはしないでください。Codex は初回の実行時に、新しいフック設定を信頼するか確認します。この確認は想定どおりの動作です。

どちらか一方の方法を選んでください。プラグインと手動のエントリが両方あると、すべてのフックが 2 回実行されます。0.8.0 より前に手動でインストールした場合は、プラグインに切り替えるときに ~/.codex/hooks.json からこちらのエントリを削除してください。

Codex で使える機能

セッション内の 1 行とチャイムが使えます。通知バナーはありません。Codex のフック出力に、ターミナルのシーケンスを渡すフィールドがないためです。ステータスラインの項目もありません。Codex ではそのバーをスクリプトで操作できません。

カウンターは Claude Code、Gemini CLI と共通です。どのエージェントで待っていても、1 時間の待ち時間は 1 回分として数えます。このアダプターは macOS 上の Codex CLI 0.149.1 の実環境で動作させました。

よくある質問

インストールしたのに何も起きません。なぜですか？
Codex は、信頼したプラグインのフックしか実行しません。/hooks を開き、vibestretch の 3 つのエントリを信頼してください。
すべてのフックが 2 回実行されます。なぜですか？
プラグインと、~/.codex/hooks.json の手動エントリが両方あると考えられます。どちらか一方だけを残してください。
codex exec でも使えますか？
その環境で VIBESTRETCH_DISABLE=1 を設定してください。無人の実行は、座って待っていた時間として数えるべきではありません。
