Gemini CLI に休憩リマインダーを追加する方法

Gemini CLI では v0.26 からフックが有効な状態で提供されています。vibestretch はそこに 3 つのフックを追加し、長いターンの間にストレッチを促します。

インストール

リポジトリをクローンします。

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

次に、~/.gemini/vibestretch/hooks/gemini-hooks.json の hooks オブジェクトを ~/.gemini/settings.json にコピーします。このファイルには Gemini の設定がすべて入っているので、置き換えずにマージしてください。jq を使えば 1 行で済みます。

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

使用するフック

  • BeforeAgent: エージェントがプロンプトの処理を始めます。
  • AfterTool: ツールが終了しました。待ち時間が加算され、条件を満たしていれば通知が出ます。
  • AfterAgent: ターンが終わりました。集計を締めます。

Gemini CLI で使える機能

セッション内の 1 行とチャイムが使えます。通知バナーはありません。Gemini はフックの stdout を JSON 専用にしているため、エスケープシーケンスを出力する場所がありません。

このアダプターは macOS 上の Gemini CLI 0.56.0 の実環境で動作させました。カウンターは Claude Code、Codex CLI と共通です。

よくある質問

Gemini CLI のどのバージョンが必要ですか？
Gemini CLI v0.26 以降では、フックが有効な状態で提供されています。
マージで設定が上書きされませんか？
jq コマンドは、hooks オブジェクトを既存の settings.json にマージします。念のため、先にファイルをバックアップしておくと安心です。
gemini -p でも使えますか？
スクリプト、cron、ボットから Gemini を実行するときは、VIBESTRETCH_DISABLE=1 を設定してください。
