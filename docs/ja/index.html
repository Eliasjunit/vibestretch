コーディングエージェントの作業中にストレッチ

vibestretch は、エージェントの長いターンを待っている間に、短いストレッチや軽い運動、目の休憩を表示します。Claude Code、Codex CLI、Gemini CLI で使えます。

claude plugin marketplace add Eliasjunit/vibestretch && claude plugin install vibestretch@vibestretch

これで Claude Code にプラグインがインストールされます。Codex CLI と Gemini CLI のインストール手順は、それぞれのページにあります。

通知の表示例

🧘 Wrist circles, 10 each way. Your tendons will thank you. · vibestretch · 7 min of agent time

セッションに 1 行が表示され、控えめなチャイムが鳴ります。対応するターミナルでは通知バナーも出ます。

通知のタイミングの決め方

vibestretch には決まったスケジュールがありません。数えるのは 1 つだけです。エージェントのターンのせいでマシンの前で待たされた時間です。次の 3 つの条件がすべてそろったときだけ通知します。

  1. 現在のターンが 2 分以上続いている。
  2. 前回の通知からのエージェント時間の合計が 5 分以上になっている。
  3. 前回の通知から 15 分以上たっている。

短いターンでは通知しません。短いターンばかりの日は、一度も通知が出ません。もともと待っている間にしか通知しないので、スヌーズ機能もありません。詳しくは AI コーディングエージェント実行中のストレッチ休憩 をご覧ください。

主な機能

  • 12 種類の組み込みエクササイズ。ストレッチ、軽い運動、20-20-20 などの目の休憩があります。
  • 同じエクササイズが 2 回続けて出ないローテーション。
  • 好みに合わせて自分のエクササイズリストも使えます。プログラマー向けデスクストレッチ をご覧ください。
  • Claude Code のステータスラインに表示する項目 (任意)。

プライバシー

vibestretch は小さな POSIX シェルスクリプト数本と、同梱のサウンド 1 つでできています。ネットワーク通信はしません。テレメトリも送信しません。広告を表示せず、ターミナルにリンクも出しません。モデルのコンテキストにも何も追加しません。状態は ~/.cache/vibestretch/ に保存されます。

よくある質問

vibestretch とは何ですか？
vibestretch はコーディングエージェント用のプラグインです。エージェントの長いターンを待っている間に、ストレッチや体を動かすこと、目を休めることを促します。
どのコーディングエージェントに対応していますか？
Claude Code、OpenAI Codex CLI、Gemini CLI です。3 つとも同じカウンターを使います。どのエージェントで待っていても、1 時間の待ち時間は 1 回分として数えます。
休憩タイマーですか？
いいえ。タイマーはスケジュールで動きます。vibestretch が数えるのは、エージェントのターンで待たされた時間だけです。通知もその待ち時間の間にしか出しません。
データをどこかに送信しますか？
いいえ。ネットワーク通信もテレメトリの送信もしません。データがマシンの外に出ることはありません。
料金はかかりますか？
無料です。vibestretch は MIT ライセンスのオープンソースで、コードは GitHub で公開しています。
通知を止めるには？
VIBESTRETCH_DISABLE に任意の値を設定すると、通知が止まります。VIBESTRETCH_SOUND=0 で音を消せます。VIBESTRETCH_NOTIFY=0 でバナーを出さなくなります。
