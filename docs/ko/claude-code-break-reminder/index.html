Claude Code에 휴식 알림 추가하는 방법

vibestretch는 Claude Code 플러그인입니다. 훅 세 개로 긴 턴을 감지하고 몸을 움직이도록 알려 줍니다.

설치

Claude Code 안에서 다음 두 명령을 실행하세요.

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

의존성도, 데몬도, 텔레메트리도 없습니다. 따로 설정할 것도 없습니다.

알림이 표시되는 곳

  • 세션 안의 한 줄.
  • 함께 들어 있는 부드러운 차임.
  • Warp, Ghostty, iTerm2, WezTerm, kitty의 알림 배너. VS Code에서는 알림용 확장 프로그램이 필요합니다.
  • 설정했다면 상태 표시줄.

상태 표시줄에 추가하기

/vibestretch:statusline

이 명령은 설정을 백업하고 기존 상태 표시줄 명령을 감쌉니다. 상태 표시줄이 없으면 최소한의 상태 표시줄을 설치합니다. 알림이 나온 뒤 운동 내용이 5분 동안 그곳에 표시됩니다. 되돌리려면 /vibestretch:statusline off를 실행하세요. 플러그인을 제거하기 전에 off를 먼저 실행하세요.

VS Code

통합 터미널에서는 세션의 한 줄, 차임, 상태 표시줄이 모두 동작합니다. 확장 프로그램의 채팅 패널에서는 차임만 전달됩니다. 배너는 두 곳 모두 알림용 확장 프로그램이 필요합니다. 이 내용은 Claude Code 2.1.234에서 확인했습니다.

설정

모든 설정은 선택 사항인 환경 변수입니다. 시간 단위는 초입니다.

변수기본값설명
VIBESTRETCH_MIN_TURN120현재 턴이 최소한 이 시간 동안 실행되어야 합니다.
VIBESTRETCH_MIN_ACTIVE300마지막 휴식 이후 필요한 에이전트 시간입니다.
VIBESTRETCH_COOLDOWN900알림 사이의 최소 간격입니다.
VIBESTRETCH_AWAY300이 시간 동안 키보드나 마우스 입력이 없으면 자리를 비운 것으로 봅니다. macOS 전용입니다. 0이면 이 기능을 끕니다.
VIBESTRETCH_DISABLEunset아무 값이나 설정하면 알림이 꺼집니다.
VIBESTRETCH_NOTIFY10으로 설정하면 데스크톱 알림을 표시하지 않습니다.
VIBESTRETCH_SOUND10으로 설정하면 소리가 꺼집니다.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txt나만의 운동 목록 파일 경로입니다.

스크립트에서 claude -p로 Claude Code를 헤드리스 실행하나요? 그 환경에 VIBESTRETCH_DISABLE=1을 설정하세요.

자주 묻는 질문

상태 표시줄 항목은 어떻게 없애나요?
/vibestretch:statusline off를 실행하세요. 플러그인을 제거하기 전에 실행해야 합니다. 그렇지 않으면 항목이 설정에 남은 채 멈춰 있게 됩니다.
알림이 모델에 전달되나요?
아니요. 알림은 systemMessage입니다. 사용자에게만 표시되고 모델 컨텍스트에는 추가되지 않습니다.
소리가 두 번 들리는 이유는 무엇인가요?
iTerm2 같은 일부 터미널은 알림에 자체 소리를 냅니다. 터미널 소리만 남기려면 VIBESTRETCH_SOUND=0을 설정하세요.
