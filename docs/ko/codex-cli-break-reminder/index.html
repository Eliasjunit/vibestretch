Codex CLI에 휴식 알림 추가하는 방법

vibestretch는 OpenAI Codex CLI의 플러그인 마켓플레이스에서 설치할 수 있습니다. 긴 턴 동안 스트레칭 안내 한 줄을 보여 주고 차임을 울립니다.

플러그인으로 설치

codex plugin marketplace add Eliasjunit/vibestretch
codex plugin add vibestretch@vibestretch

Codex는 플러그인의 훅을 검토하기 전까지 실행하지 않습니다. /hooks를 열고 vibestretch 항목 세 개를 신뢰하세요. 그전까지는 플러그인이 설치되어 있어도 아무 동작도 하지 않습니다.

직접 설치

저장소 클론과 설정 파일 하나로도 같은 일을 할 수 있습니다.

git clone https://github.com/Eliasjunit/vibestretch ~/.codex/vibestretch
cp ~/.codex/vibestretch/hooks/codex-hooks.json ~/.codex/hooks.json

이미 ~/.codex/hooks.json이 있나요? 저희 파일의 항목 세 개를 기존 파일에 병합하세요. 기존 파일을 덮어쓰지 마세요. Codex는 새 훅 설정을 처음 실행할 때 신뢰할지 묻습니다. 이 확인 창은 정상입니다.

한 가지 방법만 선택하세요. 플러그인과 직접 만든 항목이 둘 다 있으면 모든 훅이 두 번 실행됩니다. 0.8.0 이전에 직접 설치했다면, 플러그인으로 바꿀 때 ~/.codex/hooks.json에서 저희 항목을 지우세요.

Codex에서 쓸 수 있는 기능

세션 안의 한 줄과 차임을 쓸 수 있습니다. 알림 배너는 없습니다. Codex의 훅 출력에는 터미널 시퀀스를 넘길 필드가 없기 때문입니다. 상태 표시줄 항목도 없습니다. Codex에서는 그 표시줄을 스크립트로 다룰 수 없습니다.

카운터는 Claude Code, Gemini CLI와 공유됩니다. 어떤 에이전트를 기다렸든 1시간의 대기 시간은 한 번만 계산됩니다. 이 어댑터는 macOS의 Codex CLI 0.149.1 실제 설치 환경에서 실행해 보았습니다.

자주 묻는 질문

설치했는데 아무 일도 일어나지 않습니다. 왜 그런가요?
Codex는 신뢰한 플러그인 훅만 실행합니다. /hooks를 열고 vibestretch 항목 세 개를 신뢰하세요.
모든 훅이 두 번 실행됩니다. 왜 그런가요?
플러그인과 ~/.codex/hooks.json의 직접 만든 항목이 둘 다 있을 가능성이 큽니다. 둘 중 하나만 남기세요.
codex exec에서도 쓸 수 있나요?
그 환경에 VIBESTRETCH_DISABLE=1을 설정하세요. 무인 실행은 앉아서 기다린 시간으로 계산되면 안 됩니다.
