Gemini CLI에 휴식 알림 추가하는 방법

Gemini CLI는 v0.26부터 훅이 활성화된 상태로 제공됩니다. vibestretch는 여기에 훅 세 개를 추가해 긴 턴 동안 스트레칭하도록 알려 줍니다.

설치

저장소를 클론하세요.

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

그다음 ~/.gemini/vibestretch/hooks/gemini-hooks.json의 hooks 객체를 ~/.gemini/settings.json에 복사하세요. 이 파일에는 Gemini 설정 전체가 들어 있으므로 병합해야 합니다. 파일을 통째로 바꾸지 마세요. jq를 쓰면 한 줄이면 됩니다.

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

BeforeAgent, AfterTool, AfterAgent에 직접 넣은 훅이 이미 있다면 이 명령은 그 훅을 저희 훅으로 바꿉니다. 그럴 때는 저희 항목 세 개를 직접 목록에 추가하세요.

사용하는 훅

  • BeforeAgent: 에이전트가 프롬프트 작업을 시작합니다.
  • AfterTool: 도구 실행이 끝났습니다. 대기 시간이 더해지고, 조건이 맞으면 알림이 나옵니다.
  • AfterAgent: 턴이 끝났습니다. 집계를 마감합니다.

Gemini CLI에서 쓸 수 있는 기능

세션 안의 한 줄과 차임을 쓸 수 있습니다. 알림 배너는 없습니다. Gemini는 훅의 stdout을 JSON 전용으로 쓰기 때문에 이스케이프 시퀀스를 출력할 곳이 없습니다.

이 어댑터는 macOS의 Gemini CLI 0.56.0 실제 설치 환경에서 실행해 보았습니다. 카운터는 Claude Code, Codex CLI와 공유됩니다.

자주 묻는 질문

어떤 Gemini CLI 버전이 필요한가요?
Gemini CLI v0.26부터 훅이 활성화된 상태로 제공됩니다.
병합하면 기존 설정이 덮어써지나요?
다른 설정은 그대로 남습니다. 다만 BeforeAgent, AfterTool, AfterAgent에 직접 넣은 훅이 이미 있다면 jq가 그 목록을 저희 것으로 바꿉니다. 그럴 때는 저희 항목 세 개를 직접 추가하세요. 먼저 파일을 백업하세요.
gemini -p에서도 쓸 수 있나요?
스크립트, cron, 봇에서 Gemini를 실행할 때는 VIBESTRETCH_DISABLE=1을 설정하세요.
