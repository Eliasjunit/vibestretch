코딩 에이전트가 일하는 동안 스트레칭하세요

vibestretch는 에이전트의 긴 턴을 기다리는 동안 짧은 스트레칭, 가벼운 운동, 눈 휴식을 보여 줍니다. Claude Code, Codex CLI, Gemini CLI에서 사용할 수 있습니다.

claude plugin marketplace add Eliasjunit/vibestretch && claude plugin install vibestretch@vibestretch

이 명령으로 Claude Code에 플러그인이 설치됩니다. Codex CLI와 Gemini CLI 설치 방법은 각 페이지에 있습니다.

알림은 이렇게 표시됩니다

🧘 Wrist circles, 10 each way. Your tendons will thank you. · vibestretch · 7 min of agent time

세션에 한 줄이 표시되고 부드러운 차임이 울립니다. 지원하는 터미널에서는 알림 배너도 나타납니다.

알림 시점을 정하는 방법

vibestretch에는 정해진 일정이 없습니다. 세는 것은 하나뿐입니다. 에이전트 턴 때문에 컴퓨터 앞에서 기다린 시간입니다. 다음 세 가지 조건이 모두 맞을 때만 알림이 나옵니다.

  1. 현재 턴이 2분 이상 실행되었습니다.
  2. 마지막 알림 이후 에이전트 시간의 합이 5분 이상입니다.
  3. 마지막 알림 후 15분 이상 지났습니다.

짧은 턴에서는 알림이 나오지 않습니다. 짧은 턴만 있었던 날에는 알림이 한 번도 나오지 않습니다. 이미 기다리고 있을 때만 알리기 때문에 다시 알림(스누즈) 기능도 없습니다. 자세한 내용은 AI 코딩 에이전트 실행 중 스트레칭 휴식을 참고하세요.

주요 기능

  • 기본 운동 12가지. 스트레칭, 가벼운 운동, 20-20-20 같은 눈 휴식이 있습니다.
  • 같은 운동이 두 번 연속 나오지 않는 순환 방식.
  • 원하면 나만의 운동 목록을 쓸 수 있습니다. 개발자를 위한 책상 스트레칭을 참고하세요.
  • Claude Code 상태 표시줄 항목(선택 사항).

개인정보

vibestretch는 작은 POSIX 셸 스크립트 몇 개와 사운드 파일 하나로 이루어져 있습니다. 네트워크 요청을 보내지 않습니다. 텔레메트리도 보내지 않습니다. 광고를 보여 주지 않고 터미널에 링크도 넣지 않습니다. 모델 컨텍스트에도 아무것도 추가하지 않습니다. 상태 정보는 ~/.cache/vibestretch/에 저장됩니다.

자주 묻는 질문

vibestretch는 무엇인가요?
vibestretch는 코딩 에이전트용 플러그인입니다. 에이전트의 긴 턴을 기다리는 동안 스트레칭을 하거나 몸을 움직이거나 눈을 쉬도록 알려 줍니다.
어떤 코딩 에이전트를 지원하나요?
Claude Code, OpenAI Codex CLI, Gemini CLI를 지원합니다. 세 가지 모두 같은 카운터를 쓰므로, 어떤 에이전트를 기다렸든 1시간의 대기 시간은 한 번만 계산됩니다.
휴식 타이머인가요?
아닙니다. 타이머는 일정에 따라 동작합니다. vibestretch는 에이전트 턴 때문에 기다린 시간만 세고, 그 대기 시간 동안에만 알립니다.
데이터를 어딘가로 보내나요?
아니요. 네트워크 요청도 텔레메트리 전송도 하지 않습니다. 컴퓨터 밖으로 나가는 데이터는 없습니다.
비용이 드나요?
MIT 라이선스의 오픈 소스입니다. 코드는 GitHub에 있습니다.
알림을 끄려면 어떻게 하나요?
VIBESTRETCH_DISABLE에 아무 값이나 설정하면 알림이 꺼집니다. VIBESTRETCH_SOUND=0은 소리를 끕니다. VIBESTRETCH_NOTIFY=0은 배너를 표시하지 않습니다.
