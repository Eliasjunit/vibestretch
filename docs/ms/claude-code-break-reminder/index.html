Cara menambah peringatan rehat pada Claude Code

vibestretch ialah pemalam Claude Code. Ia menggunakan tiga hook untuk mengesan giliran panjang dan mengingatkan anda supaya bergerak.

Pemasangan

Jalankan dua arahan ini dalam Claude Code:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

Tiada kebergantungan, tiada daemon dan tiada telemetri. Tiada apa-apa lagi yang perlu dikonfigurasi.

Di mana peringatan dipaparkan

  • Satu baris dalam sesi.
  • Bunyi loceng lembut yang disertakan.
  • Sepanduk pemberitahuan dalam Warp, Ghostty, iTerm2, WezTerm dan kitty. Dalam VS Code, ia memerlukan sambungan pemberitahuan.
  • Status line anda, jika anda menyediakannya.

Tambahkan pada status line anda

/vibestretch:statusline

Arahan ini menyandarkan tetapan anda dan membalut arahan status line sedia ada. Jika anda belum ada, ia memasang versi minimum. Selepas peringatan, senaman itu kekal di situ selama 5 minit. Batalkan dengan /vibestretch:statusline off. Jalankan off sebelum anda menyahpasang pemalam.

VS Code

Dalam terminal bersepadu, baris peringatan, bunyi loceng dan status line semuanya berfungsi. Dalam panel sembang sambungan itu, hanya bunyi loceng yang sampai kepada anda. Sepanduk memerlukan sambungan pemberitahuan di kedua-dua tempat. Perkara ini telah disemak pada Claude Code 2.1.234.

Tetapan

Semua tetapan ialah pemboleh ubah persekitaran pilihan. Masa dalam saat.

Pemboleh ubahLalaiMaksud
VIBESTRETCH_MIN_TURN120Giliran semasa mesti berjalan sekurang-kurangnya selama ini.
VIBESTRETCH_MIN_ACTIVE300Masa ejen yang diperlukan sejak rehat terakhir anda.
VIBESTRETCH_COOLDOWN900Sela minimum antara peringatan.
VIBESTRETCH_AWAY300Tiada aktiviti papan kekunci atau tetikus selama ini bermakna anda tiada di tempat. macOS sahaja. 0 mematikan kawalan ini.
VIBESTRETCH_DISABLEunsetTetapkan kepada sebarang nilai untuk menyenyapkan peringatan.
VIBESTRETCH_NOTIFY1Tetapkan kepada 0 untuk membuang pemberitahuan desktop.
VIBESTRETCH_SOUND1Tetapkan kepada 0 untuk mematikan bunyi.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtLaluan ke senarai senaman anda sendiri.

Menjalankan Claude Code secara headless dengan claude -p daripada skrip? Tetapkan VIBESTRETCH_DISABLE=1 di situ.

Soalan lazim

Bagaimana mahu membuang segmen status line?
Jalankan /vibestretch:statusline off. Lakukan ini sebelum menyahpasang pemalam. Jika tidak, segmen itu kekal dalam konfigurasi tetapi beku.
Adakah peringatan sampai kepada model?
Tidak. Peringatan ialah systemMessage. Ia dipaparkan kepada anda dan tidak pernah ditambah ke dalam konteks model.
Mengapa saya mendengar dua bunyi?
Sesetengah terminal, seperti iTerm2, memainkan bunyi sendiri untuk pemberitahuan. Tetapkan VIBESTRETCH_SOUND=0 untuk mengekalkan bunyi terminal sahaja.
