Cara menambah peringatan rehat pada Gemini CLI

Gemini CLI telah mendayakan hook secara lalai sejak v0.26. vibestretch menambah tiga daripadanya untuk mengingatkan anda membuat regangan semasa giliran panjang.

Pemasangan

Klon repositori:

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

Kemudian salin objek hooks daripada ~/.gemini/vibestretch/hooks/gemini-hooks.json ke dalam ~/.gemini/settings.json. Fail itu menyimpan keseluruhan konfigurasi Gemini anda, jadi gabungkannya. Jangan gantikannya. Dengan jq, cukup satu baris:

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

Jika anda sudah ada hook sendiri dalam BeforeAgent, AfterTool atau AfterAgent, arahan ini menggantikannya dengan hook kami. Dalam keadaan itu, tambah tiga entri kami ke dalam senarai anda secara manual.

Hook yang digunakan

  • BeforeAgent: ejen mula mengerjakan prompt anda.
  • AfterTool: satu alat telah selesai. Masa menunggu ditambah, dan peringatan dipaparkan jika sudah tiba masanya.
  • AfterAgent: giliran tamat. Pengiraan ditutup.

Apa yang anda dapat dalam Gemini CLI

Anda mendapat baris dalam sesi dan bunyi loceng. Tiada sepanduk pemberitahuan. Gemini mengkhaskan stdout hook untuk JSON sahaja, jadi tiada tempat untuk mencetak jujukan escape.

Penyesuai ini telah dijalankan pada pemasangan sebenar Gemini CLI 0.56.0 di macOS. Pembilang dikongsi dengan Claude Code dan Codex CLI.

Soalan lazim

Versi Gemini CLI yang mana saya perlukan?
Hook didayakan secara lalai sejak Gemini CLI v0.26.
Adakah penggabungan akan menulis ganti tetapan saya?
Tetapan lain anda kekal. Jika anda sudah ada hook sendiri dalam BeforeAgent, AfterTool atau AfterAgent, jq menggantikan senarai itu dengan senarai kami. Dalam keadaan itu, tambah tiga entri kami secara manual. Sandarkan fail itu dahulu.
Bolehkah saya menggunakannya dengan gemini -p?
Tetapkan VIBESTRETCH_DISABLE=1 apabila anda menjalankan Gemini daripada skrip, cron atau bot.
