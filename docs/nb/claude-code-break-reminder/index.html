Slik legger du til en pausepåminnelse i Claude Code

vibestretch er en utvidelse for Claude Code. Den bruker tre hooks for å merke lange turer og minne deg på å bevege deg.

Installasjon

Kjør disse to kommandoene i Claude Code:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

Det er ingen avhengigheter, ingen daemon og ingen telemetri. Ingenting annet å konfigurere.

Hvor påminnelsen vises

  • En linje i økten.
  • En myk medfølgende lyd.
  • Et varselbanner i Warp, Ghostty, iTerm2, WezTerm og kitty. I VS Code krever det en varslingsutvidelse.
  • Statuslinjen din, hvis du setter den opp.

Legg den til i statuslinjen

/vibestretch:statusline

Denne kommandoen tar sikkerhetskopi av innstillingene dine og legger seg rundt den eksisterende statuslinjekommandoen din. Har du ingen, installerer den en minimal. Etter en påminnelse blir øvelsen stående der i 5 minutter. Angre med /vibestretch:statusline off. Kjør off før du avinstallerer utvidelsen.

VS Code

I den integrerte terminalen fungerer linjen, lyden og statuslinjen. I chatpanelet til utvidelsen er det bare lyden som når fram. Banneret krever en varslingsutvidelse begge steder. Dette ble sjekket med Claude Code 2.1.234.

Innstillinger

Alle innstillinger er valgfrie miljøvariabler. Tider oppgis i sekunder.

VariabelStandardBetydning
VIBESTRETCH_MIN_TURN120Den gjeldende turen må kjøre minst så lenge.
VIBESTRETCH_MIN_ACTIVE300Agenttid som trengs siden forrige pause.
VIBESTRETCH_COOLDOWN900Minste tid mellom påminnelser.
VIBESTRETCH_AWAY300Så lenge uten tastatur eller mus betyr at du er borte. Bare macOS. 0 slår av sperren.
VIBESTRETCH_DISABLEunsetSett til en hvilken som helst verdi for å slå av påminnelser.
VIBESTRETCH_NOTIFY1Sett til 0 for å fjerne skrivebordsvarselet.
VIBESTRETCH_SOUND1Sett til 0 for å slå av lyden.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtSti til din egen liste med øvelser.

Kjører du Claude Code headless med claude -p fra et skript? Sett VIBESTRETCH_DISABLE=1 der.

Ofte stilte spørsmål

Hvordan fjerner jeg feltet i statuslinjen?
Kjør /vibestretch:statusline off. Gjør det før du avinstallerer utvidelsen, ellers blir feltet liggende i oppsettet og står stille.
Når påminnelsen fram til modellen?
Nei. Påminnelsen er en systemMessage. Den vises for deg og legges aldri til i modellens kontekst.
Hvorfor hører jeg to lyder?
Noen terminaler, som iTerm2, spiller sin egen lyd for varsler. Sett VIBESTRETCH_SOUND=0 for å beholde bare terminalens lyd.
