Zo voeg je een pauzeherinnering toe aan Claude Code

vibestretch is een plugin voor Claude Code. Het gebruikt drie hooks om lange beurten op te merken en je een seintje te geven om te bewegen.

Installeren

Voer deze twee commando's uit in Claude Code:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

Er zijn geen afhankelijkheden, geen daemon en geen telemetrie. Verder hoef je niets in te stellen.

Waar het seintje verschijnt

  • Een regel in de sessie.
  • Een zacht, meegeleverd belletje.
  • Een melding in Warp, Ghostty, iTerm2, WezTerm en kitty. In VS Code heb je daarvoor een notificatie-extensie nodig.
  • Je statusregel, als je die instelt.

Toevoegen aan je statusregel

/vibestretch:statusline

Dit commando maakt een back-up van je instellingen en bouwt je bestaande statusregelcommando erin in. Heb je er geen, dan installeert het een minimale versie. Na een seintje blijft de oefening daar 5 minuten staan. Ongedaan maken doe je met /vibestretch:statusline off. Voer off uit voordat je de plugin verwijdert.

VS Code

In de geïntegreerde terminal werken de regel, het belletje en de statusregel. In het chatpaneel van de extensie bereikt alleen het belletje je. Voor de melding heb je op beide plekken een notificatie-extensie nodig. Gecontroleerd met Claude Code 2.1.234.

Instellingen

Alle instellingen zijn optionele omgevingsvariabelen. Tijden zijn in seconden.

VariabeleStandaardBetekenis
VIBESTRETCH_MIN_TURN120Zo lang moet de huidige beurt minstens lopen.
VIBESTRETCH_MIN_ACTIVE300Benodigde agenttijd sinds je vorige pauze.
VIBESTRETCH_COOLDOWN900Minimale tijd tussen seintjes.
VIBESTRETCH_AWAY300Zo lang geen toetsenbord of muis betekent dat je weg bent. Alleen macOS. 0 zet deze controle uit.
VIBESTRETCH_DISABLEunsetGeef een willekeurige waarde om seintjes uit te zetten.
VIBESTRETCH_NOTIFY1Zet op 0 om de bureaubladmelding uit te zetten.
VIBESTRETCH_SOUND1Zet op 0 om het geluid uit te zetten.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtPad naar je eigen lijst met oefeningen.

Draai je Claude Code headless met claude -p vanuit een script? Zet daar VIBESTRETCH_DISABLE=1.

Veelgestelde vragen

Hoe verwijder ik het onderdeel uit de statusregel?
Voer /vibestretch:statusline off uit. Doe dit voordat je de plugin verwijdert. Anders blijft het onderdeel ingesteld, maar wordt het niet meer bijgewerkt.
Komt het seintje bij het model terecht?
Nee. Het seintje is een systemMessage. Het wordt aan jou getoond en nooit aan de context van het model toegevoegd.
Waarom hoor ik twee geluiden?
Sommige terminals, zoals iTerm2, spelen een eigen geluid af bij meldingen. Zet VIBESTRETCH_SOUND=0 om alleen het geluid van de terminal te houden.
