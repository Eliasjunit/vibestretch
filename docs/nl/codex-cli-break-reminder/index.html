Zo voeg je een pauzeherinnering toe aan Codex CLI

vibestretch installeer je in OpenAI Codex CLI via de pluginmarketplace. Tijdens lange beurten toont het een rekregel en klinkt er een belletje.

Installeren als plugin

codex plugin marketplace add Eliasjunit/vibestretch
codex plugin add vibestretch@vibestretch

Codex voert de hooks van een plugin pas uit als je ze hebt bekeken. Open /hooks en vertrouw de drie items van vibestretch. Tot die tijd is de plugin geïnstalleerd, maar blijft hij stil.

Met de hand installeren

Een kloon en een configuratiebestand doen hetzelfde:

git clone https://github.com/Eliasjunit/vibestretch ~/.codex/vibestretch
cp ~/.codex/vibestretch/hooks/codex-hooks.json ~/.codex/hooks.json

Heb je al een ~/.codex/hooks.json? Voeg de drie items uit ons bestand samen met het jouwe. Overschrijf je eigen bestand niet. Codex vraagt bij de eerste start of je een nieuwe hookconfiguratie vertrouwt. Die vraag is normaal.

Kies één manier. Staan de plugin en de handmatige items er allebei, dan draait elke hook twee keer. Heb je vóór 0.8.0 met de hand geïnstalleerd, haal dan onze items uit ~/.codex/hooks.json als je overstapt op de plugin.

Wat je krijgt in Codex

Je krijgt de regel in de sessie en het belletje. Er is geen melding, omdat Codex geen hook-uitvoerveld heeft voor een terminalreeks. Er is ook geen onderdeel in de statusregel. Die balk is in Codex niet met scripts aan te sturen.

De teller wordt gedeeld met Claude Code en Gemini CLI. Een uur wachten telt één keer, welke agent je ook in je stoel hield. De adapter is getest op een echte installatie van Codex CLI 0.149.1 op macOS.

Veelgestelde vragen

Ik heb het geïnstalleerd, maar er gebeurt niets. Waarom?
Codex voert de hooks van een plugin pas uit als je ze vertrouwt. Open /hooks en vertrouw de drie items van vibestretch.
Elke hook draait twee keer. Waarom?
Waarschijnlijk heb je zowel de plugin als handmatige items in ~/.codex/hooks.json. Houd er één van de twee over.
Kan ik het gebruiken met codex exec?
Zet VIBESTRETCH_DISABLE=1 in die omgeving. Runs zonder toezicht horen niet mee te tellen als tijd die je hebt uitgezeten.
