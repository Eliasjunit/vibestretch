Rek je uit terwijl je coding agent werkt

vibestretch toont een korte rekoefening, een mini-workout of een oogpauze terwijl je wacht op een lange beurt van je agent. Het werkt met Claude Code, Codex CLI en Gemini CLI.

claude plugin marketplace add Eliasjunit/vibestretch && claude plugin install vibestretch@vibestretch

Hiermee installeer je de plugin in Claude Code. De pagina's over Codex CLI en Gemini CLI laten de installatiestappen daarvoor zien.

Zo ziet een seintje eruit

🧘 Wrist circles, 10 each way. Your tendons will thank you. · vibestretch · 7 min of agent time

Er verschijnt één regel in de sessie. Er klinkt een zacht belletje. In terminals die het ondersteunen verschijnt ook een melding.

Wanneer je een seintje krijgt

vibestretch werkt zonder schema. Het telt één ding: de minuten dat je achter je computer op een beurt van de agent wachtte. Je krijgt alleen een seintje als alle drie de voorwaarden kloppen:

  1. De huidige beurt loopt 2 minuten of langer.
  2. Je agenttijd sinds het vorige seintje komt samen op 5 minuten of meer.
  3. Het vorige seintje is minstens 15 minuten geleden.

Snelle beurten zetten het nooit in gang. Een dag vol korte beurten blijft helemaal stil. Er valt niets uit te stellen, want het meldt zich alleen als je toch al wacht. Lees meer over rekpauzes terwijl AI coding agents werken.

Wat je krijgt

  • Twaalf ingebouwde oefeningen: rekoefeningen, mini-workouts en oogpauzes zoals 20-20-20.
  • Een volgorde die nooit twee keer achter elkaar dezelfde oefening geeft.
  • Je eigen lijst met oefeningen, als je dat liever hebt. Zie rekoefeningen aan je bureau voor programmeurs.
  • Een optioneel onderdeel in de statusregel van Claude Code.

Privacy

vibestretch bestaat uit een paar kleine POSIX-shellscripts en één meegeleverd geluid. Het maakt geen netwerkverbindingen. Het verstuurt geen telemetrie. Het toont geen advertenties en zet geen links in je terminal. Het voegt niets toe aan de context van het model. De status staat in ~/.cache/vibestretch/.

Veelgestelde vragen

Wat is vibestretch?
vibestretch is een plugin voor coding agents. Het herinnert je eraan om je uit te rekken, te bewegen of je ogen rust te geven terwijl je wacht op een lange beurt van de agent.
Welke coding agents worden ondersteund?
Claude Code, OpenAI Codex CLI en Gemini CLI. Alle drie gebruiken dezelfde teller. Een uur wachten telt dus één keer, welke agent je ook in je stoel hield.
Is het een pauzetimer?
Nee. Een timer werkt volgens een schema. vibestretch telt alleen de tijd dat je op een beurt van de agent wachtte, en geeft alleen tijdens dat wachten een seintje.
Stuurt het ergens gegevens heen?
Nee. Het maakt geen netwerkverbindingen en verstuurt geen telemetrie. Er gaat niets van je computer af.
Wat kost het?
Het is gratis. vibestretch is open source onder de MIT-licentie en de code staat op GitHub.
Hoe zet ik het uit?
Geef VIBESTRETCH_DISABLE een willekeurige waarde om de seintjes uit te zetten. VIBESTRETCH_SOUND=0 zet het geluid uit. VIBESTRETCH_NOTIFY=0 schakelt de melding uit.
