Jak dodać przypomnienie o przerwie do Claude Code

vibestretch to wtyczka do Claude Code. Używa trzech hooków, aby zauważać długie odpowiedzi i przypominać ci o ruchu.

Instalacja

Uruchom te dwa polecenia w Claude Code:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

Nie ma zależności, demona ani telemetrii. Nic więcej nie trzeba konfigurować.

Gdzie pojawia się przypomnienie

  • Linia w sesji.
  • Cichy dołączony dźwięk.
  • Baner powiadomienia w Warp, Ghostty, iTerm2, WezTerm i kitty. W VS Code wymaga rozszerzenia do powiadomień.
  • Twój pasek stanu, jeśli go skonfigurujesz.

Dodaj go do paska stanu

/vibestretch:statusline

To polecenie robi kopię zapasową ustawień i opakowuje twoje obecne polecenie paska stanu. Jeśli go nie masz, instaluje minimalne. Po przypomnieniu ćwiczenie zostaje tam przez 5 minut. Cofniesz to poleceniem /vibestretch:statusline off. Uruchom off przed odinstalowaniem wtyczki.

VS Code

W zintegrowanym terminalu działają linia, dźwięk i pasek stanu. W panelu czatu rozszerzenia dociera do ciebie tylko dźwięk. Baner w obu miejscach wymaga rozszerzenia do powiadomień. Sprawdzono na Claude Code 2.1.234.

Ustawienia

Wszystkie ustawienia to opcjonalne zmienne środowiskowe. Czas podaje się w sekundach.

ZmiennaDomyślnieZnaczenie
VIBESTRETCH_MIN_TURN120Minimalny czas trwania bieżącej odpowiedzi agenta.
VIBESTRETCH_MIN_ACTIVE300Potrzebny czas agenta od ostatniej przerwy.
VIBESTRETCH_COOLDOWN900Minimalny odstęp między przypomnieniami.
VIBESTRETCH_AWAY300Brak użycia klawiatury i myszy przez tyle czasu oznacza, że cię nie ma. Tylko macOS. 0 wyłącza tę ochronę.
VIBESTRETCH_DISABLEunsetDowolna wartość wycisza przypomnienia.
VIBESTRETCH_NOTIFY10 wyłącza powiadomienie na pulpicie.
VIBESTRETCH_SOUND10 wycisza dźwięk.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtŚcieżka do twojej własnej listy ćwiczeń.

Uruchamiasz Claude Code bez interfejsu przez claude -p ze skryptu? Ustaw tam VIBESTRETCH_DISABLE=1.

Najczęstsze pytania

Jak usunąć segment z paska stanu?
Uruchom /vibestretch:statusline off. Zrób to przed odinstalowaniem wtyczki, inaczej segment zostanie w konfiguracji, ale przestanie się aktualizować.
Czy przypomnienie trafia do modelu?
Nie. Przypomnienie to systemMessage. Widzisz je ty, a do kontekstu modelu nigdy nie trafia.
Dlaczego słyszę dwa dźwięki?
Niektóre terminale, na przykład iTerm2, odtwarzają własny dźwięk powiadomień. Ustaw VIBESTRETCH_SOUND=0, aby zostawić tylko dźwięk terminala.
