Jak dodać przypomnienie o przerwie do Gemini CLI

Gemini CLI ma hooki włączone domyślnie od v0.26. vibestretch dodaje trzy z nich, aby przypominać o rozciąganiu podczas długich odpowiedzi.

Instalacja

Sklonuj repozytorium:

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

Następnie skopiuj obiekt hooks z ~/.gemini/vibestretch/hooks/gemini-hooks.json do ~/.gemini/settings.json. Ten plik zawiera całą twoją konfigurację Gemini, więc scal dane. Nie zastępuj pliku. Z jq to jedna linia:

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

Jeśli masz już własne hooki w BeforeAgent, AfterTool lub AfterAgent, to polecenie zastąpi je naszymi. Wtedy dopisz nasze trzy wpisy do swoich list ręcznie.

Jakich hooków używa

  • BeforeAgent: agent zaczyna pracę nad twoim promptem.
  • AfterTool: narzędzie zakończyło pracę. Czas czekania jest dodawany i jeśli przyszła pora, pojawia się przypomnienie.
  • AfterAgent: odpowiedź się skończyła. Rozliczanie czasu jest zamykane.

Co działa w Gemini CLI

Dostajesz linię w sesji i dźwięk. Nie ma banera powiadomienia. Gemini rezerwuje stdout hooka wyłącznie dla JSON, więc nie ma gdzie wypisać sekwencji sterującej.

Adapter uruchomiono na działającej instalacji Gemini CLI 0.56.0 w macOS. Licznik jest wspólny z Claude Code i Codex CLI.

Najczęstsze pytania

Jakiej wersji Gemini CLI potrzebuję?
Hooki są włączone domyślnie od Gemini CLI v0.26.
Czy scalanie nadpisze moje ustawienia?
Pozostałe ustawienia zostają. Jeśli masz już własne hooki w BeforeAgent, AfterTool lub AfterAgent, jq zastąpi te listy naszymi. Wtedy dopisz nasze trzy wpisy ręcznie. Najpierw zrób kopię zapasową pliku.
Czy mogę używać go z gemini -p?
Ustaw VIBESTRETCH_DISABLE=1, gdy uruchamiasz Gemini ze skryptu, przez cron albo z bota.
