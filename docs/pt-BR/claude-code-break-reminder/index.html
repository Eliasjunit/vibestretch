Como adicionar um lembrete de pausa ao Claude Code

vibestretch é um plugin do Claude Code. Ele usa três hooks para perceber turnos longos e lembrar você de se mexer.

Instalação

Rode estes dois comandos dentro do Claude Code:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

Não há dependências, daemon nem telemetria. Não há mais nada para configurar.

Onde o aviso aparece

  • Uma linha na sessão.
  • Um som suave incluído.
  • Uma notificação no Warp, Ghostty, iTerm2, WezTerm e kitty. No VS Code, é preciso uma extensão de notificações.
  • Sua linha de status, se você configurar.

Adicione à sua linha de status

/vibestretch:statusline

Esse comando faz backup das suas configurações e envolve o comando de linha de status que você já usa. Se não houver nenhum, ele instala um mínimo. Depois de um aviso, o exercício fica ali por 5 minutos. Para desfazer, use /vibestretch:statusline off. Rode off antes de desinstalar o plugin.

VS Code

No terminal integrado, a linha, o som e a linha de status funcionam. No painel de chat da extensão, só o som chega até você. A notificação precisa de uma extensão de notificações nos dois casos. Isso foi verificado no Claude Code 2.1.234.

Configurações

Todas as configurações são variáveis de ambiente opcionais. Os tempos são em segundos.

VariávelPadrãoSignificado
VIBESTRETCH_MIN_TURN120O turno atual precisa durar pelo menos esse tempo.
VIBESTRETCH_MIN_ACTIVE300Tempo de agente necessário desde sua última pausa.
VIBESTRETCH_COOLDOWN900Intervalo mínimo entre avisos.
VIBESTRETCH_AWAY300Sem teclado nem mouse por esse tempo, considera-se que você saiu. Só no macOS. 0 desliga essa verificação.
VIBESTRETCH_DISABLEunsetDefina com qualquer valor para silenciar os avisos.
VIBESTRETCH_NOTIFY1Defina como 0 para remover a notificação na área de trabalho.
VIBESTRETCH_SOUND1Defina como 0 para desligar o som.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtCaminho para sua própria lista de exercícios.

Roda o Claude Code em modo headless com claude -p a partir de um script? Defina VIBESTRETCH_DISABLE=1 nele.

Perguntas frequentes

Como removo o segmento da linha de status?
Rode /vibestretch:statusline off. Faça isso antes de desinstalar o plugin, senão o segmento continua configurado, mas congelado.
O aviso chega ao modelo?
Não. O aviso é um systemMessage. Ele é mostrado para você e nunca entra no contexto do modelo.
Por que ouço dois sons?
Alguns terminais, como o iTerm2, tocam o próprio som nas notificações. Defina VIBESTRETCH_SOUND=0 para manter só o som do terminal.
