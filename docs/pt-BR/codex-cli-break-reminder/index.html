Como adicionar um lembrete de pausa ao Codex CLI

vibestretch é instalado no OpenAI Codex CLI pelo marketplace de plugins. Ele mostra uma linha de alongamento e toca um som durante turnos longos.

Instalar como plugin

codex plugin marketplace add Eliasjunit/vibestretch
codex plugin add vibestretch@vibestretch

O Codex não roda os hooks de um plugin até você revisá-los. Abra /hooks e marque como confiáveis as três entradas do vibestretch. Até lá, o plugin fica instalado, mas em silêncio.

Instalar manualmente

Um clone e um arquivo de configuração fazem o mesmo trabalho:

git clone https://github.com/Eliasjunit/vibestretch ~/.codex/vibestretch
cp ~/.codex/vibestretch/hooks/codex-hooks.json ~/.codex/hooks.json

Já tem um ~/.codex/hooks.json? Mescle nele as três entradas do nosso. Não sobrescreva o seu. O Codex pede que você confie em uma nova configuração de hooks na primeira vez que ela roda. Esse pedido é esperado.

Escolha um dos dois jeitos. Com o plugin e as entradas manuais ao mesmo tempo, cada hook roda duas vezes. Se você instalou manualmente antes da 0.8.0, remova nossas entradas de ~/.codex/hooks.json ao mudar para o plugin.

O que você recebe no Codex

Você recebe a linha na sessão e o som. Não há notificação, porque o Codex não tem um campo de saída de hook para uma sequência de terminal. Também não há segmento na linha de status. Essa barra não é programável no Codex.

O contador é compartilhado com o Claude Code e o Gemini CLI. Uma hora de espera conta uma vez só, seja qual for o agente que deixou você na cadeira. O adaptador foi testado em uma instalação real do Codex CLI 0.149.1 no macOS.

Perguntas frequentes

Instalei, mas nada acontece. Por quê?
O Codex só roda os hooks de um plugin depois que você confia neles. Abra /hooks e marque como confiáveis as três entradas do vibestretch.
Cada hook roda duas vezes. Por quê?
Você provavelmente tem o plugin e entradas manuais em ~/.codex/hooks.json. Mantenha só um dos dois.
Posso usar com codex exec?
Defina VIBESTRETCH_DISABLE=1 nesse ambiente. Execuções sem ninguém olhando não deveriam contar como tempo que você passou esperando.
