Como adicionar um lembrete de pausa ao Gemini CLI

O Gemini CLI vem com hooks ativados desde a v0.26. vibestretch adiciona três deles para lembrar você de se alongar durante turnos longos.

Instalação

Clone o repositório:

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

Depois copie o objeto hooks de ~/.gemini/vibestretch/hooks/gemini-hooks.json para ~/.gemini/settings.json. Esse arquivo guarda toda a sua configuração do Gemini, então mescle. Não substitua. Com jq, é uma linha só:

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

Se você já tem hooks próprios em BeforeAgent, AfterTool ou AfterAgent, esse comando os substitui pelos nossos. Nesse caso, adicione nossas três entradas às suas listas manualmente.

Quais hooks ele usa

  • BeforeAgent: o agente começa a trabalhar no seu prompt.
  • AfterTool: uma ferramenta terminou. O tempo de espera é somado, e um aviso aparece se estiver na hora.
  • AfterAgent: o turno terminou. A contagem é fechada.

O que você recebe no Gemini CLI

Você recebe a linha na sessão e o som. Não há notificação. O Gemini reserva o stdout de um hook só para JSON, então não há onde imprimir uma sequência de escape.

O adaptador foi testado em uma instalação real do Gemini CLI 0.56.0 no macOS. O contador é compartilhado com o Claude Code e o Codex CLI.

Perguntas frequentes

Qual versão do Gemini CLI eu preciso?
Os hooks vêm ativados desde o Gemini CLI v0.26.
A mesclagem vai sobrescrever minhas configurações?
Suas outras configurações continuam lá. Se você já tem hooks próprios em BeforeAgent, AfterTool ou AfterAgent, o jq substitui essas listas pelas nossas. Nesse caso, adicione nossas três entradas manualmente. Faça um backup do arquivo antes.
Posso usar com gemini -p?
Defina VIBESTRETCH_DISABLE=1 quando rodar o Gemini a partir de um script, cron ou bot.
