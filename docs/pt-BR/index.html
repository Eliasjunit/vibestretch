Alongue-se enquanto seu agente de código trabalha

vibestretch mostra um alongamento rápido, um mini exercício ou uma pausa para os olhos enquanto você espera um turno longo do agente. Funciona com Claude Code, Codex CLI e Gemini CLI.

claude plugin marketplace add Eliasjunit/vibestretch && claude plugin install vibestretch@vibestretch

Isso instala o plugin no Claude Code. As páginas do Codex CLI e do Gemini CLI mostram como instalar neles.

Como é um aviso

🧘 Wrist circles, 10 each way. Your tendons will thank you. · vibestretch · 7 min of agent time

Uma linha aparece na sessão. Um som suave toca. Nos terminais compatíveis, também aparece uma notificação.

Como ele decide quando avisar

vibestretch não tem horário. Ele conta uma coisa só: os minutos que um turno do agente deixou você esperando no computador. O aviso só aparece quando as três condições são verdadeiras:

  1. O turno atual está rodando há 2 minutos ou mais.
  2. Seu tempo de agente desde o último aviso soma 5 minutos ou mais.
  3. O último aviso foi há pelo menos 15 minutos.

Turnos rápidos nunca disparam o aviso. Um dia de turnos curtos não gera aviso nenhum. Não há nada para adiar, porque ele só fala quando você já está esperando. Saiba mais em pausas para alongamento enquanto agentes de IA trabalham.

O que vem incluído

  • Doze exercícios prontos: alongamentos, mini exercícios e pausas para os olhos, como a regra 20-20-20.
  • Um rodízio que nunca repete o mesmo exercício duas vezes seguidas.
  • Sua própria lista de exercícios, se preferir. Veja alongamentos na mesa para programadores.
  • Um segmento opcional na linha de status do Claude Code.

Privacidade

vibestretch são alguns scripts de shell POSIX pequenos e um som incluído. Ele não faz chamadas de rede. Não envia telemetria. Não mostra anúncios nem coloca links no seu terminal. Não adiciona nada ao contexto do modelo. O estado fica em ~/.cache/vibestretch/.

Perguntas frequentes

O que é o vibestretch?
vibestretch é um plugin para agentes de código. Ele lembra você de se alongar, se mexer ou descansar os olhos enquanto espera um turno longo do agente.
Quais agentes de código ele suporta?
Claude Code, OpenAI Codex CLI e Gemini CLI. Os três usam o mesmo contador, então uma hora de espera conta uma vez só, seja qual for o agente que deixou você na cadeira.
É um timer de pausas?
Não. Um timer segue um horário. vibestretch conta só o tempo que um turno do agente deixou você esperando, e só avisa durante essa espera.
Ele envia dados para algum lugar?
Não. Ele não faz chamadas de rede e não envia telemetria. Nada sai do seu computador.
Quanto custa?
É grátis. O vibestretch é open source sob a licença MIT, e o código está no GitHub.
Como deixo ele em silêncio?
Defina VIBESTRETCH_DISABLE com qualquer valor para silenciar os avisos. VIBESTRETCH_SOUND=0 desliga o som. VIBESTRETCH_NOTIFY=0 remove a notificação.
