Cum adaugi un memento pentru pauze în Claude Code

vibestretch este un plugin pentru Claude Code. Folosește trei hookuri ca să observe rundele lungi și să te îndemne să te miști.

Instalare

Rulează aceste două comenzi în Claude Code:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

Nu are dependențe, nici daemon, nici telemetrie. Nu mai e nimic de configurat.

Unde apare mementoul

  • O linie în sesiune.
  • Un sunet discret, inclus în plugin.
  • O notificare în Warp, Ghostty, iTerm2, WezTerm și kitty. În VS Code ai nevoie de o extensie pentru notificări.
  • Linia de stare, dacă o configurezi.

Adaugă-l în linia de stare

/vibestretch:statusline

Comanda face o copie de rezervă a setărilor și învelește comanda ta existentă pentru linia de stare. Dacă nu ai una, instalează una minimă. După un memento, exercițiul rămâne acolo 5 minute. Anulezi cu /vibestretch:statusline off. Rulează off înainte să dezinstalezi pluginul.

VS Code

În terminalul integrat funcționează linia, sunetul și linia de stare. În panoul de chat al extensiei ajunge la tine doar sunetul. Notificarea are nevoie de o extensie pentru notificări în ambele locuri. Acest lucru a fost verificat pe Claude Code 2.1.234.

Setări

Toate setările sunt variabile de mediu opționale. Timpii sunt în secunde.

VariabilăImplicitSemnificație
VIBESTRETCH_MIN_TURN120Runda curentă trebuie să dureze cel puțin atât.
VIBESTRETCH_MIN_ACTIVE300Timpul de agent necesar de la ultima pauză.
VIBESTRETCH_COOLDOWN900Intervalul minim dintre mementouri.
VIBESTRETCH_AWAY300Fără tastatură sau mouse atâta timp înseamnă că ești plecat. Doar pe macOS. 0 dezactivează această protecție.
VIBESTRETCH_DISABLEunsetSetează orice valoare ca să oprești mementourile.
VIBESTRETCH_NOTIFY1Setează 0 ca să renunți la notificarea pe desktop.
VIBESTRETCH_SOUND1Setează 0 ca să oprești sunetul.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtCalea către propria listă de exerciții.

Rulezi Claude Code fără interfață, cu claude -p, dintr-un script? Setează acolo VIBESTRETCH_DISABLE=1.

Întrebări frecvente

Cum elimin segmentul din linia de stare?
Rulează /vibestretch:statusline off. Fă asta înainte să dezinstalezi pluginul, altfel segmentul rămâne configurat, dar înghețat.
Ajunge mementoul la model?
Nu. Mementoul este un systemMessage. Îți este afișat ție și nu este adăugat niciodată în contextul modelului.
De ce aud două sunete?
Unele terminale, precum iTerm2, redau propriul sunet pentru notificări. Setează VIBESTRETCH_SOUND=0 ca să rămână doar sunetul terminalului.
