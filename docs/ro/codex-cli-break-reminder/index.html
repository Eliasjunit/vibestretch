Cum adaugi un memento pentru pauze în Codex CLI

vibestretch se instalează în OpenAI Codex CLI din marketplace-ul de pluginuri. Afișează o linie de stretching și redă un sunet în rundele lungi.

Instalare ca plugin

codex plugin marketplace add Eliasjunit/vibestretch
codex plugin add vibestretch@vibestretch

Codex nu rulează hookurile unui plugin până nu le verifici. Deschide /hooks și marchează ca de încredere cele trei intrări vibestretch. Până atunci pluginul este instalat, dar tăcut.

Instalare manuală

O clonă și un fișier de configurare fac același lucru:

git clone https://github.com/Eliasjunit/vibestretch ~/.codex/vibestretch
cp ~/.codex/vibestretch/hooks/codex-hooks.json ~/.codex/hooks.json

Ai deja un ~/.codex/hooks.json? Adaugă în el cele trei intrări din fișierul nostru. Nu îl suprascrie pe al tău. Codex îți cere să aprobi o configurare nouă de hookuri la prima rulare. Această solicitare este normală.

Alege o singură metodă. Dacă ai și pluginul, și intrările adăugate manual, fiecare hook rulează de două ori. Dacă ai instalat manual înainte de 0.8.0, șterge intrările noastre din ~/.codex/hooks.json când treci la plugin.

Ce primești în Codex

Primești linia în sesiune și sunetul. Nu există notificare, pentru că Codex nu are un câmp de ieșire pentru hookuri în care să trimiți o secvență de terminal. Nu există nici segment în linia de stare. Bara aceea nu poate fi controlată prin scripturi în Codex.

Contorul este comun cu Claude Code și Gemini CLI. O oră de așteptare se numără o singură dată, indiferent ce agent te-a ținut pe scaun. Adaptorul a fost rulat pe o instalare reală de Codex CLI 0.149.1 pe macOS.

Întrebări frecvente

L-am instalat, dar nu se întâmplă nimic. De ce?
Codex rulează hookurile unui plugin doar după ce le marchezi ca de încredere. Deschide /hooks și aprobă cele trei intrări vibestretch.
Fiecare hook rulează de două ori. De ce?
Probabil ai atât pluginul, cât și intrări adăugate manual în ~/.codex/hooks.json. Păstrează doar una dintre variante.
Îl pot folosi cu codex exec?
Setează VIBESTRETCH_DISABLE=1 în acel mediu. Rulările nesupravegheate nu ar trebui să se numere ca timp petrecut de tine în așteptare.
