Cum adaugi un memento pentru pauze în Gemini CLI

Gemini CLI vine cu hookurile activate începând cu v0.26. vibestretch adaugă trei dintre ele ca să-ți amintească de stretching în rundele lungi.

Instalare

Clonează depozitul:

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

Apoi copiază obiectul hooks din ~/.gemini/vibestretch/hooks/gemini-hooks.json în ~/.gemini/settings.json. Acel fișier conține toată configurarea Gemini, așa că îmbină conținutul. Nu înlocui fișierul. Cu jq este o singură linie:

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

Ce hookuri folosește

  • BeforeAgent: agentul începe să lucreze la promptul tău.
  • AfterTool: un instrument și-a terminat treaba. Se adaugă timpul de așteptare și apare un memento dacă e momentul.
  • AfterAgent: runda s-a încheiat. Contabilizarea se închide.

Ce primești în Gemini CLI

Primești linia în sesiune și sunetul. Nu există notificare. Gemini rezervă stdout-ul unui hook doar pentru JSON, așa că nu există unde să afișezi o secvență escape.

Adaptorul a fost rulat pe o instalare reală de Gemini CLI 0.56.0 pe macOS. Contorul este comun cu Claude Code și Codex CLI.

Întrebări frecvente

De ce versiune de Gemini CLI am nevoie?
Hookurile vin activate începând cu Gemini CLI v0.26.
Combinarea îmi suprascrie setările?
Comanda jq îmbină obiectul hooks în settings.json-ul existent. Fă mai întâi o copie de rezervă a fișierului dacă vrei să fii sigur.
Îl pot folosi cu gemini -p?
Setează VIBESTRETCH_DISABLE=1 când rulezi Gemini dintr-un script, din cron sau dintr-un bot.
