Правило 20-20-20 для глаз разработчика

Пока агент долго отвечает, вы долго смотрите в экран. В чередовании vibestretch есть упражнения для глаз, и 20-20-20 входит в их число.

Перерыв 20-20-20 в vibestretch

Так выглядит напоминание:

🧘 20-20-20: look at something 20 feet away for 20 seconds.

Посмотрите на что-нибудь на расстоянии 20 футов (около 6 м). Смотрите 20 секунд. Затем возвращайтесь к агенту.

Другие упражнения для глаз в списке

  • Медленно моргните 20 раз.
  • Разотрите ладони до тепла и накройте ими закрытые глаза на 20 секунд.
  • Встаньте и подойдите к окну.

Когда приходит напоминание

vibestretch не работает по часам. Он напоминает, пока вы ждёте долгий ответ агента, по умолчанию не чаще раза в 15 минут. Упражнения для глаз выпадают в общем чередовании из двенадцати упражнений. Как устроен расчёт времени, читайте в статье перерывы на разминку, пока работают ИИ-агенты.

Нужны только упражнения для глаз?

Составьте свой список только из тех упражнений для глаз, которые вам нравятся. По одному упражнению на строку в ~/.config/vibestretch/exercises.txt. Тогда встроенный список не используется. Пример в статье разминка за компьютером для программистов.

Частые вопросы

vibestretch напоминает каждые 20 минут?
Нет. У него нет фиксированного расписания. Он напоминает только во время долгих ответов агента, а пауза между напоминаниями по умолчанию 15 минут.
Можно оставить только упражнения для глаз?
Да. Запишите свои упражнения в ~/.config/vibestretch/exercises.txt, по одному на строку, и vibestretch будет использовать этот список вместо встроенного.
