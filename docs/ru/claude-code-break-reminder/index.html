Как добавить напоминание о перерыве в Claude Code

vibestretch работает как плагин для Claude Code. Он использует три хука, чтобы замечать долгие ответы и напоминать вам подвигаться.

Установка

Выполните эти две команды в Claude Code:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

Зависимостей, фонового процесса и телеметрии нет. Больше ничего настраивать не нужно.

Где появляется напоминание

  • Строка в сессии.
  • Тихий встроенный звуковой сигнал.
  • Баннер уведомления в Warp, Ghostty, iTerm2, WezTerm и kitty. В VS Code для него нужно расширение для уведомлений.
  • Ваша строка состояния, если вы её настроили.

Добавьте его в строку состояния

/vibestretch:statusline

Эта команда делает резервную копию настроек и оборачивает вашу текущую команду строки состояния. Если её нет, устанавливается минимальная. После напоминания упражнение остаётся там 5 минут. Отменить можно командой /vibestretch:statusline off. Выполните off перед удалением плагина.

VS Code

Во встроенном терминале работают строка, звуковой сигнал и строка состояния. В панели чата расширения до вас доходит только звуковой сигнал. Для баннера в обоих случаях нужно расширение для уведомлений. Проверено на Claude Code 2.1.234.

Настройки

Все настройки задаются необязательными переменными окружения. Время указывается в секундах.

ПеременнаяПо умолчаниюНазначение
VIBESTRETCH_MIN_TURN120Минимальная длительность текущего ответа агента.
VIBESTRETCH_MIN_ACTIVE300Сколько времени агента нужно с последнего перерыва.
VIBESTRETCH_COOLDOWN900Минимальная пауза между напоминаниями.
VIBESTRETCH_AWAY300Если клавиатура и мышь не используются столько времени, вы считаетесь отошедшим. Только macOS. 0 отключает проверку.
VIBESTRETCH_DISABLEunsetЛюбое значение отключает напоминания.
VIBESTRETCH_NOTIFY10 отключает уведомление на рабочем столе.
VIBESTRETCH_SOUND10 отключает звук.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtПуть к вашему списку упражнений.

Запускаете Claude Code без интерфейса через claude -p из скрипта? Задайте там VIBESTRETCH_DISABLE=1.

Частые вопросы

Как убрать блок из строки состояния?
Выполните /vibestretch:statusline off. Сделайте это до удаления плагина, иначе блок останется в настройках, но перестанет обновляться.
Видит ли напоминание модель?
Нет. Напоминание передаётся как systemMessage. Его видите вы, в контекст модели оно не попадает.
Почему я слышу два звука?
Некоторые терминалы, например iTerm2, проигрывают свой звук для уведомлений. Задайте VIBESTRETCH_SOUND=0, чтобы оставить только звук терминала.
