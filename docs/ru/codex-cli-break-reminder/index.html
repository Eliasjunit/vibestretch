Как добавить напоминание о перерыве в Codex CLI

vibestretch устанавливается в OpenAI Codex CLI из маркетплейса плагинов. Во время долгих ответов он показывает строку с упражнением и проигрывает звуковой сигнал.

Установка как плагин

codex plugin marketplace add Eliasjunit/vibestretch
codex plugin add vibestretch@vibestretch

Codex не запускает хуки плагина, пока вы их не проверите. Откройте /hooks и отметьте три записи vibestretch как доверенные. До этого плагин установлен, но молчит.

Установка вручную

То же самое делают клон репозитория и файл конфигурации:

git clone https://github.com/Eliasjunit/vibestretch ~/.codex/vibestretch
cp ~/.codex/vibestretch/hooks/codex-hooks.json ~/.codex/hooks.json

У вас уже есть ~/.codex/hooks.json? Добавьте в него три записи из нашего файла. Не перезаписывайте свой файл. При первом запуске Codex попросит подтвердить доверие к новой конфигурации хуков. Так и должно быть.

Выберите один способ. Если стоят и плагин, и записи, добавленные вручную, каждый хук запускается дважды. Если вы устанавливали вручную до версии 0.8.0, при переходе на плагин удалите наши записи из ~/.codex/hooks.json.

Что работает в Codex

Вы получаете строку в сессии и звуковой сигнал. Баннера уведомления нет, потому что в выводе хуков Codex нет поля для управляющей последовательности терминала. Блока в строке состояния тоже нет. Эту панель в Codex нельзя настроить скриптом.

Счётчик общий с Claude Code и Gemini CLI. Час ожидания учитывается один раз, какой бы агент вас ни задержал. Адаптер проверен на реальной установке Codex CLI 0.149.1 в macOS.

Частые вопросы

Я установил плагин, но ничего не происходит. Почему?
Codex запускает хуки плагина только после того, как вы отметите их как доверенные. Откройте /hooks и подтвердите три записи vibestretch.
Каждый хук запускается дважды. Почему?
Скорее всего, у вас есть и плагин, и записи, добавленные вручную в ~/.codex/hooks.json. Оставьте что-то одно.
Можно ли использовать его с codex exec?
Задайте VIBESTRETCH_DISABLE=1 в этом окружении. Запуски без вашего участия не должны считаться временем, которое вы просидели.
