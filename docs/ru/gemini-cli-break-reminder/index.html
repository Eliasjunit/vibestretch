Как добавить напоминание о перерыве в Gemini CLI

В Gemini CLI хуки включены по умолчанию начиная с v0.26. vibestretch добавляет три хука, чтобы напоминать о разминке во время долгих ответов.

Установка

Клонируйте репозиторий:

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

Затем скопируйте объект hooks из ~/.gemini/vibestretch/hooks/gemini-hooks.json в ~/.gemini/settings.json. В этом файле вся ваша конфигурация Gemini, поэтому объедините данные. Не заменяйте файл. С jq это одна строка:

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

Какие хуки используются

  • BeforeAgent: агент начинает работать над вашим запросом.
  • AfterTool: инструмент завершил работу. Время ожидания добавляется, и если пора, приходит напоминание.
  • AfterAgent: ответ закончен. Учёт времени закрывается.

Что работает в Gemini CLI

Вы получаете строку в сессии и звуковой сигнал. Баннера уведомления нет. Gemini отводит stdout хука только под JSON, поэтому вывести управляющую последовательность некуда.

Адаптер проверен на реальной установке Gemini CLI 0.56.0 в macOS. Счётчик общий с Claude Code и Codex CLI.

Частые вопросы

Какая версия Gemini CLI нужна?
Хуки включены по умолчанию начиная с Gemini CLI v0.26.
Слияние перезапишет мои настройки?
Команда jq добавляет объект hooks в ваш существующий settings.json. Если хотите подстраховаться, сначала сделайте резервную копию файла.
Можно ли использовать его с gemini -p?
Задайте VIBESTRETCH_DISABLE=1, когда запускаете Gemini из скрипта, cron или бота.
