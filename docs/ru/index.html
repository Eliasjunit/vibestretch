Разминайтесь, пока работает агент

vibestretch предлагает короткую растяжку, мини-тренировку или отдых для глаз, пока вы ждёте долгий ответ агента. Работает с Claude Code, Codex CLI и Gemini CLI.

claude plugin marketplace add Eliasjunit/vibestretch && claude plugin install vibestretch@vibestretch

Эта команда устанавливает плагин в Claude Code. Шаги установки для Codex CLI и Gemini CLI описаны на отдельных страницах.

Как выглядит напоминание

🧘 Wrist circles, 10 each way. Your tendons will thank you. · vibestretch · 7 min of agent time

В сессии появляется одна строка. Звучит тихий сигнал. В терминалах с поддержкой уведомлений появляется ещё и баннер.

Когда приходит напоминание

У vibestretch нет расписания. Он считает только одно: сколько минут вы просидели у компьютера в ожидании ответа агента. Напоминание приходит, только когда выполнены все три условия:

  1. Текущий ответ агента длится 2 минуты или дольше.
  2. С последнего напоминания время работы агента набралось на 5 минут или больше.
  3. Последнее напоминание было не меньше 15 минут назад.

Быстрые ответы его не запускают. Если весь день ответы короткие, вы его не услышите. Откладывать его не нужно: он говорит только тогда, когда вы и так ждёте. Подробнее в статье перерывы на разминку, пока работают ИИ-агенты.

Что вы получаете

  • Двенадцать встроенных упражнений: растяжка, мини-тренировки и отдых для глаз, например 20-20-20.
  • Чередование, при котором одно упражнение не повторяется два раза подряд.
  • Свой список упражнений, если хотите. См. разминка за компьютером для программистов.
  • Необязательный блок в строке состояния Claude Code.

Приватность

vibestretch состоит из нескольких небольших POSIX-скриптов и одного звукового файла. Он не обращается к сети. Он не отправляет телеметрию. Он не показывает рекламу и не выводит ссылки в терминал. Он ничего не добавляет в контекст модели. Его состояние хранится в ~/.cache/vibestretch/.

Частые вопросы

Что такое vibestretch?
vibestretch это плагин для ИИ-агентов для программирования. Он напоминает размяться, подвигаться или дать отдых глазам, пока вы ждёте долгий ответ агента.
Какие агенты поддерживаются?
Claude Code, OpenAI Codex CLI и Gemini CLI. У всех трёх общий счётчик, поэтому час ожидания учитывается один раз, какой бы агент вас ни задержал.
Это таймер перерывов?
Нет. Таймер работает по расписанию. vibestretch считает только время, когда вы ждали ответа агента, и напоминает только во время этого ожидания.
Он куда-нибудь отправляет данные?
Нет. Он не обращается к сети и не отправляет телеметрию. Ничего не покидает ваш компьютер.
Сколько это стоит?
Это открытый исходный код по лицензии MIT. Код лежит на GitHub.
Как его отключить?
Задайте VIBESTRETCH_DISABLE с любым значением, чтобы отключить напоминания. VIBESTRETCH_SOUND=0 выключает звук. VIBESTRETCH_NOTIFY=0 убирает баннер.
