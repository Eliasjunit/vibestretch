Stretch breaks while AI coding agents run

A coding agent can work for minutes at a time. You sit and watch. vibestretch turns that wait into a short break.

Why the wait is a good moment

Break timers fire on a schedule. They often land in the middle of a thought, and many people end up turning them off. The time an agent is busy is different. You are waiting anyway. A stretch in that gap costs you no focus.

What vibestretch counts

It counts agent time: the minutes an agent turn was running while you were at the machine. It adds them up since your last nudge. This is not how long you have been at your desk. An hour of reading and typing with quick turns in between adds almost nothing.

When a nudge fires

All three conditions must be true:

  1. The current turn has run for at least 2 minutes.
  2. Agent time since the last nudge is at least 5 minutes. One big task or several medium ones both count.
  3. The last nudge was at least 15 minutes ago.

You can change each number with an environment variable. See the Claude Code page for the full list.

When you step away

If you are away from the keyboard for 45 minutes or more, the count resets. You already had your break. On macOS the hooks read the system keyboard and mouse idle clock. So an agent working overnight adds no agent time and never chimes at an empty chair. Linux has no portable idle clock, so there only the 45-minute reset applies.

What the nudge asks you to do

Each nudge is one exercise from a list of twelve. They cover stretches, micro-workouts and eye breaks. See desk stretches for programmers for the whole list.

FAQ

Will it nudge me during short turns?
No. A turn must run for at least 2 minutes, and enough agent time must build up, before a nudge can fire.
Does a fast model mean fewer nudges?
Yes. Fast models finish turns before the thresholds are reached, so there is nothing to mute.
What about agents run from scripts or cron?
Set VIBESTRETCH_DISABLE=1 in that environment. Otherwise unattended sessions count as time you never sat through.
