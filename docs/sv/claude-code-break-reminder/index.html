Så lägger du till en pauspåminnelse i Claude Code

vibestretch är ett plugin för Claude Code. Det använder tre hookar för att märka långa turer och påminna dig om att röra på dig.

Installera

Kör de här två kommandona i Claude Code:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

Det finns inga beroenden, ingen daemon och ingen telemetri. Inget mer att konfigurera.

Var påminnelsen syns

  • En rad i sessionen.
  • Ett mjukt medföljande ljud.
  • En notisbanner i Warp, Ghostty, iTerm2, WezTerm och kitty. I VS Code krävs ett notistillägg.
  • Din statusrad, om du ställer in den.

Lägg till den i statusraden

/vibestretch:statusline

Kommandot säkerhetskopierar dina inställningar och lägger sig runt ditt befintliga statusradskommando. Har du inget installeras ett minimalt. Efter en påminnelse står övningen kvar där i 5 minuter. Ångra med /vibestretch:statusline off. Kör off innan du avinstallerar pluginet.

VS Code

I den integrerade terminalen fungerar raden, ljudet och statusraden. I tilläggets chattpanel når bara ljudet fram. Bannern kräver ett notistillägg på båda ställena. Det här kontrollerades med Claude Code 2.1.234.

Inställningar

Alla inställningar är valfria miljövariabler. Tider anges i sekunder.

VariabelStandardBetydelse
VIBESTRETCH_MIN_TURN120Den aktuella turen måste pågå minst så här länge.
VIBESTRETCH_MIN_ACTIVE300Agenttid som krävs sedan din senaste paus.
VIBESTRETCH_COOLDOWN900Minsta tid mellan påminnelser.
VIBESTRETCH_AWAY300Så här lång tid utan tangentbord eller mus betyder att du är borta. Bara macOS. 0 stänger av spärren.
VIBESTRETCH_DISABLEunsetSätt till valfritt värde för att stänga av påminnelser.
VIBESTRETCH_NOTIFY1Sätt till 0 för att ta bort skrivbordsnotisen.
VIBESTRETCH_SOUND1Sätt till 0 för att stänga av ljudet.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtSökväg till din egen lista med övningar.

Kör du Claude Code headless med claude -p från ett skript? Sätt VIBESTRETCH_DISABLE=1 där.

Vanliga frågor

Hur tar jag bort fältet i statusraden?
Kör /vibestretch:statusline off. Gör det innan du avinstallerar pluginet, annars ligger fältet kvar i inställningarna men står still.
Når påminnelsen modellen?
Nej. Påminnelsen är ett systemMessage. Den visas för dig och läggs aldrig till i modellens kontext.
Varför hör jag två ljud?
Vissa terminaler, som iTerm2, spelar ett eget ljud för notiser. Sätt VIBESTRETCH_SOUND=0 för att bara behålla terminalens ljud.
