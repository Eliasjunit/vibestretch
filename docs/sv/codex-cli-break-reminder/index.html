Så lägger du till en pauspåminnelse i Codex CLI

vibestretch installeras i OpenAI Codex CLI från pluginmarknaden. Det visar en stretchrad och spelar ett ljud under långa turer.

Installera som plugin

codex plugin marketplace add Eliasjunit/vibestretch
codex plugin add vibestretch@vibestretch

Codex kör inte ett plugins hookar förrän du har granskat dem. Öppna /hooks och godkänn de tre posterna för vibestretch. Fram till dess är pluginet installerat men tyst.

Installera för hand

En klon och en konfigurationsfil gör samma jobb:

git clone https://github.com/Eliasjunit/vibestretch ~/.codex/vibestretch
cp ~/.codex/vibestretch/hooks/codex-hooks.json ~/.codex/hooks.json

Har du redan en ~/.codex/hooks.json? Slå ihop de tre posterna från vår fil med din. Skriv inte över din. Codex ber dig godkänna en ny hookkonfiguration första gången den körs. Den frågan är väntad.

Välj ett sätt. Om både pluginet och de handskrivna posterna finns körs varje hook två gånger. Om du installerade för hand före 0.8.0, ta bort våra poster från ~/.codex/hooks.json när du byter till pluginet.

Det här får du i Codex

Du får raden i sessionen och ljudet. Det finns ingen notisbanner, eftersom Codex saknar ett utdatafält i hookar för en terminalsekvens. Det finns inte heller något fält i statusraden. Den raden går inte att skripta i Codex.

Räknaren delas med Claude Code och Gemini CLI. En timmes väntan räknas en gång, oavsett vilken agent som höll dig kvar i stolen. Adaptern kördes på en riktig installation av Codex CLI 0.149.1 på macOS.

Vanliga frågor

Jag har installerat det, men inget händer. Varför?
Codex kör ett plugins hookar först när du har godkänt dem. Öppna /hooks och godkänn de tre posterna för vibestretch.
Varje hook körs två gånger. Varför?
Du har förmodligen både pluginet och handskrivna poster i ~/.codex/hooks.json. Behåll ett av dem.
Kan jag använda det med codex exec?
Sätt VIBESTRETCH_DISABLE=1 i den miljön. Obevakade körningar ska inte räknas som tid du satt igenom.
