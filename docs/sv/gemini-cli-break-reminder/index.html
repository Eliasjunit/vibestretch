Så lägger du till en pauspåminnelse i Gemini CLI

Gemini CLI har haft hookar aktiverade sedan v0.26. vibestretch lägger till tre av dem för att påminna dig om att stretcha under långa turer.

Installera

Klona repot:

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

Kopiera sedan objektet hooks från ~/.gemini/vibestretch/hooks/gemini-hooks.json till ~/.gemini/settings.json. Den filen innehåller hela din Gemini-konfiguration, så slå ihop dem. Ersätt den inte. Med jq räcker en rad:

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

Vilka hookar den använder

  • BeforeAgent: agenten börjar arbeta med din prompt.
  • AfterTool: ett verktyg är klart. Väntetid läggs till, och en påminnelse kommer om det är dags.
  • AfterAgent: turen är över. Räkningen avslutas.

Det här får du i Gemini CLI

Du får raden i sessionen och ljudet. Det finns ingen notisbanner. Gemini reserverar en hooks stdout för enbart JSON, så det finns ingenstans att skriva ut en escapesekvens.

Adaptern kördes på en riktig installation av Gemini CLI 0.56.0 på macOS. Räknaren delas med Claude Code och Codex CLI.

Vanliga frågor

Vilken version av Gemini CLI behöver jag?
Hookar är aktiverade som standard sedan Gemini CLI v0.26.
Skriver sammanslagningen över mina inställningar?
Kommandot med jq slår ihop objektet hooks med din befintliga settings.json. Säkerhetskopiera filen först om du vill vara säker.
Kan jag använda det med gemini -p?
Sätt VIBESTRETCH_DISABLE=1 när du kör Gemini från ett skript, cron eller en bot.
