วิธีเพิ่มตัวเตือนพักเบรกใน Claude Code

vibestretch เป็นปลั๊กอินของ Claude Code มันใช้ฮุกสามตัวเพื่อจับรอบที่ยาว แล้วเตือนให้คุณลุกขยับร่างกาย

ติดตั้ง

รันสองคำสั่งนี้ใน Claude Code:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

ไม่มี dependency ไม่มี daemon และไม่มีการส่งข้อมูลการใช้งาน ไม่ต้องตั้งค่าอะไรเพิ่ม

การเตือนจะขึ้นที่ไหน

  • ข้อความหนึ่งบรรทัดในเซสชัน
  • เสียงเตือนเบา ๆ ที่มาพร้อมปลั๊กอิน
  • แบนเนอร์แจ้งเตือนใน Warp, Ghostty, iTerm2, WezTerm และ kitty ใน VS Code ต้องใช้ส่วนขยายสำหรับแจ้งเตือน
  • แถบสถานะของคุณ ถ้าตั้งค่าไว้

เพิ่มลงในแถบสถานะ

/vibestretch:statusline

คำสั่งนี้จะสำรองการตั้งค่าของคุณ แล้วครอบคำสั่งแถบสถานะเดิมที่คุณใช้อยู่ ถ้ายังไม่มี มันจะติดตั้งแบบพื้นฐานให้ หลังการเตือน ท่าจะแสดงค้างอยู่ตรงนั้น 5 นาที ยกเลิกได้ด้วย /vibestretch:statusline off ให้รัน off ก่อนถอนการติดตั้งปลั๊กอิน

VS Code

ในเทอร์มินัลในตัว ข้อความ เสียงเตือน และแถบสถานะทำงานได้ทั้งหมด ในแผงแชตของส่วนขยาย คุณจะได้ยินแค่เสียงเตือน แบนเนอร์ต้องใช้ส่วนขยายสำหรับแจ้งเตือนในทั้งสองที่ ข้อมูลนี้ทดสอบกับ Claude Code 2.1.234

การตั้งค่า

การตั้งค่าทั้งหมดเป็นตัวแปรสภาพแวดล้อมที่ไม่บังคับ เวลามีหน่วยเป็นวินาที

ตัวแปรค่าเริ่มต้นความหมาย
VIBESTRETCH_MIN_TURN120รอบปัจจุบันต้องทำงานนานอย่างน้อยเท่านี้
VIBESTRETCH_MIN_ACTIVE300เวลาเอเจนต์ที่ต้องสะสมนับจากการพักครั้งล่าสุด
VIBESTRETCH_COOLDOWN900ระยะห่างขั้นต่ำระหว่างการเตือนแต่ละครั้ง
VIBESTRETCH_AWAY300ถ้าไม่มีการใช้คีย์บอร์ดหรือเมาส์นานเท่านี้ ถือว่าคุณไม่อยู่ ใช้ได้เฉพาะ macOS ตั้งเป็น 0 เพื่อปิดการตรวจนี้
VIBESTRETCH_DISABLEunsetตั้งเป็นค่าใดก็ได้เพื่อปิดการเตือน
VIBESTRETCH_NOTIFY1ตั้งเป็น 0 เพื่อปิดการแจ้งเตือนบนเดสก์ท็อป
VIBESTRETCH_SOUND1ตั้งเป็น 0 เพื่อปิดเสียง
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtพาธไปยังรายการท่าของคุณเอง

รัน Claude Code แบบ headless ด้วย claude -p จากสคริปต์อยู่หรือเปล่า ให้ตั้ง VIBESTRETCH_DISABLE=1 ในสคริปต์นั้น

คำถามที่พบบ่อย

เอาส่วนแสดงผลในแถบสถานะออกอย่างไร
รัน /vibestretch:statusline off ให้ทำก่อนถอนการติดตั้งปลั๊กอิน ไม่อย่างนั้นส่วนนี้จะยังอยู่ในการตั้งค่าแต่ค้างไม่อัปเดต
การเตือนส่งไปถึงโมเดลไหม
ไม่ การเตือนเป็น systemMessage มันแสดงให้คุณเห็นเท่านั้น และไม่ถูกเพิ่มลงในบริบทของโมเดล
ทำไมได้ยินเสียงสองครั้ง
เทอร์มินัลบางตัว เช่น iTerm2 จะเล่นเสียงของตัวเองเมื่อมีการแจ้งเตือน ตั้งค่า VIBESTRETCH_SOUND=0 เพื่อให้เหลือแค่เสียงของเทอร์มินัล
