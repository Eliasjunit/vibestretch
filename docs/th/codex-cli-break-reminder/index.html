วิธีเพิ่มตัวเตือนพักเบรกใน Codex CLI

vibestretch ติดตั้งใน OpenAI Codex CLI ได้จาก plugin marketplace มันจะแสดงข้อความชวนยืดเส้นและเล่นเสียงเตือนระหว่างรอบยาว

ติดตั้งแบบปลั๊กอิน

codex plugin marketplace add Eliasjunit/vibestretch
codex plugin add vibestretch@vibestretch

Codex จะไม่รันฮุกของปลั๊กอินจนกว่าคุณจะตรวจสอบมันก่อน เปิด /hooks แล้วกดเชื่อถือรายการ vibestretch ทั้งสามรายการ ก่อนหน้านั้นปลั๊กอินจะติดตั้งอยู่แต่ไม่ทำงาน

ติดตั้งเอง

โคลนรีโพแล้วเพิ่มไฟล์คอนฟิกหนึ่งไฟล์ ก็ได้ผลเหมือนกัน:

git clone https://github.com/Eliasjunit/vibestretch ~/.codex/vibestretch
cp ~/.codex/vibestretch/hooks/codex-hooks.json ~/.codex/hooks.json

มีไฟล์ ~/.codex/hooks.json อยู่แล้วหรือเปล่า ให้รวมสามรายการจากไฟล์ของเราเข้าไป อย่าเขียนทับไฟล์ของคุณ ครั้งแรกที่ Codex เจอคอนฟิกฮุกใหม่ มันจะถามว่าคุณเชื่อถือหรือไม่ ข้อความนี้เป็นเรื่องปกติ

เลือกวิธีเดียว ถ้ามีทั้งปลั๊กอินและรายการที่เพิ่มเอง ฮุกทุกตัวจะรันสองครั้ง ถ้าคุณเคยติดตั้งเองก่อนเวอร์ชัน 0.8.0 ให้ลบรายการของเราออกจาก ~/.codex/hooks.json เมื่อเปลี่ยนมาใช้ปลั๊กอิน

ใน Codex จะได้อะไรบ้าง

คุณจะได้ข้อความในเซสชันและเสียงเตือน ไม่มีแบนเนอร์แจ้งเตือน เพราะเอาต์พุตของฮุกใน Codex ไม่มีช่องสำหรับส่ง terminal sequence และไม่มีส่วนแสดงผลในแถบสถานะด้วย เพราะแถบนั้นใน Codex เขียนสคริปต์ควบคุมไม่ได้

ตัวนับใช้ร่วมกับ Claude Code และ Gemini CLI การรอหนึ่งชั่วโมงจึงนับแค่ครั้งเดียว ไม่ว่าเอเจนต์ตัวไหนจะทำให้คุณต้องนั่งรอ ตัวเชื่อมนี้ผ่านการรันบน Codex CLI 0.149.1 ที่ติดตั้งใช้งานจริงบน macOS

คำถามที่พบบ่อย

ติดตั้งแล้วแต่ไม่มีอะไรเกิดขึ้น ทำไม
Codex จะรันฮุกของปลั๊กอินหลังจากที่คุณกดเชื่อถือแล้วเท่านั้น เปิด /hooks แล้วกดเชื่อถือรายการ vibestretch ทั้งสามรายการ
ฮุกทุกตัวรันสองครั้ง ทำไม
คุณน่าจะมีทั้งปลั๊กอินและรายการที่เพิ่มเองใน ~/.codex/hooks.json ให้เก็บไว้แค่อย่างเดียว
ใช้กับ codex exec ได้ไหม
ตั้งค่า VIBESTRETCH_DISABLE=1 ในสภาพแวดล้อมนั้น การรันที่ไม่มีคนเฝ้าไม่ควรถูกนับเป็นเวลาที่คุณนั่งรอ
