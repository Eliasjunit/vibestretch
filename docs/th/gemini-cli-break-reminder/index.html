วิธีเพิ่มตัวเตือนพักเบรกใน Gemini CLI

Gemini CLI เปิดใช้ฮุกเป็นค่าเริ่มต้นตั้งแต่ v0.26 vibestretch เพิ่มฮุกสามตัวเพื่อเตือนให้คุณยืดเส้นระหว่างรอบยาว

ติดตั้ง

โคลนรีโพ:

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

จากนั้นคัดลอกออบเจกต์ hooks จาก ~/.gemini/vibestretch/hooks/gemini-hooks.json ไปไว้ใน ~/.gemini/settings.json ไฟล์นั้นเก็บการตั้งค่า Gemini ทั้งหมดของคุณ จึงต้องรวมเข้าไป อย่าแทนที่ทั้งไฟล์ ถ้าใช้ jq ทำได้ในบรรทัดเดียว:

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

ใช้ฮุกตัวไหนบ้าง

  • BeforeAgent: เอเจนต์เริ่มทำงานตามพรอมต์ของคุณ
  • AfterTool: เครื่องมือตัวหนึ่งทำงานเสร็จ ระบบเพิ่มเวลารอ และถ้าถึงเวลาก็จะเตือน
  • AfterAgent: จบรอบแล้ว การนับเวลาของรอบนี้ปิดลง

ใน Gemini CLI จะได้อะไรบ้าง

คุณจะได้ข้อความในเซสชันและเสียงเตือน ไม่มีแบนเนอร์แจ้งเตือน Gemini สงวน stdout ของฮุกไว้สำหรับ JSON เท่านั้น จึงไม่มีที่ให้พิมพ์ escape sequence

ตัวเชื่อมนี้ผ่านการรันบน Gemini CLI 0.56.0 ที่ติดตั้งใช้งานจริงบน macOS ตัวนับใช้ร่วมกับ Claude Code และ Codex CLI

คำถามที่พบบ่อย

ต้องใช้ Gemini CLI เวอร์ชันไหน
ฮุกเปิดใช้เป็นค่าเริ่มต้นตั้งแต่ Gemini CLI v0.26
การรวมจะเขียนทับการตั้งค่าของฉันไหม
คำสั่ง jq จะรวมออบเจกต์ hooks เข้าไปใน settings.json ที่คุณมีอยู่ ถ้าอยากให้ชัวร์ ให้สำรองไฟล์ไว้ก่อน
ใช้กับ gemini -p ได้ไหม
ตั้งค่า VIBESTRETCH_DISABLE=1 เมื่อรัน Gemini จากสคริปต์ cron หรือบอต
