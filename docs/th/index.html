ยืดเส้นระหว่างที่เอเจนต์เขียนโค้ดทำงาน

เมื่อเอเจนต์ทำงานรอบยาวจนคุณต้องนั่งรอ vibestretch จะแสดงท่ายืดเส้นสั้น ๆ การออกกำลังกายสั้น ๆ หรือการพักสายตา ใช้ได้กับ Claude Code, Codex CLI และ Gemini CLI

claude plugin marketplace add Eliasjunit/vibestretch && claude plugin install vibestretch@vibestretch

คำสั่งนี้ติดตั้งปลั๊กอินใน Claude Code ส่วนวิธีติดตั้งสำหรับ Codex CLI และ Gemini CLI ดูได้ในหน้าของแต่ละตัว

หน้าตาของการเตือน

🧘 Wrist circles, 10 each way. Your tendons will thank you. · vibestretch · 7 min of agent time

จะมีข้อความหนึ่งบรรทัดขึ้นในเซสชัน พร้อมเสียงเตือนเบา ๆ ถ้าเทอร์มินัลรองรับ ก็จะมีแบนเนอร์แจ้งเตือนขึ้นมาด้วย

เตือนเมื่อไหร่

vibestretch ไม่มีตารางเวลา มันนับแค่อย่างเดียว คือจำนวนนาทีที่รอบการทำงานของเอเจนต์ทำให้คุณต้องนั่งรออยู่หน้าเครื่อง การเตือนจะเกิดขึ้นเมื่อครบทั้งสามข้อนี้:

  1. รอบปัจจุบันทำงานมาแล้วอย่างน้อย 2 นาที
  2. เวลาเอเจนต์ที่สะสมตั้งแต่การเตือนครั้งล่าสุดรวมได้อย่างน้อย 5 นาที
  3. การเตือนครั้งล่าสุดผ่านมาแล้วอย่างน้อย 15 นาที

รอบที่จบเร็วจะไม่ทำให้เกิดการเตือน ถ้าทั้งวันมีแต่รอบสั้น ๆ ก็จะไม่มีการเตือนเลย ไม่ต้องกดเลื่อนการเตือน เพราะมันจะเตือนเฉพาะตอนที่คุณกำลังรออยู่แล้ว อ่านเพิ่มเติมที่ ยืดเส้นระหว่างที่เอเจนต์เขียนโค้ด AI ทำงาน

มีอะไรให้บ้าง

  • ท่าในตัว 12 ท่า ทั้งท่ายืดเส้น การออกกำลังกายสั้น ๆ และการพักสายตา เช่น 20-20-20
  • การวนท่าที่ไม่ให้ท่าเดิมซ้ำสองครั้งติดกัน
  • ใช้รายการท่าของคุณเองได้ถ้าต้องการ ดู ท่ายืดเส้นที่โต๊ะทำงานสำหรับโปรแกรมเมอร์
  • ส่วนแสดงผลในแถบสถานะของ Claude Code ซึ่งจะเปิดใช้หรือไม่ก็ได้

ความเป็นส่วนตัว

vibestretch คือสคริปต์ POSIX shell ขนาดเล็กไม่กี่ไฟล์กับไฟล์เสียงหนึ่งไฟล์ที่มาด้วยกัน มันไม่เชื่อมต่อเครือข่าย ไม่ส่งข้อมูลการใช้งาน ไม่แสดงโฆษณา และไม่ใส่ลิงก์ในเทอร์มินัลของคุณ มันไม่เพิ่มอะไรลงในบริบทของโมเดล สถานะของมันเก็บไว้ที่ ~/.cache/vibestretch/

คำถามที่พบบ่อย

vibestretch คืออะไร
vibestretch เป็นปลั๊กอินสำหรับเอเจนต์เขียนโค้ด มันเตือนให้คุณยืดเส้น ขยับร่างกาย หรือพักสายตา ระหว่างที่เอเจนต์ทำงานรอบยาวจนคุณต้องรอ
รองรับเอเจนต์เขียนโค้ดตัวไหนบ้าง
Claude Code, OpenAI Codex CLI และ Gemini CLI ทั้งสามใช้ตัวนับเดียวกัน การรอหนึ่งชั่วโมงจึงนับแค่ครั้งเดียว ไม่ว่าเอเจนต์ตัวไหนจะทำให้คุณต้องนั่งรอ
เป็นตัวจับเวลาพักเบรกหรือเปล่า
ไม่ใช่ ตัวจับเวลาทำงานตามตารางเวลา vibestretch นับเฉพาะเวลาที่รอบการทำงานของเอเจนต์ทำให้คุณต้องรอ และเตือนเฉพาะระหว่างที่รออยู่
มีการส่งข้อมูลไปที่ไหนไหม
ไม่มี มันไม่เชื่อมต่อเครือข่ายและไม่ส่งข้อมูลการใช้งาน ไม่มีข้อมูลใดออกจากเครื่องของคุณ
