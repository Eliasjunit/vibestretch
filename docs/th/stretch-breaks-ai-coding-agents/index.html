ยืดเส้นระหว่างที่เอเจนต์เขียนโค้ด AI ทำงาน

เอเจนต์เขียนโค้ดอาจทำงานต่อเนื่องหลายนาที คุณได้แต่นั่งดู vibestretch เปลี่ยนช่วงรอนั้นให้เป็นการพักสั้น ๆ

ทำไมช่วงรอถึงเหมาะกับการพัก

ตัวจับเวลาพักเบรกจะเตือนตามตารางเวลา มันมักดังขึ้นตอนที่คุณกำลังคิดงานอยู่ หลายคนจึงปิดมันไปในที่สุด ช่วงที่เอเจนต์กำลังทำงานต่างออกไป คุณรออยู่แล้ว การยืดเส้นในช่วงนั้นจึงไม่เสียสมาธิ

vibestretch นับอะไร

มันนับเวลาเอเจนต์ คือจำนวนนาทีที่รอบการทำงานของเอเจนต์กำลังรันอยู่ขณะที่คุณอยู่หน้าเครื่อง แล้วรวมเวลาตั้งแต่การเตือนครั้งล่าสุด ตัวเลขนี้ไม่เกี่ยวกับว่าคุณนั่งที่โต๊ะมานานแค่ไหน การอ่านและพิมพ์หนึ่งชั่วโมงโดยมีรอบสั้น ๆ คั่นอยู่ แทบไม่ทำให้เวลาเพิ่มขึ้น

การเตือนเกิดขึ้นเมื่อไหร่

ต้องครบทั้งสามเงื่อนไข:

  1. รอบปัจจุบันทำงานมาแล้วอย่างน้อย 2 นาที
  2. เวลาเอเจนต์ตั้งแต่การเตือนครั้งล่าสุดรวมได้อย่างน้อย 5 นาที จะเป็นงานใหญ่งานเดียวหรืองานขนาดกลางหลายงานก็นับเหมือนกัน
  3. การเตือนครั้งล่าสุดผ่านมาแล้วอย่างน้อย 15 นาที

ตัวเลขแต่ละตัวเปลี่ยนได้ด้วยตัวแปรสภาพแวดล้อม ดูรายการทั้งหมดได้ที่ หน้า Claude Code

เมื่อคุณลุกออกไป

ถ้าคุณไม่ได้แตะคีย์บอร์ดนาน 45 นาทีขึ้นไป เวลาที่สะสมไว้จะถูกรีเซ็ต เพราะคุณได้พักไปแล้ว บน macOS ฮุกจะอ่านเวลาว่างของคีย์บอร์ดและเมาส์จากระบบ เอเจนต์ที่ทำงานข้ามคืนจึงไม่เพิ่มเวลาเอเจนต์ และไม่ส่งเสียงเตือนใส่เก้าอี้ว่าง Linux ไม่มีวิธีอ่านเวลาว่างที่ใช้ได้ทั่วไป บน Linux จึงมีแค่การรีเซ็ตหลัง 45 นาที

การเตือนให้คุณทำอะไร

การเตือนแต่ละครั้งคือหนึ่งท่าจากรายการ 12 ท่า มีทั้งท่ายืดเส้น การออกกำลังกายสั้น ๆ และการพักสายตา ดูรายการทั้งหมดที่ ท่ายืดเส้นที่โต๊ะทำงานสำหรับโปรแกรมเมอร์

คำถามที่พบบ่อย

รอบสั้น ๆ จะมีการเตือนไหม
ไม่มี รอบนั้นต้องทำงานอย่างน้อย 2 นาที และต้องมีเวลาเอเจนต์สะสมมากพอ จึงจะเตือนได้
โมเดลที่เร็วจะเตือนน้อยลงไหม
ใช่ โมเดลที่เร็วทำรอบเสร็จก่อนถึงเกณฑ์ จึงไม่มีอะไรต้องปิด
ถ้ารันเอเจนต์จากสคริปต์หรือ cron ล่ะ
ตั้งค่า VIBESTRETCH_DISABLE=1 ในสภาพแวดล้อมนั้น ไม่อย่างนั้นเซสชันที่ไม่มีคนเฝ้าจะถูกนับเป็นเวลารอ ทั้งที่คุณไม่ได้นั่งรออยู่จริง
