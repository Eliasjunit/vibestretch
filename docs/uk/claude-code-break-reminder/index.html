Як додати нагадування про перерву в Claude Code

vibestretch це плагін для Claude Code. Він використовує три хуки, щоб помічати довгі відповіді й нагадувати вам порухатися.

Встановлення

Виконайте ці дві команди в Claude Code:

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

Залежностей, фонового процесу й телеметрії немає. Більше нічого налаштовувати не потрібно.

Де з'являється нагадування

  • Рядок у сесії.
  • Тихий вбудований звуковий сигнал.
  • Банер сповіщення у Warp, Ghostty, iTerm2, WezTerm і kitty. У VS Code для нього потрібне розширення для сповіщень.
  • Ваш рядок стану, якщо ви його налаштували.

Додайте його в рядок стану

/vibestretch:statusline

Ця команда робить резервну копію налаштувань і обгортає вашу поточну команду рядка стану. Якщо її немає, встановлюється мінімальна. Після нагадування вправа залишається там 5 хвилин. Скасувати можна командою /vibestretch:statusline off. Виконайте off перед видаленням плагіна.

VS Code

У вбудованому терміналі працюють рядок, звуковий сигнал і рядок стану. У панелі чату розширення до вас доходить лише звуковий сигнал. Для банера в обох випадках потрібне розширення для сповіщень. Перевірено на Claude Code 2.1.234.

Налаштування

Усі налаштування задаються необов'язковими змінними середовища. Час вказується в секундах.

ЗміннаЗа замовчуваннямПризначення
VIBESTRETCH_MIN_TURN120Мінімальна тривалість поточної відповіді агента.
VIBESTRETCH_MIN_ACTIVE300Скільки часу агента потрібно від останньої перерви.
VIBESTRETCH_COOLDOWN900Мінімальна пауза між нагадуваннями.
VIBESTRETCH_AWAY300Якщо клавіатура й миша не використовуються стільки часу, вважається, що ви відійшли. Лише macOS. 0 вимикає перевірку.
VIBESTRETCH_DISABLEunsetБудь-яке значення вимикає нагадування.
VIBESTRETCH_NOTIFY10 вимикає сповіщення на робочому столі.
VIBESTRETCH_SOUND10 вимикає звук.
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txtШлях до вашого списку вправ.

Запускаєте Claude Code без інтерфейсу через claude -p зі скрипта? Задайте там VIBESTRETCH_DISABLE=1.

Часті запитання

Як прибрати блок із рядка стану?
Виконайте /vibestretch:statusline off. Зробіть це до видалення плагіна, інакше блок залишиться в налаштуваннях, але перестане оновлюватися.
Чи бачить нагадування модель?
Ні. Нагадування передається як systemMessage. Його бачите ви, до контексту моделі воно не потрапляє.
Чому я чую два звуки?
Деякі термінали, наприклад iTerm2, відтворюють власний звук для сповіщень. Задайте VIBESTRETCH_SOUND=0, щоб залишити лише звук термінала.
