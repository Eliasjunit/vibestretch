Як додати нагадування про перерву в Gemini CLI

У Gemini CLI хуки ввімкнені за замовчуванням починаючи з v0.26. vibestretch додає три хуки, щоб нагадувати про розминку під час довгих відповідей.

Встановлення

Клонуйте репозиторій:

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

Потім скопіюйте об'єкт hooks з ~/.gemini/vibestretch/hooks/gemini-hooks.json у ~/.gemini/settings.json. У цьому файлі вся ваша конфігурація Gemini, тому об'єднайте дані. Не замінюйте файл. З jq це один рядок:

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

Якщо у вас уже є власні хуки в BeforeAgent, AfterTool або AfterAgent, ця команда замінить їх нашими. Тоді додайте три наші записи до своїх списків вручну.

Які хуки використовуються

  • BeforeAgent: агент починає працювати над вашим запитом.
  • AfterTool: інструмент завершив роботу. Час очікування додається, і якщо час настав, надходить нагадування.
  • AfterAgent: відповідь завершено. Облік часу закривається.

Що працює в Gemini CLI

Ви отримуєте рядок у сесії та звуковий сигнал. Банера сповіщення немає. Gemini відводить stdout хука лише під JSON, тому вивести керуючу послідовність нікуди.

Адаптер перевірено на реальному встановленні Gemini CLI 0.56.0 у macOS. Лічильник спільний із Claude Code і Codex CLI.

Часті запитання

Яка версія Gemini CLI потрібна?
Хуки ввімкнені за замовчуванням починаючи з Gemini CLI v0.26.
Об'єднання перезапише мої налаштування?
Інші налаштування зберігаються. Якщо у вас уже є власні хуки в BeforeAgent, AfterTool або AfterAgent, jq замінить ці списки нашими. Тоді додайте три наші записи вручну. Спершу зробіть резервну копію файлу.
Чи можна використовувати його з gemini -p?
Задайте VIBESTRETCH_DISABLE=1, коли запускаєте Gemini зі скрипта, cron або бота.
