如何为 Claude Code 添加休息提醒

vibestretch 是一个 Claude Code 插件。它通过三个钩子识别长时间运行的轮次，并提醒你起身活动。

安装

在 Claude Code 中运行以下两条命令：

/plugin marketplace add Eliasjunit/vibestretch
/plugin install vibestretch@vibestretch

没有依赖，没有守护进程，也没有遥测。无需其他配置。

提醒显示在哪里

  • 会话中的一行提示。
  • 一声内置的轻柔提示音。
  • 在 Warp、Ghostty、iTerm2、WezTerm 和 kitty 中显示通知横幅。在 VS Code 中需要安装通知类扩展。
  • 你的状态栏（如果你设置了的话）。

添加到状态栏

/vibestretch:statusline

这条命令会备份你的设置，并包装你现有的状态栏命令。如果你还没有状态栏，它会安装一个最简版本。提醒触发后，动作会在那里显示 5 分钟。用 /vibestretch:statusline off 撤销。卸载插件之前，请先运行 off。

VS Code

在集成终端中，提示行、提示音和状态栏都能正常工作。在扩展的聊天面板中，你只能听到提示音。在这两处，通知横幅都需要通知类扩展。以上已在 Claude Code 2.1.234 上验证。

设置

所有设置都是可选的环境变量。时间单位为秒。

变量默认值说明
VIBESTRETCH_MIN_TURN120当前轮次至少要运行这么久。
VIBESTRETCH_MIN_ACTIVE300自上次休息以来所需的智能体时间。
VIBESTRETCH_COOLDOWN900两次提醒之间的最短间隔。
VIBESTRETCH_AWAY300键盘和鼠标无操作达到这个时长，即视为你已离开。仅限 macOS。设为 0 关闭此判断。
VIBESTRETCH_DISABLEunset设为任意值即可关闭提醒。
VIBESTRETCH_NOTIFY1设为 0 关闭桌面通知。
VIBESTRETCH_SOUND1设为 0 关闭声音。
VIBESTRETCH_EXERCISES~/.config/vibestretch/exercises.txt你自己的动作列表的路径。

在脚本中用 claude -p 以无头模式运行 Claude Code？请在那里设置 VIBESTRETCH_DISABLE=1。

常见问题

如何移除状态栏片段？
运行 /vibestretch:statusline off。请在卸载插件之前执行。否则该片段会留在配置中，但不再更新。
提醒会发送给模型吗？
不会。提醒是一条 systemMessage。它只显示给你看，不会加入模型的上下文。
为什么我听到两个声音？
有些终端（例如 iTerm2）会为通知播放自己的声音。设置 VIBESTRETCH_SOUND=0，只保留终端的声音。
