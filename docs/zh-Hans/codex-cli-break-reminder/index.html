如何为 Codex CLI 添加休息提醒

vibestretch 可以从插件市场安装到 OpenAI Codex CLI。在长时间运行的轮次中，它会显示一行拉伸提示并播放提示音。

以插件方式安装

codex plugin marketplace add Eliasjunit/vibestretch
codex plugin add vibestretch@vibestretch

在你审核插件的钩子之前，Codex 不会运行它们。打开 /hooks，信任三个 vibestretch 条目。在此之前，插件虽已安装，但不会有任何动静。

手动安装

克隆仓库，再加一个配置文件，效果相同：

git clone https://github.com/Eliasjunit/vibestretch ~/.codex/vibestretch
cp ~/.codex/vibestretch/hooks/codex-hooks.json ~/.codex/hooks.json

已经有 ~/.codex/hooks.json 了？把我们文件中的三个条目合并进去。不要覆盖你的文件。Codex 首次运行新的钩子配置时，会请你确认信任。出现这个提示是正常的。

两种方式选一种。如果插件和手动添加的条目同时存在，每个钩子都会运行两次。如果你在 0.8.0 之前手动安装过，换成插件时，请从 ~/.codex/hooks.json 中删除我们的条目。

在 Codex 中能得到什么

你会看到会话中的提示行，并听到提示音。没有通知横幅，因为 Codex 的钩子输出中没有可以传递终端序列的字段。也没有状态栏片段。Codex 的状态栏不支持脚本。

计数器与 Claude Code 和 Gemini CLI 共用。无论是哪个智能体让你坐在椅子上，一小时的等待只计一次。该适配器已在 macOS 上实际安装的 Codex CLI 0.149.1 中运行过。

常见问题

装好了，但没有任何反应。为什么？
Codex 只有在你信任插件的钩子之后才会运行它们。打开 /hooks，信任三个 vibestretch 条目。
每个钩子都运行了两次。为什么？
你可能既装了插件，又在 ~/.codex/hooks.json 中手动添加了条目。两者保留一个即可。
可以配合 codex exec 使用吗？
在那个环境中设置 VIBESTRETCH_DISABLE=1。无人值守的运行不应算作你坐着等待的时间。
