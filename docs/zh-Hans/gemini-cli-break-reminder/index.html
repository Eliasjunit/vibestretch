如何为 Gemini CLI 添加休息提醒

Gemini CLI 从 v0.26 起默认启用钩子。vibestretch 添加其中三个钩子，在长时间运行的轮次中提醒你拉伸。

安装

克隆仓库：

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

然后把 ~/.gemini/vibestretch/hooks/gemini-hooks.json 中的 hooks 对象复制到 ~/.gemini/settings.json。该文件保存着你的全部 Gemini 配置，所以请合并，不要替换。用 jq 只需一行：

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

如果你在 BeforeAgent、AfterTool 或 AfterAgent 下已经有自己的钩子，这条命令会用我们的钩子替换它们。这种情况下，请手动把我们的三个条目加进你的列表。

使用了哪些钩子

  • BeforeAgent：智能体开始处理你的提示词。
  • AfterTool：某个工具执行完毕。累加等待时间。如果到了该提醒的时候，就触发提醒。
  • AfterAgent：本轮结束。统计随之结束。

在 Gemini CLI 中能得到什么

你会看到会话中的提示行，并听到提示音。没有通知横幅。Gemini 规定钩子的 stdout 只能输出 JSON，所以没有地方输出转义序列。

该适配器已在 macOS 上实际安装的 Gemini CLI 0.56.0 中运行过。计数器与 Claude Code 和 Codex CLI 共用。

常见问题

需要哪个版本的 Gemini CLI？
Gemini CLI 从 v0.26 起默认启用钩子。
合并会覆盖我的设置吗？
其他设置会保留。但如果你在 BeforeAgent、AfterTool 或 AfterAgent 下已经有自己的钩子，jq 会用我们的列表替换它们。这种情况下，请手动添加我们的三个条目。请先备份该文件。
可以配合 gemini -p 使用吗？
从脚本、cron 或机器人运行 Gemini 时，请设置 VIBESTRETCH_DISABLE=1。
