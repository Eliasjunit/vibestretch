编程智能体工作时，起来拉伸一下

智能体的一轮长任务让你干等时，vibestretch 会显示一个简短的拉伸动作、微运动或护眼休息。它支持 Claude Code、Codex CLI 和 Gemini CLI。

claude plugin marketplace add Eliasjunit/vibestretch && claude plugin install vibestretch@vibestretch

这会在 Claude Code 中安装插件。Codex CLI 和 Gemini CLI 的页面介绍了各自的安装步骤。

提醒是什么样子

🧘 Wrist circles, 10 each way. Your tendons will thank you. · vibestretch · 7 min of agent time

会话中会出现一行提示，同时响起一声轻柔的提示音。在支持通知的终端里，还会弹出通知横幅。

它如何决定何时提醒

vibestretch 没有固定的时间表。它只统计一件事：智能体的任务让你在电脑前等了多少分钟。只有同时满足以下三个条件，才会提醒：

  1. 当前这一轮已运行 2 分钟或以上。
  2. 自上次提醒以来，智能体累计运行时间达到 5 分钟或以上。
  3. 距上次提醒至少过了 15 分钟。

很快结束的轮次不会触发提醒。一整天都是短轮次，它就一声不响。它也没有“稍后提醒”，因为它只在你本来就在等待时出声。详见AI 编程智能体运行时的拉伸休息。

功能

  • 12 个内置动作：拉伸、微运动和护眼休息，例如 20-20-20。
  • 轮换时不会连续两次出现同一个动作。
  • 你也可以使用自己的动作列表。参见程序员办公桌拉伸。
  • Claude Code 中可选的状态栏片段。

隐私

vibestretch 由几个小巧的 POSIX shell 脚本和一个内置音效组成。它不发起任何网络请求，不发送遥测数据。它不显示广告，也不会在终端里插入链接。它不会向模型的上下文添加任何内容。它的状态保存在 ~/.cache/vibestretch/。

常见问题

vibestretch 是什么？
vibestretch 是一款编程智能体插件。智能体的一轮长任务让你等待时，它会提醒你拉伸、活动一下或让眼睛休息。
它支持哪些编程智能体？
Claude Code、OpenAI Codex CLI 和 Gemini CLI。三者共用同一个计数器。无论是哪个智能体让你坐在椅子上，一小时的等待只计一次。
它是休息计时器吗？
不是。计时器按固定时间表运行。vibestretch 只统计智能体任务让你等待的时间，也只在等待期间提醒你。
它会把数据发送到别处吗？
不会。它不发起网络请求，也不发送遥测数据。任何数据都不会离开你的电脑。
它要多少钱？
它是开源软件，采用 MIT 许可证。代码托管在 GitHub 上。
如何让它静音？
将 VIBESTRETCH_DISABLE 设为任意值，即可关闭提醒。VIBESTRETCH_SOUND=0 关闭声音。VIBESTRETCH_NOTIFY=0 关闭通知横幅。
