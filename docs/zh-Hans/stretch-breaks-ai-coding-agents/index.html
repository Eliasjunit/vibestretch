AI 编程智能体运行时的拉伸休息

编程智能体一次可能要工作好几分钟。你只能坐着看。vibestretch 把这段等待变成一次短暂的休息。

为什么等待是休息的好时机

休息计时器按固定时间表响起。它们常常打断你的思路，很多人最后干脆把它关掉。智能体忙碌的时间不一样。你反正都在等。在这个空档拉伸一下，不会影响你的专注。

vibestretch 统计什么

它统计智能体时间：你在电脑前时，智能体任务运行的分钟数。它从上次提醒开始累加。这与你在桌前坐了多久无关。一小时里你在阅读和打字，中间穿插几次很快的轮次，几乎不会累加时间。

何时触发提醒

必须同时满足三个条件：

  1. 当前这一轮已运行至少 2 分钟。
  2. 自上次提醒以来，智能体时间至少 5 分钟。一个大任务或几个中等任务都算。
  3. 距上次提醒至少过了 15 分钟。

每个数值都可以通过环境变量修改。完整列表见 Claude Code 页面。

当你离开电脑时

如果你离开键盘 45 分钟或更久，累计时间会清零。你已经休息过了。在 macOS 上，钩子会读取系统的键盘和鼠标空闲时间。因此，智能体通宵工作不会累加智能体时间，也不会对着空椅子响铃。Linux 没有通用的空闲时间接口，所以在 Linux 上只适用 45 分钟清零规则。

提醒会让你做什么

每次提醒是 12 个动作中的一个，涵盖拉伸、微运动和护眼休息。完整列表见程序员办公桌拉伸。

常见问题

短轮次时它会提醒我吗？
不会。一轮任务必须运行至少 2 分钟，并且累计了足够的智能体时间，才可能触发提醒。
模型越快，提醒就越少吗？
是的。快速模型在达到阈值之前就完成了轮次，所以没有什么需要静音的。
通过脚本或 cron 运行的智能体怎么办？
在那个环境中设置 VIBESTRETCH_DISABLE=1。否则，无人值守的会话也会被计入，尽管你并没有坐在那里等。
