如何在 Gemini CLI 加上休息提醒

Gemini CLI 從 v0.26 起預設啟用 hook。vibestretch 加入其中三個 hook，在回合跑很久時提醒你伸展。

安裝

clone 儲存庫：

git clone https://github.com/Eliasjunit/vibestretch ~/.gemini/vibestretch

接著把 ~/.gemini/vibestretch/hooks/gemini-hooks.json 中的 hooks 物件複製到 ~/.gemini/settings.json。這個檔案存有你全部的 Gemini 設定，所以請用合併的方式。不要直接取代。用 jq 只要一行：

jq -s '.[0] * .[1]' ~/.gemini/settings.json ~/.gemini/vibestretch/hooks/gemini-hooks.json > /tmp/s.json && mv /tmp/s.json ~/.gemini/settings.json

用到哪些 hook

  • BeforeAgent：程式代理開始處理你的提示。
  • AfterTool：某個工具執行完畢。累加等待時間。如果該提醒了，就會跳出提醒。
  • AfterAgent：回合結束。這一輪的計算也跟著結束。

在 Gemini CLI 中有哪些功能

你會在工作階段中看到提醒文字，也會聽到提示音。沒有通知橫幅。Gemini 規定 hook 的 stdout 只能輸出 JSON，所以沒有地方可以輸出跳脫序列。

這個轉接程式已在 macOS 上實際安裝的 Gemini CLI 0.56.0 執行過。計數器與 Claude Code 和 Codex CLI 共用。

常見問題

需要哪個版本的 Gemini CLI？
Gemini CLI 從 v0.26 起預設啟用 hook。
合併會覆蓋我的設定嗎？
這個 jq 指令會把 hooks 物件合併到你現有的 settings.json。想保險一點的話，請先備份這個檔案。
可以搭配 gemini -p 使用嗎？
從指令碼、cron 或機器人執行 Gemini 時，請設定 VIBESTRETCH_DISABLE=1。
