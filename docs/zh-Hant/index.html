程式代理在跑，你可以起來伸展

程式代理跑一個很長的回合、讓你乾等的時候，vibestretch 會顯示一個簡短的伸展、小運動或讓眼睛休息的動作。支援 Claude Code、Codex CLI 和 Gemini CLI。

claude plugin marketplace add Eliasjunit/vibestretch && claude plugin install vibestretch@vibestretch

這會在 Claude Code 安裝外掛程式。Codex CLI 和 Gemini CLI 的頁面有各自的安裝步驟。

提醒長什麼樣子

🧘 Wrist circles, 10 each way. Your tendons will thank you. · vibestretch · 7 min of agent time

工作階段中會出現一行文字，並響起輕柔的提示音。如果終端機支援，也會跳出通知橫幅。

它怎麼決定何時提醒

vibestretch 沒有排程。它只計算一件事：程式代理的回合讓你在電腦前等了幾分鐘。以下三個條件都成立時，才會提醒你：

  1. 目前這個回合已經跑了 2 分鐘以上。
  2. 從上次提醒到現在，程式代理時間累計達 5 分鐘以上。
  3. 距離上次提醒至少 15 分鐘。

很快結束的回合不會觸發提醒。一整天都是短回合，它就完全不會出聲。它也沒有「稍後提醒」可按，因為它只在你本來就在等的時候出聲。詳情請看AI 程式代理執行時的伸展休息。

有哪些功能

  • 內建 12 個動作：伸展、小運動和讓眼睛休息的動作，例如 20-20-20。
  • 輪替時不會連續兩次出現同一個動作。
  • 想用自己的動作清單也可以。請看工程師的辦公桌伸展操。
  • Claude Code 狀態列可選用的提醒區塊。

隱私

vibestretch 只有幾個小型 POSIX shell 指令碼和一個內附的音效。它不會連上網路，也不傳送遙測資料。它不顯示廣告，也不會在終端機裡放連結。它不會在模型的上下文中加入任何內容。狀態資料存放在 ~/.cache/vibestretch/。

常見問題

vibestretch 是什麼？
vibestretch 是程式代理的外掛程式。程式代理跑一個很長的回合、讓你等待時，它會提醒你伸展、活動一下或讓眼睛休息。
支援哪些程式代理？
Claude Code、OpenAI Codex CLI 和 Gemini CLI。三者共用同一個計數器。不管是哪個程式代理讓你坐在椅子上等，一小時的等待只會算一次。
它是休息計時器嗎？
不是。計時器依排程運作。vibestretch 只計算程式代理的回合讓你等待的時間，也只在等待期間提醒你。
它會把資料傳到別的地方嗎？
不會。它不連網路，也不傳送遙測資料。所有資料都留在你的電腦上。
要多少錢？
免費。vibestretch 以 MIT 授權條款開放原始碼，程式碼放在 GitHub 上。
要怎麼讓它安靜？
把 VIBESTRETCH_DISABLE 設成任何值，就能關閉提醒。VIBESTRETCH_SOUND=0 可關閉聲音。VIBESTRETCH_NOTIFY=0 可關閉通知橫幅。
