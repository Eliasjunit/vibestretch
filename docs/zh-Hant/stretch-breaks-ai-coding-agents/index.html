AI 程式代理執行時的伸展休息

程式代理一次可能要跑好幾分鐘。你只能坐著看。vibestretch 把這段等待變成一次短暫的休息。

為什麼等待是休息的好時機

休息計時器依排程響起。它常常在你想事情想到一半時跳出來，很多人最後乾脆把它關掉。程式代理忙碌的時間不一樣。你反正都在等。趁這個空檔伸展一下，不會打斷你的專注。

vibestretch 計算什麼

它計算程式代理時間：你在電腦前時，程式代理回合執行的分鐘數。從上次提醒開始累加。這跟你在座位上坐了多久無關。一小時都在閱讀和打字，中間只有幾個很快的回合，幾乎不會累積時間。

什麼時候會提醒

以下三個條件必須同時成立：

  1. 目前這個回合已經跑了至少 2 分鐘。
  2. 從上次提醒到現在，程式代理時間至少 5 分鐘。一個大任務或幾個中型任務都算。
  3. 距離上次提醒至少 15 分鐘。

每個數字都能用環境變數調整。完整清單請看 Claude Code 頁面。

離開座位的時候

如果你離開鍵盤 45 分鐘以上，累積的時間會歸零。你已經休息過了。在 macOS 上，hook 會讀取系統的鍵盤與滑鼠閒置時間。所以程式代理整晚在跑，也不會累積程式代理時間，更不會對著空椅子響鈴。Linux 沒有通用的閒置時間介面，所以在 Linux 上只有 45 分鐘歸零這條規則。

提醒會要你做什麼

每次提醒都是 12 個動作中的一個，包括伸展、小運動和讓眼睛休息的動作。完整清單請看工程師的辦公桌伸展操。

常見問題

短回合也會提醒我嗎？
不會。回合必須跑至少 2 分鐘，而且累積了足夠的程式代理時間，才可能觸發提醒。
模型越快，提醒就越少嗎？
對。快的模型在達到門檻前就結束回合了，所以不需要特別關掉提醒。
用指令碼或 cron 執行的程式代理呢？
在那個環境中設定 VIBESTRETCH_DISABLE=1。否則無人看管的工作階段也會被算進去，但你其實沒有坐在那裡等。
